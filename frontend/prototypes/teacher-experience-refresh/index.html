完整备份会保护什么

会备份

  • 考试、成绩、评分依据与批注
  • 题库试卷、题目和标签
  • 班主任工作与学生档案数据库
  • 配置、模板、报告与快照

不会备份

  • API 密钥和服务地址
  • 运行日志和开发缓存
  • 备课工作台资料目录
  • 备份文件本身
完整备份 ≠ 完整数据包：数据包用于搬运部分数据，不包含班主任工作区，也不包含 API 设置。
