## 开始和安全边界

1. 只使用 Codex 准备的匿名验收环境。
2. 页面不应出现真实学生、真实考试、密钥、业务正文或本机绝对路径。
3. 备份、恢复准备、上传和下载都只写入临时目录。
4. 如果看到真实业务数据、密钥、非本机地址，或页面要求选择真实文件夹，请立即停止并按 Blocker 反馈。

## 七项快速检查

### 1. 查看系统状态账本

- 打开“设置与运维”。
- 预期：能看到版本、API 配置是否完成、数据目录、两个数据库、外部工具和备份清单；只显示逻辑名称，不显示本机路径或 API Key。

### 2. 复制脱敏诊断

- 点击“复制脱敏诊断”。
- 预期：页面提示“已复制脱敏诊断”；粘贴内容只有公开状态，不含密钥、路径或业务正文。

### 3. 创建临时备份

- 在“创建备份”点击“开始预检”。
- 先输入错误文字，再输入“确认备份”。
- 预期：错误文字不能提交；准确短语才能启动任务。任务完成后显示 100%，不能显示成 1%。

### 4. 下载备份结果

- 点击“下载结果”。
- 预期：浏览器下载一个安全命名的 ZIP，不要求选择服务器目录，也不显示内部路径。

### 5. 准备恢复但不应用

- 在备份清单中选择刚生成的完整备份，点击“检查恢复影响”，输入“确认恢复”。
- 预期：页面明确提示需要重启；任务成功后只能显示“准备完成，尚未应用”，不能声称恢复已经生效。

### 6. 撤销待重启操作

- 点击“撤销待重启操作”。
- 预期：页面显示“待执行操作已撤销”，并说明下次启动不会应用本次准备内容。

### 7. 窄桌面窗口

- 把窗口调到约 1024×768。
- 预期：安全闸门移到主要内容前方；所有状态、确认输入和操作仍可滚动访问，页面不应整体横向溢出。
