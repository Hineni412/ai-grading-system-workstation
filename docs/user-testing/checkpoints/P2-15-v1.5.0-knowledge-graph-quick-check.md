**预计用时：** 5—8 分钟

## 开始和结束

1. 由协作助手打开匿名验收窗口；教师不需要运行命令。
2. 确认页面标题是“知识图谱”，顶部显示当前考试，页面出现“查看范围”和“知识标签分布”。
3. 验收结束后直接关闭匿名验收浏览器标签页；匿名数据不会保存。

## 快速检查

### 1. 工作台范围带入

- 从工作台选择“七年级一班”，点击“打开完整知识图谱”。
- 应进入知识图谱页，并保留当前考试和“七年级一班”。
- 直接打开但没有班级时，应提示“请选择班级并应用范围”，不能自动猜第一个班级。

### 2. 范围筛选

- 依次查看“当前考试”“指定考试”“全部可用考试”。
- 依次查看“整个班级”“单名学生”“已选学生”。
- 修改选择但未点击“应用范围”时，当前图不应变化；点击后才更新。
- 顶部当前考试改变时，旧的当前考试图应清空并要求重新应用班级范围。

### 3. 掌握度分区

- 页面应同时写出四档文字和阈值：重点薄弱、需要讲评、轻微欠缺、稳定。
- 画布中应有可见节点，不是空白框。
- 节点之间不应出现知识父子、先修或相关关系线。
- 使用鼠标滚轮缩放、拖动画布，再点击“恢复视图”，画布应恢复可读。

### 4. 学生分组树

- 点击“学生分组树”。
- 应显示范围、学生和精确知识标签之间的虚线分组。
- 页面必须常驻显示：“虚线仅表示筛选范围、学生与知识标签的分组归属；不是知识点父子、先修或相关关系。”

### 5. 文字目录和证据

- 在“知识标签文字目录”搜索一个标签。
- 使用方向键移动焦点，按回车选择标签。
- 右侧“知识点详情”应显示得分率、文字等级、证据数、学生数、扣分记录、支持标签和扣分原因。
- 若存在多页证据，点击“加载更多证据”；原有证据应保留，重复项不应增加。
- 页面不应出现排名、预测、自动建议或关系编辑入口。

### 6. 提示、空态和紧凑窗口

- 覆盖率和 warning 应以文字显示，不能只靠颜色。
- 无标签范围应显示明确空态；读取失败应有重新加载入口。
- 在 1024×768 窗口中，筛选、画布、文字目录和知识点详情都应可滚动到达，不应出现横向溢出或内容遮挡。
