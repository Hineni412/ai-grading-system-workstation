## 固定环境与安全边界

- **数据源：** 仅使用便携包内固定合成数据或临时隔离副本；不读取、修改、移动、暂存或提交真实 `user_data/`。
- **启动方式：** 在干净便携目录双击 `运行.bat`；工作机不需要 Node.js。
- **默认地址：** `http://127.0.0.1:8000/`；API 健康检查为同源 `/api/healthz`。
- **可见标识：** 控制台显示“当前入口: Vue + FastAPI”，页面显示 Vue 工作台；回退时显示“当前入口: Streamlit 回退模式”。
- **关闭方式：** 关闭启动窗口或按 `Ctrl+C`，确认前台服务退出；不保留后台启动进程。
- **回退方式：** 关闭当前窗口后设置 `USE_STREAMLIT=1` 再运行；需要时可同时设置 `START_API=0`。
