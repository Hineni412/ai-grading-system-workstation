## 七项快速检查

### 1. 从题库加入试题篮

- 在题库页选择 2–3 道题，点击“加入试题篮”。
- 再重复加入其中 1 道题。
- 预期：组卷篮只保留去重后的题目数量，并能进入“组卷工作台”。

### 2. 刷新恢复

- 在组卷工作台刷新页面。
- 预期：标题、题目顺序、已选题目和预览仍恢复；页面不要求重新选择题目。

### 3. 排序和分节

- 调整题目上下顺序。
- 在左侧组卷篮点击“添加分节”，直接在左侧分节名称输入框里改名。
- 把“未分节”里的题目拖到目标分节。
- 预期：左侧实时显示“未分节”和已有分节；预览区上方不再出现单独的分节编辑面板；预览中的题目顺序和分节标题同步变化；没有题目重复或消失。

### 4. 学生 / 教师预览

- 切换学生预览和教师预览。
- 预期：学生预览不显示答案；教师预览显示答案或教师信息。缺少图片素材时应保留文字说明，不显示本机路径。

### 5. 导出 Word 和 Markdown

- 分别提交 Word 和 Markdown 导出。
- 预期：任务可看到进度，成功后可下载；下载文件名安全，不暴露本机路径。

### 6. 失败重试、取消和记录恢复

- 对失败或取消的导出任务使用重试。
- 从历史记录恢复一份组卷。
- 删除一条历史记录。
- 预期：重试不会要求选择本机路径；恢复后题目和顺序回到记录内容；删除只删除记录，不影响已下载文件。

### 7. 窄桌面窗口

- 把窗口调到约 1024×768。
- 预期：分节、预览、导出记录都能滚动访问；页面不应整体横向溢出，主要按钮不被遮挡。
