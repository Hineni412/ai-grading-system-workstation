## 七项快速检查

### 1. 明确范围并分析

- 选择“匿名阶段测验”和“匿名学生甲”，点击“分析薄弱知识点”。
- 预期：页面明确显示 1 场考试、1 名学生，并出现掌握率、薄弱原因和评分证据；筛选结果不会被自动当作已选范围。

### 2. 空证据与覆盖缺口

- 改选“匿名学生乙”并分析，再切回“匿名学生甲”。
- 预期：无精确标签证据时说明原因和下一步；切回后显示覆盖缺口，不会残留上一名学生的诊断。

### 3. 生成精确标签计划

- 点击“生成计划预览”。
- 预期：按“针对训练 / 基础巩固 / 提升应用”显示推荐题和理由；缺题会如实提示，不会用近义或相邻标签补足。

### 4. 题库变化冲突保护

- 在验收环境触发预置的候选题变化，再点击“确认并保存训练任务”。
- 预期：页面提示候选题已变化，保留旧预览供核对，但禁止把旧计划直接保存；重新生成后才能再次确认。

### 5. 确认和刷新恢复

- 重新生成并确认训练任务，然后刷新页面。
- 预期：只保存一个固定任务；刷新后可从“最近训练任务”恢复并查看题目版本。

### 6. 导出和下载

- 对已保存任务提交训练材料导出并下载。
- 预期：可看到任务状态，成功后下载 ZIP；失败或取消状态有明确重试入口，不要求选择本机输出路径。

### 7. 窄桌面窗口

- 把窗口调到约 1024×768。
- 预期：范围、证据、推荐路径、任务历史和导出均可滚动访问；页面不应整体横向溢出，主要按钮不被遮挡。
