## 开始和安全边界

1. 由 Codex 启动匿名验收窗口；教师不需要运行命令。
2. 页面应只显示“匿名九年级期末试卷”“匿名验收题目”等合成文字，不应出现真实考试、学生、题目或密钥。
3. 所有写入只发生在每次重建的 `frontend/test-results/p2-16-real/` 临时目录；AI 操作只使用假处理器，不产生费用。
4. 验收结束后关闭匿名浏览器即可；日常 Streamlit 入口不受影响。

如出现真实业务数据、密钥、非本机地址，或页面要求选择真实文件，请立即停止并报告为 Blocker。

## 七项快速检查

### 1. 规模、筛选与分页

- 应看到“共 2005 题”和连续题目台账。
- 在关键词输入 `LONG_FORMULA`，但先不点击“应用筛选”：总数和列表不应变化。
- 点击“应用筛选”后应只剩 1 题；点击“清除”后恢复 2005 题。
- 使用“下一页”后页码应变为“第 2 / 101 页”。

### 2. 完整题页与素材

- 筛选 `LONG_FORMULA` 并打开第 1 题。
- 右侧应显示长公式、题目图片、答案与解析，以及“打开题目预览”。
- 长公式和图片不能撑出整个窗口；图片失效时仍应保留文字并显示局部说明。

### 3. 跨页选择与费用确认

- 清除筛选，在第 1 页选择一题，再到第 2 页选择一题。
- 应看到“已选 2 题，其中 1 题在其他页”。
- 点击“AI 标注 2 题”时，必须先出现包含实际题数和可能产生费用的确认；选择取消时不能提交任务。

### 4. 部分失败、下载与恢复

- 确认启动匿名 AI 任务后，应看到“部分完成”，并分别显示成功、跳过、失败数。
- 点击“下载失败清单”，文件只能包含题目 ID、失败分类和脱敏说明。
- 刷新页面后，该任务及部分失败状态仍应恢复。
- 点击重试时应再次出现费用确认，并只重试允许的失败题目。

### 5. 教师标签确认

- 打开第 1 题，添加“知识点 / 函数建模”标签并保存。
- 应看到“标签已经保存”；题干和答案不应变化。
- 如果页面提示题目已被其他操作更新，当前标签草稿必须仍在，不能自动覆盖。

### 6. 受控导入与立即恢复

- 选择验收提供的匿名 `.docx` 文件，应出现独立“试卷导入 #…”任务；页面不要求本机文件夹或目标路径。
- 删除当前第 1 题前必须出现确认；删除成功后应出现“立即恢复”。
- 点击“立即恢复”后题目应重新打开，标签仍在。

### 7. 紧凑桌面窗口

- 将窗口调整到约 1024×768。
- 筛选、任务、连续台账和题页检查器都应可滚动到达；页面不能整页横向溢出，按钮不能被遮挡。
- 使用 `Tab` 经过主要控件，焦点应清楚可见。

## 反馈格式

- 全部正常：回复“P2-16 1–7 通过”。
- 有异常：回复“步骤编号 + 看到的现象 + 截图”。
- Blocker：真实数据或密钥出现、写入真实系统、页面无法启动或主流程整体不能继续。
- Major：筛选/分页结果错误、跨页选择丢失、未确认就调用 AI、冲突覆盖草稿、任务刷新丢失、删除无法恢复。
- Minor：不影响七项操作完成和结果正确的文字、间距、焦点或局部布局问题。
