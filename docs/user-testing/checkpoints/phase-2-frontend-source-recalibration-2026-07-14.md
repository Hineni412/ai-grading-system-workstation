| 1 | 打开验收地址，不做任何操作。 | 默认进入 Q1 批量复核；题号、待复核数、满分、搜索、范围、排序和两份答卷都清楚可见；没有单份深查区叠在页面上。 | 停止并回复“步骤 1 + 现象 + 截图”。 |
| 2 | 比较当前两份答卷的图片、风险、置信度和教师最终分；不要改第一份的 3 分。 | 两份答卷能在同一批次横向比较；保留 AI 原分也属于可确认结果，不要求为了提交而改分。 | 停止并回复“步骤 2 + 缺失的信息”。 |
| 3 | 把任一“教师最终分”改成 8。 | 就地提示不能超过本题 5 分；“确认本批并继续”不可用，整批不会提交。改回 0～5 的有效值后按钮恢复。 | 停止并回复“步骤 3 + 是否仍可提交”。 |
