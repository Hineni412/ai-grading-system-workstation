## 2. 当前三路产品定义

### P4：个性化训练闭环

权威文档：

- [产品与实现设计](../../product/PERSONALIZED_TRAINING_LOOP.md)
- [详细实施计划](./phase-4-execution-packages.md)

冻结方向：

- 知识点关系只由教师确认后生效；
- 掌握度 v2 与旧口径并列、可解释、可回退；
- 题库分析可在一次物理请求中同时产生标签和训练判定点；
- 标签与判定点分别校验、保存、审核和重试；
- 产品操作上先完成普通标签治理，再在题库同一道题详情中审核训练判定点；
- 训练判定点不带分值；
- 一人一卷冻结题目、判定点和页面身份；
- 混合扫描先归卷，后按学生整卷判定；
- 模型逐点返回四态，本地计算达成点数/总判定点数；
- 普通考试分数、排名、报告和教师最终分锁保持不变。

### 3.1 快速迭代与提问规则

- P4-00—P4-17、A00—A10、B00—B11 是范围、依赖和完成清单，不是逐包测试或逐包复审关口；
- 每个小任务完成后记录进度和必要检查点，随后持续推进；
- 只有故障阻塞继续实现时才做最小范围诊断，不因此启动全量测试或正式复审；
- 当整条业务线进入用户最终验收阶段时，冻结完整候选，一次性运行回归、完整测试、必要构建、交叉冒烟和双复审；
- 会改变功能结果且无法从源码或文档查明的问题要及时询问用户；
- 提问前先集中调查，尽量一次列出当前全部已知问题，并给出推荐答案及影响；
- 后续问题确实依赖前一轮回答，或需要根据页面效果继续调整时，可以分步骤询问；
- 一条线等待用户回答时，只暂停受影响部分，其他业务线和该线内不受影响的工作继续。

F0 可以与 P4-00/P4-01、A00、B00 同时启动，但 F0 不是长期第四条产品线。F0 整体完成后集中测试、复审和验收一次，合入形成 M1，随后只剩 P4、A、B 三条业务线长期并行。
