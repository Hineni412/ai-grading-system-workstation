## 工作约定

1. 同一长期分支持续承接全部 P3.5 批次，不为每批创建执行包、短分支或 integration。
2. 每批只围绕用户当前提出的真实需求实施；能够从项目查明的事实自行调查。
3. 用户查看后可继续提出调整；启动和构建只服务展示，不构成自动验收门槛。
4. 用户明确表示整体满意前，不进入统一精简、push、PR 或主线同步。
5. Phase 4 保持暂停，不预先实现其 Schema、关系语义、模型任务或训练闭环。
6. 真实数据、真实模型费用、数据库迁移和不可逆操作每次都要单独取得用户明确授权。
