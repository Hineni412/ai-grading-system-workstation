## 2. 当前三路产品定义

### P4：个性化训练闭环

权威文档：

- [产品与实现设计](../../product/PERSONALIZED_TRAINING_LOOP.md)
- [详细实施计划](./phase-4-execution-packages.md)

冻结方向：

- 知识点关系只由教师确认后生效；
- 掌握度 v2 与旧口径并列、可解释、可回退；
- 题库分析可在一次物理请求中同时产生标签和训练判定点；
- 标签与判定点分别校验、保存、审核和重试；
- 训练判定点不带分值；
- 一人一卷冻结题目、判定点和页面身份；
- 混合扫描先归卷，后按学生整卷判定；
- 模型逐点返回四态，本地计算达成点数/总判定点数；
- 普通考试分数、排名、报告和教师最终分锁保持不变。

## 4. 当前授权边界

本轮用户已明确授权：

- 更新和整合 P4、A、B 的设计与实施文档；
- 创建本次纯文档分支；
- 提交、push、创建 PR、合并云端 `main`；
- 同步本地 `main`。

本轮没有授权：

- 实现 F0、P4、A 或 B 业务代码；
- 读取、复制、修改、迁移或删除真实 `user_data`；
- 调用真实模型或产生模型费用；
- 对真实数据库执行迁移；
- 操作真实教材、教辅、PPT、学生档案、成绩、训练卷或答卷；
- 启动真实应用；
- 自动打印、发送或执行不可逆操作。

以后每次具体真实操作仍需单独确认目标、范围、备份、费用和回退。
