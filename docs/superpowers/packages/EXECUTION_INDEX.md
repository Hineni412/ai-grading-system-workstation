## 当前执行队列

### 当前执行方式

从下一批里程碑起，默认采用“根目录 `main` + 一个滚动功能 worktree + 一个 integration worktree”的低占用串行模式。每个执行包仍创建独立短分支；上一包进入 integration 并完成逐包验证、安全释放功能目录后，下一包在同一物理功能 worktree 从 Index 记录的精确基线创建新分支。只有本文件明确记录第二通道、文件所有权和并行收益时，才临时增加第二个功能 worktree。
