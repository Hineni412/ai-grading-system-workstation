# 夜间自动化安全停机

P4、A、B 已进入可派发准备，但用户没有授权无人值守开发。任何夜间自动化仍必须 **只报告、不实施**。

夜间不得：

- 自动领取、创建、恢复或继续 F0、P4、A、B 开发任务；
- 修改代码或文档、切换分支、创建或重分配 worktree；
- 运行测试、构建、复审或用户验收；
- 创建提交、push、PR、合并或清理分支/worktree；
- 读取或操作真实 `user_data`；
- 调用真实模型、使用密钥、产生费用或执行不可逆操作。

每次触发只需报告：

1. 当前执行索引中的 F0、P4、A00、B00 状态；
2. 是否存在等待用户决定的文件、数据、费用或治理关口；
3. 白天可以人工派发的下一动作；
4. 不自动改变任何任务状态。

只有用户单独要求设计夜间自动化，并明确允许的任务、分支、时段、测试、费用、真实数据边界和停机条件后，才可另建自动化规格。不得根据历史包、旧资格矩阵或“阶段已恢复”自行启动。
