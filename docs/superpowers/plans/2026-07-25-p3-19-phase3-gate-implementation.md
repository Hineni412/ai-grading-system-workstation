## 故障场景

| 场景 | P3-19 预期结果 |
|---|---|
| 重复操作 | 同一副本重复迁移、重复验证与重复恢复结果一致，不重复修改源文件 |
| 同时操作 | 并发启动/迁移继续由现有锁和原子事务保护；门槛只在隔离副本上验证 |
| 中途退出 | 未完成迁移或恢复不得冒充成功；临时目录可清理，源文件不变 |
| 重新启动 | 已迁移副本通过版本/checksum/完整性门槛；应用可从同一副本再次启动 |
| 失败重试 | 从新的源副本重新预演；不得在半完成副本上掩盖第一次失败 |
| 取消 | 停止后不产生阶段通过结论；不得触发真实迁移或外部模型请求 |
| 部分完成 | 任一矩阵项、五流程或恢复项失败都会保留精确证据并阻止 Phase 3 收口 |
| 数据缺失或冲突 | 不受支持、损坏、漂移或身份冲突的快照明确分类并失败关闭，不猜测修复 |
