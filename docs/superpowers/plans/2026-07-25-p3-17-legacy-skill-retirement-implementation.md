## 集中调查与冻结前问题清单

1. 11 张旧语义表来自题库 migrations 006—008；历史迁移文件必须保留，新增迁移只能向前删除当前表。
2. 活动图谱、训练推荐和批改上下文已经读取 `grading_question_links + question_tags`，对应 67 项 tag-only 聚焦回归通过。
3. 旧体系仍有源码能力：旧知识对齐、技能目录/解析/链接/迁移服务，冲突收件箱，诊断的 legacy/skill 分支，推荐的 legacy/skill 分支，以及题库标签的显式旧技能双写。
4. 真实题库只做了只读完整性和数据存在性核对；具体业务数量、内容和路径不进入文档或 Git。该核对不构成修改或迁移真实库的授权。
5. `training_sets/training_set_items` 没有活动调用，但不属于目标明确列出的 11 张旧语义表；按最保守边界留给独立后续任务，不随本包扩大删除集合。
6. P3-16 滚动功能目录没有 Git 变更，但仓库基线本身含受保护的 `user_data` 文件；为避免切换时误触，P3-17 使用从最新主线新建的独立干净 worktree，所有 `user_data` 保持未修改。

冻结前根因分为三组：活动源码仍保留旧语义能力；删除前缺少独立只读归档；迁移链尚无精确 11 表删除与恢复证据。当前唯一产品未决项是用户是否仍需要查看旧技能语义历史数据。

## 故障场景

| 场景 | 预期结果 |
|---|---|
| 重复导出 | 默认拒绝覆盖；显式覆盖也必须使用同路径进程锁和原子替换 |
| 同时导出 | 同一目标只允许一个进程发布；其他进程明确失败，不得静默覆盖 |
| 导出中途退出 | 不发布半成品；临时文件可清理，源库保持只读 |
| 重复迁移/重新启动 | 新迁移只登记一次；再次运行无待处理项 |
| 迁移失败或结构冲突 | 整笔回滚且不登记成功；迁移前整库备份保留 |
| 取消 | 导出和迁移为短同步命令，无协作式取消；进程终止按中途退出规则处理 |
| 部分完成 | 11 表必须在同一事务全部删除或全部保留 |
| 数据缺失或冲突 | 结构守卫失败关闭，不猜测或自动修补历史 Schema |
| 归档数据不完整 | 表列、全部行、表级计数和内容摘要必须可重算核对 |
| 真实数据误触 | 所有写验证仅接受临时路径；真实两库 SHA-256 前后必须一致 |
