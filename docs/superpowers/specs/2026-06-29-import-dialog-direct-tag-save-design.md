# 导入弹窗与题库标签直接保存设计

## 目标

修复题库导入弹窗在选择文件后关闭、关闭后保留未导入试卷的问题；同时让题库 AI 标签保存不再自动触发旧技能目录的 AI 消歧。

## 已确认行为

- 选择单个或多个文件、选择文件夹后，弹窗继续显示扫描结果，不执行整页重跑。
- 点击“关闭”或右上角 X、点击遮罩、按 Esc 后，清除未导入扫描行、表格编辑状态和旧成功提示。
- “导入后自动打标签”“跳过已标注题”等用户偏好不因关闭弹窗而重置。
- AI 返回的知识点、方法、能力、模型、易错点、细分技能、主技能和辅助技能等原始标签继续写入 `question_tags`。
- `QuestionService.save_tag_analysis()` 默认不再同步 `question_skill_links`，也不调用 `LLMSkillContextRanker`。
- 旧技能迁移与兼容路径继续保留；明确需要旧双写的调用方可显式传入 `resolve_skills=True`。
- 活动知识图谱、诊断和训练推荐继续直接读取题库当前 `knowledge_point` 标签，不新增字段或数据迁移。

## 实现边界

- 在 `pages_shared` 增加一个只负责 Streamlit 导入弹窗状态的轻量模块，避免在巨型页面中散落状态清理规则。
- `pages/题库管理.py` 复用状态模块；文件选择完成后直接继续渲染，弹窗内部需要刷新时使用 fragment 级重跑。
- 题库标签页不再构造带 LLM ranker 的 `SkillResolutionService`。
- 不删除旧技能表、服务、迁移脚本或兼容测试。

## 验证

- 单元测试覆盖导入状态替换、关闭清理和偏好保留。
- UI 契约测试覆盖 X/关闭回调、选择文件后无整页重跑。
- 服务测试证明默认保存不会调用 resolver，显式兼容开关仍能写入旧技能链接。
- 浏览器验证弹窗打开、关闭和重新打开为空状态；本地原生文件选择仍需人工点击完成最终 Windows 窗口验证。
