# P2-03 App Shell、路由与全局会话上下文设计

## 1. 目标

在尚未切换生产入口的 Vue 前端中建立稳定应用外壳：顶部栏、可收起左导航、中央路由工作区和可收起右检查器；按既定七项一级信息架构提供路由入口；用 Pinia 统一当前考试会话上下文，并在刷新后恢复经过现有 sessions API 验证的选择。

P2-03 只建立后续业务页面可复用的壳层和上下文，不迁移任何 Streamlit 业务页面，不建设 P2-04 的通用 API Client、统一错误契约、轮询、退避或 Job Store。

## 2. 权威依据与已确认决定

- `docs/ui/STYLE.md` 是视觉、信息层级、App Shell、响应式和可访问性的唯一权威来源。
- `docs/superpowers/packages/phase-2-execution-packages.md` 定义 P2-03 的稳定范围、依赖和验收。
- `docs/superpowers/plans/2026-07-03-frontend-backend-modernization-master-plan.md` 固定七项一级导航、设置入口和全局会话选择器位置。
- 现有 Streamlit 会话选择器在无有效选择时保持“未选择”，不会自动选中第一场考试；新前端维持该业务行为。
- 用户于 2026-07-12 批准：P2-03 通过会话专用轻量适配器真实读取 `/api/sessions`，通用网络层仍留给 P2-04。
- 用户于 2026-07-12 进一步确认：产品不需要任何移动端或平板支持，只实现和验收宽度不低于 1024px 的 Windows 桌面浏览器；此前规格中的 768×1024、390×844 和低于 1024px 抽屉要求由本决定取代。
- P2-02 已实现的 Token、Element Plus 主题、基础状态控件和组件展示页继续作为视觉与交互基础。

## 3. 方案比较与选择

### 方案 A：会话专用轻量适配器（采用）

只为 `GET /api/sessions` 定义最小响应类型和读取函数，Pinia Store 消费该函数。适配器保持可注入、可单测，P2-04 可以在不改变 Store 公共语义的前提下替换其底层网络实现。

该方案能验证真实 sessions API 契约和刷新恢复行为，同时不提前引入通用错误模型、request ID、重试、取消或轮询。

### 方案 B：仅使用模拟会话

实现范围最小，但无法证明全局会话上下文与现有 API 契约相容，也不能完成真实刷新恢复，因此不采用。

### 方案 C：提前建设通用 API Client

可以一次解决网络层复用，但会侵入 P2-04 的独立包边界并扩大复审范围，因此不采用。

## 4. 范围

### 4.1 包含

- App Shell 的顶部栏、左导航、中央工作区和右检查器；
- 七项一级导航、侧栏底部设置入口、面包屑、404 和路由错误边界；
- 导航可用性模型，以及“智能体与自动化”的禁用未来入口；
- Pinia 全局 session Store、浏览器持久化和 sessions API 验证；
- 左导航和右检查器的展开/收起状态；
- 1024–1279px 的紧凑桌面栏位策略，以及低于 1024px 不受支持的明确边界；
- 无业务功能的统一路由占位页；
- P2-02 组件展示页迁移到 `/design-system`；
- 路由、Store、壳层、响应式、键盘和多视口自动测试；
- P2-03 完成后的版本化短测清单。

### 4.2 不包含

- 阅卷、考试、学生、分析、题库、训练、设置等业务页面迁移；
- 通用 API Client、统一错误解析、request ID、网络重试、轮询、取消和 Job Store；
- 会话创建、改名、删除、恢复或进度读取；
- 认证、角色、权限系统或新的业务状态；
- 智能体聊天、任务、自动化规则或执行记录；
- 后端、数据库 Schema、`运行.bat`、生产静态托管或 Streamlit 入口修改；
- 新前端依赖、深色模式、品牌换肤或 P2-02 Token 之外的新色板；
- 真实 `user_data/`、真实密钥或真实模型调用。

## 5. 信息架构与路由

路由配置是导航、面包屑和页面标题的单一来源。一级入口固定为：

| 路径 | 导航名称 | 本包行为 |
|---|---|---|
| `/workbench` | 工作台 | 显示尚未迁移说明和当前会话上下文 |
| `/grading` | 阅卷 | 显示尚未迁移说明和后续包边界 |
| `/exams` | 考试 | 显示尚未迁移说明和当前会话上下文 |
| `/students` | 学生 | 显示尚未迁移说明 |
| `/analytics` | 分析 | 显示尚未迁移说明 |
| `/question-bank` | 题库与训练 | 显示尚未迁移说明 |
| 无可进入路径 | 智能体与自动化 | 禁用入口，显示“未来能力”说明和禁用原因 |
| `/settings` | 设置 | 显示尚未迁移说明；入口固定在侧栏底部 |
| `/design-system` | 设计系统展示 | 保留 P2-02 全部样张与验收能力，不进入一级导航 |
| `/:pathMatch(.*)*` | 页面未找到 | 显示安全返回工作台的 404 状态 |

根路径重定向到 `/workbench`。占位页只说明该能力尚未迁移、当前可做什么以及后续由哪个包承接，不伪造统计、按钮或业务数据。导航配置支持 `available | future` 两种可用性，不引入不存在的角色或权限概念。

## 6. App Shell 结构

### 6.1 顶部栏

- 高度使用 P2-02 尺寸 Token 约束在 STYLE.md 的 56–64px 范围；
- 左侧显示侧栏切换按钮、面包屑和当前页面名称；
- 中部或右侧放置常驻“当前考试”选择器；
- 右侧提供检查器切换按钮；
- 长页面名和长考试名允许省略显示，但必须通过可访问名称或原生提示读取完整文字；
- 不放营销口号、超大标题、全局搜索假入口或无法执行的主要操作。

本壳层的视觉签名是“业务上下文线”：面包屑、当前页面和当前考试沿顶部栏形成连续阅读路径，让教师始终知道自己位于哪个工作区、正在处理哪场考试。它使用现有背景、边框和字重表达层级，不增加装饰性色彩或动效。

### 6.2 左导航

- 桌面展开宽度约 232px，收起后约 60px；
- 当前项使用克制的背景和文字强调，不使用渐变或大色块；
- 展开态同时显示图标与中文文字，收起态图标仍有可访问名称和提示；
- “智能体与自动化”保持可见但不可进入，禁用原因可被键盘和辅助技术理解；
- 设置固定在底部；帮助和账户因当前没有相应能力而不创建假入口。

### 6.3 中央工作区

- 承载 `RouterView`，获得剩余弹性宽度并允许自身最小宽度收缩到 0；
- 页面标题、说明和状态使用文档式分隔与留白，不套装饰性大卡片；
- 路由切换后把键盘焦点移动到页面主标题，保留清楚的跳过导航入口；
- 页面错误边界提供影响说明、重新进入当前页面和返回工作台动作。

### 6.4 右检查器

- 桌面展开宽度固定在 320–400px 范围，默认采用 360px；
- 只展示当前会话名称、已有 `status` 文本和上下文说明；不读取进度、评分配置或其他业务详情；
- 未选择会话时显示带下一动作的空态；列表加载失败时显示不清除持久化选择的错误态和重试动作；
- 收起后不改变当前 session、当前路由或中央工作区内容；
- 长内容在检查器内部滚动，不生成嵌套抽屉。

## 7. 全局会话上下文

### 7.1 数据契约

会话专用适配器只接受当前 `SessionListResponse` 的公开字段：

```ts
interface SessionSummary {
  id: number
  name: string
  status: string
  is_deleted: boolean
  deleted_at: string | null
  created_at: string | null
  updated_at: string | null
}

interface SessionListResponse {
  items: SessionSummary[]
  total: number
}
```

适配器固定请求相对地址 `/api/sessions`，不接受客户端文件路径、密钥或可变远端 Base URL。它验证 HTTP 成功、顶层对象、`items` 数组以及每个会话的最小字段类型；失败只抛出 P2-03 内部的稳定读取错误，不实现 P2-04 的全局错误体解析。

### 7.2 Store 状态与动作

Store 维护：

- `sessions`：成功验证的活动会话列表；
- `selectedSessionId`：当前已验证选择或 `null`；
- `persistedCandidateId`：启动时读取、等待 API 验证的候选 ID；
- `loadState`：`idle | loading | ready | error`；
- `errorMessage`：面向教师的短错误说明；
- `currentSession`：由列表和 `selectedSessionId` 派生，不复制对象。

公开动作包括初始化/重试读取和选择会话。页面只能通过 Store 读取或改变当前会话，不直接访问 `localStorage` 或拼接 sessions URL。

### 7.3 持久化与恢复

- 使用带版本的本地存储键，只保存十进制 session ID；“未选择”删除该键；
- 启动时先读取候选 ID，但在 API 成功验证前不把它暴露为有效当前会话；
- API 成功且候选存在于活动列表时恢复选择；
- API 成功但候选不存在时清除本地键并保持“未选择”；
- 没有候选时保持“未选择”，不自动选择第一场考试；
- API 失败时保留候选键以便重试，但 `selectedSessionId` 保持 `null`，页面不得把未验证候选当作当前业务上下文；
- 用户选择会话后立即写入本地键，选择“未选择”立即删除本地键。

该策略同时满足刷新恢复、失效会话清理和失败时不误认上下文。

## 8. 响应式与滚动

| 视口 | 壳层策略 |
|---|---|
| `≥1280px` | 展开的左导航、弹性中央区、360px 右检查器；两侧均可手动收起 |
| `1024–1279px` | 左导航默认收起为图标栏；右检查器缩至 320px 并可收起 |
| `<1024px` | 不在产品实现、测试或用户验收范围内，不建设专用抽屉、覆盖面板或移动端降级流程 |

顶部栏保持稳定。支持范围内的桌面左栏、中央区和右检查器可独立滚动；长名称可换行或省略，页面级不得横向溢出。低于 1024px 的行为不作为产品契约。

## 9. 状态、错误与可访问性

- 会话选择器有常驻可访问标签；加载时禁用并说明正在读取；失败时保留重试入口。
- 404、路由错误、会话空态和会话读取错误复用 P2-02 `StatePanel` / `FeedbackBanner`，说明原因、影响和下一动作。
- 所有图标按钮具有中文可访问名称，状态不只靠颜色表达。
- 导航、桌面栏位收起/展开、会话选择、重试和 404 返回都支持键盘。
- 桌面栏位触发器使用正确的 `aria-expanded` 和 `aria-controls`；收起栏位不能保留不可见的键盘焦点目标。
- 焦点样式、颜色、间距、圆角、阴影和动效全部复用 P2-02 Token；遵守 `prefers-reduced-motion`。
- 不隐藏真实错误影响，不显示内部路径、异常堆栈或 API 响应原文。

## 10. 文件职责建议

- `frontend/src/router/index.ts`：路由记录、页面元数据、根重定向和 404；
- `frontend/src/navigation.ts`：七项导航及设置入口的单一配置；
- `frontend/src/api/sessions.ts`：会话专用响应类型、最小校验和 GET 适配器；
- `frontend/src/stores/session.ts`：Pinia 会话状态、持久化和恢复；
- `frontend/src/layouts/AppShell.vue`：壳层栏位、响应式面板状态和滚动边界；
- `frontend/src/components/shell/AppTopbar.vue`：面包屑、会话选择和面板触发器；
- `frontend/src/components/shell/AppNavigation.vue`：导航、禁用未来入口和设置；
- `frontend/src/components/shell/SessionInspector.vue`：当前会话上下文、空态与错误重试；
- `frontend/src/views/RoutePlaceholderView.vue`：共享未迁移状态；
- `frontend/src/views/NotFoundView.vue`：404 安全返回；
- `frontend/src/App.vue`：Element 中文配置、路由错误边界和 App Shell 入口；
- `frontend/src/main.ts`：注册 Pinia 与 Router，并保持按需 Element 样式导入；
- `frontend/e2e/app-shell.spec.ts`：合成 API 响应下的真实浏览器壳层与多视口验证。

实现计划可在不改变上述职责边界的前提下合并过小文件；不得把通用网络层或业务页面塞入壳层组件。

## 11. 测试与验收

### 11.1 单元与组件测试

- 路由表覆盖七项导航、设置、设计系统、根重定向和 404；
- 智能体入口不可进入且禁用原因可读；
- 会话适配器接受合法列表，拒绝非成功响应和畸形 payload；
- Store 覆盖无候选、有效候选、失效候选、读取失败后重试、主动选择和清除选择；
- 刷新模拟后只恢复 API 中仍存在的 session ID；
- App Shell 的左右栏切换不改变路由和会话；
- 长考试名、长页面名、空列表、加载和错误状态均可渲染。

### 11.2 浏览器测试

Playwright 拦截 `/api/sessions` 并返回合成会话，不启动真实数据库，不读取真实 `user_data/`。验证：

- 1920×1080、1440×900、1366×768、1280×800、1024×768 五个桌面规定视口无页面级横向溢出；
- 桌面栏位尺寸和收起行为稳定；
- 1024–1279px 紧凑桌面布局的栏位状态、可访问名称和几何尺寸一致；
- 七项导航、设置、404 和设计系统路由行为正确；
- 选择会话后刷新仍恢复，失效选择清除；
- API 失败时不把未验证候选显示为当前会话，重试成功后恢复；
- Tab 焦点可见，长名称不遮挡主要操作；
- 浏览器控制台无应用错误。

### 11.3 工程门槛

运行 lint、typecheck、unit、build、Chromium e2e、P2-03 相关 Python 静态守卫、`git diff --check` 和 `tools/smoke_check.py --skip-tests`。功能分支不运行全量 pytest，除非实现期间出现公共基础设施变化、测试不稳定或其他仓库规则规定的触发条件。

验证前后只读比较根工作区两库的大小、UTC 修改时间和 SHA-256；必须完全不变。不得修改、暂存、提交或 stash 任何 `user_data/`。

## 12. 用户短测与回退

P2-03 是明显可见的前端批次，用户自测类型为 `quick`。自动验证和独立复审通过后，生成版本化短测清单，让用户在合成会话环境中用 5–10 分钟检查：

- 七项导航和设置位置是否容易理解；
- 当前考试选择与刷新恢复是否符合预期；
- 左右栏收起、紧凑桌面布局和长名称是否易用；
- 禁用未来入口、404、空态和错误态是否清楚；
- 整体视觉是否延续已通过的 P2-02 基调。

P2-03 尚未成为生产 UI。回退时可整体回退该包的 Vue 壳层、路由和 Store 提交；P2-02 组件、Streamlit 生产入口、FastAPI、数据库和真实 `user_data/` 不受影响。
