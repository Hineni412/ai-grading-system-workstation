# P2-15 知识图谱与证据下钻 v1 设计说明

**日期：** 2026-07-15
**执行包：** P2-15
**设计基线：** `9f47ececdd6be6eff68831d74da85d706cca7e48`
**依赖：** P2-14、P1-21（均已合并）
**风险级别：** 中等
**数据影响：** 只读，无数据库迁移
**用户决定：** 2026-07-15 确认默认使用“当前考试 + 当前班级”；确认采用独立知识图谱页面；确认 P2-15 只显示范围/学生/标签的分组线，真实父子或先修关系留给后续关系版本。

## 1. 目标与边界

P2-15 把当前 Streamlit HTML 标签树和 P2-14 工作台中的简化标签列表升级为可缩放、可拖动、可键盘下钻的 Vue 知识标签画布。页面必须让教师回答四个问题：

1. 当前考试和班级有哪些已确认的知识点标签证据；
2. 每个标签的当前得分率、证据量和失分量如何；
3. 某个标签涉及哪些学生、考试和题目；
4. 当前图谱覆盖了多少评分题，哪些题尚未进入标签证据。

本包中的“掌握度”继续等同于现有 tag-only 证据按满分加权得到的得分率，不是能力预测、知识状态模型或 Phase 4 掌握度 v2。

P1-21 的 `GraphRowsResponse.edges` 在本包仍必须是空数组。P2-15 不创建、不推断、不保存知识点父子、先修或相关关系；不得根据标签名称、支持标签、AI 错因或视觉距离暗示这些关系。

## 3. 方案比较与决定

### 方案 A：在工作台内展开完整画布

优点是当前考试上下文直接；缺点是 P2-14 的进度、题目分析、学生明细会与大画布争夺空间，1024px 下证据区和筛选器难以同时可见，千节点性能验证也不自然。不采用。

### 方案 B：独立知识图谱页面（采用）

新增独立 Vue 页面和主导航入口。工作台标签摘要提供带当前考试、当前班级上下文的入口；独立页承载筛选、ECharts 画布、分组树、节点 inspector、证据列表与文字目录。页面可以独立刷新、恢复受控 URL 范围，并为 1000 节点留下稳定画布。

### 方案 C：工作台全屏弹层

实现接线较少，但浏览器返回、刷新、深链接、跨考试切换和错误恢复均不清楚，也容易出现嵌套滚动和焦点陷阱。不采用。

```text
├────────────────────────────────────────────┬────────────────────────┤
│ ECharts 图谱或分组树画布                   │ 节点详情                │
│ 缩放 / 拖动 / 适应画布                     │ 得分率与文字等级        │
│                                            │ 学生/作答/失分计数      │
│                                            │ 支持标签与已有错因      │
│                                            │ 分页证据列表            │
├────────────────────────────────────────────┴────────────────────────┤
│ 覆盖率 / 缺失说明 / 可搜索、可键盘选择的文字节点目录                │

```

- 主导航新增“知识图谱”，工作台 `TagCoverageSummary` 保留摘要并增加“打开知识图谱”。
- 工作台进入时，把已验证的当前 `session_id` 和班级写入受控路由查询；直接进入页面时沿用全局当前考试。如果没有有效班级上下文，页面要求选择班级，不自行选择第一个班级。
- 主区域在 1280px 及以上使用约 70/30 双栏；1024px 下节点详情移到画布下方，筛选器可换行但不隐藏。
- 画布和 inspector 各自只有一个清楚的滚动边界。页面级横向溢出视为缺陷。

## 5. 范围筛选与 URL 状态

### 5.1 默认范围

- `exam_scope.mode=current`，使用当前会话 store 中的有效考试；
- `scope.mode=class`，使用从工作台传入或本浏览器会话中当前有效的班级；
- 没有班级时不发空 class 请求，显示“选择班级后查看知识图谱”。

### 5.2 可选范围

- 考试范围：当前考试、手动选择一至多场活动考试、全部活动考试；
- 学生范围：当前班级全部学生、单个学生、已选学生；
- 标签搜索：只在当前已返回节点中做规范化文本筛选和聚焦，不改变服务端诊断结果；
- 多项范围更改后由一个“应用范围”主按钮提交，避免连续选择时重复进行昂贵查询；标签搜索即时生效。

路由查询只保存已验证的服务器 ID、Graph 枚举和班级显示值，不保存学生正文、证据内容或任意 URL。无效查询被忽略并显示安全提示。切换范围时取消旧请求并立即使旧画布失效，旧范围不得出现在新标题下。

## 6. 图谱模式与分组树模式

### 6.1 图谱模式

采用 ECharts Canvas 渲染器。知识标签节点不画任何相互连接线，而是按现有四档得分率放入稳定的横向证据带：

- `>= 90%`：稳定；
- `>= 75% 且 < 90%`：轻微欠缺；
- `>= 60% 且 < 75%`：需要讲评；
- `< 60%`：重点薄弱。

节点位置在每档内由确定性排序和防碰撞布局产生；位置本身不表达知识关系。节点面积使用经上限约束的平方根尺度表达 `item_count`，标签同时显示精确知识点名称、得分率和文字等级。选择态使用主强调色边框与清晰焦点，不改变业务颜色。

画布唯一的辨识性元素是“证据带”：像教师把知识标签按需要讲评程度整理到批注纸面的四条安静横栏。它编码真实的当前得分率，并避免随机力导向布局暗示不存在的关系。

### 6.2 分组树模式

采用 ECharts tree 表达现有 rows 中可验证的容器关系：

```text
当前筛选范围
└─ 学生
   └─ 精确知识标签
```

班级聚合视图可以折叠学生分支；单个学生视图只显示该学生分支。连接线使用浅灰虚线，并在画布标题旁常驻说明：“虚线仅表示当前范围内的归属，不表示知识点父子、先修或相关关系。”

分组线只在浏览器内由当前 rows 临时生成，不进入 Graph API、数据库、导出或任何领域模型。服务返回的 `edges` 非空时，本包前端应拒绝把它渲染为 P2-15 知识关系并记录安全错误状态，防止未来契约未经设计直接泄漏进当前页面。

### 6.3 图谱与树的一致性

两个模式使用同一成功响应、同一筛选范围、同一节点选择和同一 inspector。切换模式不得重新请求数据，不得改变覆盖率、节点计数或证据结果。选中的标签在两个模式间保持；不存在时清除选择并把焦点移到画布标题。

## 7. 节点详情与证据下钻

选择节点后，右侧 inspector 固定显示：

- 精确知识标签名称；
- 当前标签得分率、四档文字等级和明确口径“按当前标签证据加权”；
- `student_count`、`item_count`、`deduction_count`；
- 支持标签，按现有 tag type 分组；
- 主错因和次要错因的现有计数；
- 当前相同范围下的分页证据列表。

证据行只显示 P1-21 允许字段中的教师可识别摘要：学生、考试、题号、得分/满分、已有扣分原因。当前接口没有复核明细 ID 或安全图像令牌，因此 P2-15 不伪造“查看原卷”“去复核”动作；未来若已有业务契约补齐，再单独设计。

Graph evidence 请求必须复用选中节点时的完整 `scope` 和 `exam_scope`。响应的标签、范围、考试和分页必须与请求完全一致；不一致响应按格式错误处理，不渲染旧内容。切换节点时取消旧 evidence 请求，快速点击不得串证据。

## 8. 文字目录、键盘与非颜色信息

- 画布下方提供真实 DOM 的“文字节点目录”，按当前图谱排序分页或窗口化显示；它不是隐藏给读屏器的重复 1000 节点列表。
- 目录支持标签搜索、上下方向键移动、Enter/Space 选择节点；选择结果与点击 ECharts 节点一致。
- 图表容器提供简短文字摘要：节点数、当前四档数量、覆盖率、当前选中节点；不得生成新的诊断结论。
- 图例同时显示颜色、文字等级和阈值。节点标签至少显示百分比或等级文字；状态不得只靠颜色。
- 画布按钮有可访问名称和可见焦点；支持 `prefers-reduced-motion`，禁用持续力模拟和大面积动画。
- ECharts 无法承担的键盘遍历由文字目录提供，画布本身仍支持 Tab 聚焦、缩放按钮和恢复视图。

## 9. 加载、空态、失败与恢复

- 初次加载保留画布和 inspector 的稳定骨架，不整页闪空；
- 无考试、未选班级、无学生、无已关联标签、覆盖不完整、节点证据为空使用不同文案；
- warnings 与覆盖率紧邻画布，不能只藏在 tooltip；
- 图表初始化失败时，文字目录和证据摘要若有成功数据仍可使用；
- Graph 请求失败且没有旧成功数据时显示安全错误和重试；有旧数据时保留旧内容、更新时间和“可能不是最新”标记；
- ECharts 组件错误不得破坏 App Shell、筛选器或工作台返回路径；
- 所有错误文案继续脱敏，不显示内部路径、SQL、堆栈、响应原文或学生作答正文。

## 10. 前端数据与组件边界

实现计划可根据最新源码微调文件名，但职责必须保持：

- `KnowledgeGraphView.vue`：页面编排、受控 URL、默认范围和响应式布局；
- `GraphScopeFilters.vue`：考试、班级、学生与应用范围；
- `KnowledgeGraphCanvas.vue`：ECharts 生命周期、图谱/分组树 option、缩放和节点事件；
- `GraphNodeInspector.vue`：节点事实、tag context、error counts 和 evidence 状态；
- `GraphTextDirectory.vue`：文字替代、搜索、分页/窗口化和键盘选择；
- Graph store：范围世代、rows、选中节点、evidence 分页和独立 loading/error/stale 状态；
- `api/graph.ts`：把目前只支持“当前考试 + 班级”的前端请求封装泛化为严格的 P1-21 三种学生范围和三种考试范围，同时保持运行时响应校验；
- 现有 sessions/students API：只为筛选器提供活动考试和学生/班级显示信息，不复制 Graph 聚合。

不得在 Vue 中复制掌握度聚合、覆盖率、错因计数或证据去重公式。前端只做已有数值的分级呈现、布局和范围一致性校验。

## 11. 视觉方向

遵循 `docs/ui/STYLE.md` 的安静教师工作台基线：

- 应用背景 `#f6f7f8`、内容表面 `#ffffff`、主文字 `#20242a`、边界 `#d9dde2`、选择强调 `#2563eb`；
- 掌握度使用克制的成功、信息、警示、危险语义色，并配文字阈值；
- 中文正文沿用 `PingFang SC / Microsoft YaHei / Noto Sans CJK SC`，数字使用等宽数字特性；
- 面板圆角不超过 8px，普通区域不使用强阴影、渐变、发光或卡片海洋；
- 页面视觉重点只有证据带画布，筛选和 inspector 保持教务表格般稳定；
- 草图仅用于验证布局和密度，不是导航名称、业务字段或未来能力来源。

## 12. 1000 节点性能设计

- 使用 ECharts Canvas 而不是为每个节点创建独立 DOM；
- chart 实例只创建一次，数据和模式切换使用受控 `setOption`，卸载时完整 `dispose`；
- 节点位置由稳定输入计算并缓存，同一范围切换 inspector 不重算全图；
- 密集范围下按缩放级别控制画布标签密度，但搜索命中、选择节点和文字目录始终可读；
- inspector evidence 按服务分页，不一次读取全部证据；
- `ResizeObserver` 合并到 animation frame，避免布局抖动；
- 1000 节点合成基准记录初次非空渲染、模式切换、缩放/拖动和节点选择耗时，并保存测试机/浏览器/提交 SHA。基线验收要求无崩溃、无长时间主线程冻结、画布非空且交互结果正确；即时计划在测得共同基线后冻结可复现的回归阈值，不凭空声明通用毫秒值。

## 13. 测试与验收

### 13.1 契约与状态测试

- 前端 Graph 请求覆盖 student/selected/class 与 current/manual/cross_exam 的所有合法组合；
- 运行时校验拒绝非 tag identity、非空知识关系 edges、范围错配、证据错页、非有限数值和多余敏感字段；
- 快速切换范围和节点时旧 rows/evidence 不污染新状态；
- 图谱和分组树的节点集合、选择、覆盖率和 inspector 完全一致；
- 90/75/60 边界值与旧生产分级一致，文字等级和颜色同时存在。

### 13.2 组件与浏览器测试

- ECharts 使用测试适配器验证 option、事件、resize、dispose，不把第三方实现细节写成业务断言；
- Playwright 使用匿名固定种子数据覆盖正常、无标签、覆盖缺失、部分失败、长中文、证据多页和 1000 节点；
- 验证缩放、拖动、恢复视图、图/树切换、节点点击、文字目录键盘选择、证据分页和返回工作台；
- 对画布截图指定区域做非背景像素检查，防止只有空容器；
- 五档桌面视口：1920×1080、1440×900、1366×768、1280×800、1024×768；
- 1024px 下不得隐藏范围筛选、文字目录、节点详情、错误恢复或覆盖率。

### 13.3 数据与安全验证

- 所有 API、组件、浏览器和性能测试只使用临时数据库、合成响应或受控假服务；
- 验证只读请求前后测试双库指纹不变；
- 功能工作区 `user_data/` 必须为空状态；根目录真实两库只读取文件大小、UTC mtime 与 SHA-256 做前后比对，不打开 SQLite；
- 不记录或截图真实学生、考试、路径、密钥或模型内容。

## 14. 回退与非目标

P2-15 是只读前端增量。回退时移除知识图谱路由/导航、Graph 页面组件/store、工作台入口和对应测试，恢复 P2-14 的标签摘要；P1-21 Graph API 保留不动。无 Schema 和业务数据变化，因此不需要数据恢复。

本包明确不做：

- 知识点父子、先修、相关边的创建、推断、编辑、确认、导入或持久化；
- 把 `tag_context.prerequisite` 当作知识关系；
- Phase 4 掌握度 v2、学生画像、排名、预测、趋势或自动建议；
- 训练任务生成、题库标签写入、评分修改、异常处理或 Job 提交；
- 原卷图像下钻、路径访问或当前 Graph evidence 契约之外的敏感字段；
- 从视觉草图、节点距离、标签名称或 AI 文本反向定义业务事实。
