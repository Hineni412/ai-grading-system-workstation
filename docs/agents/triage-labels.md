# Triage labels

| Matt 角色 | GitHub 标签 | 含义 |
|---|---|---|
| `needs-triage` | `needs-triage` | 等待确认优先级、归属和处理方式 |
| `needs-info` | `needs-info` | 缺少用户决定或必要资料 |
| `ready-for-agent` | `ready-for-agent` | 信息和依赖完整，可由独立任务领取 |
| `ready-for-human` | `ready-for-human` | 必须由用户或人工操作处理 |
| `wontfix` | `wontfix` | 已决定不实施，并记录原因 |

标签只表示 Issue 的处理状态，不改变正式执行包状态。
