# 下一版纯知识标准采用组卷网北师大版五册教材路径

下一版纯知识标签以组卷网公开展示的北师大版（2024）七年级上册至九年级上册五册“章—小节—子知识点”目录为一次性主参考，完整保留原有层级和名称，只排除精确标题“回顾与思考”和“复习题”。这一决定替代 ADR 0007 对来源叶子普遍收敛到较粗知识词的做法，但不取消教材归属、能力、解题方法、数学思想、数学模型和特殊题型等其他受控维度。

模型应选择自己能够可靠确定的最深教材知识路径节点；无法确定叶子时回退到最近可确定的上位知识节点，不从父级证据猜测子点，也不重复计算同一份父子证据。外站节点编号和网址只作为来源引用，正式节点仍使用项目稳定身份。

本决定先形成来源快照。当前294个规范知识词、70个活动核心节点及历史证据保持不变；正式启用必须另建版本化知识标准，逐项保存旧词的保留、别名、替代或退役去向，并经过校验、复审和教师确认，不能原地覆盖。
