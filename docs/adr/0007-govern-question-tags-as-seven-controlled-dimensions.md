# 将题库标签治理为七个受控维度，并隐藏保留旧词身份

教材章节、能力和特殊题型使用现有稳定集合，不因本次治理删减。原“思想方法”拆成“解题方法”和“数学思想”；知识点和数学模型按可解释、可复用、粒度稳定的原则收敛。七个正式维度是：教材归属、知识点、能力、解题方法、数学思想、数学模型、特殊题型/考法。

当前只读基础词表保留既有文件名和 `catalog_id`，以兼容本机审核状态；revision 升为 3。规范词从旧版 1288 项收敛为 417 项：教材 25、知识点 294、能力 10、解题方法 23、数学思想 13、数学模型 41、特殊题型 11。知识点不因数量目标机械裁切：保留课程主干、稳定概念、性质、定理和可复用程序，去除题目动作句、重复近义表达和只描述某个来源目录叶子的长句。外部来源快照完整保留。

被合并、改名或降级的名称和 ID 不物理消失。它们分别保存在 `legacy_names` 和 `legacy_ids` 中，只用于读取历史标签、本地检索、候选召回和规范词归并，不作为 AI 可见候选，也不会批量改写真实数据库。历史 `method_tags` 中唯一可判定的思想词可在读取时归入 `thought_tags`；无法唯一判断的历史值保持原样等待后续自然重标或人工治理。

解题方法回答“具体怎么做”，例如换元法、配方法、面积法和构造辅助线法；数学思想回答“用什么通用策略思考”，例如数形结合思想、分类讨论思想和转化与化归思想；数学模型回答“复用了什么稳定数量关系或几何结构”。模型既包括方程、函数、行程、工程等应用模型，也包括一线三等角、手拉手、将军饮马、一点两垂线等在初中教研中含义稳定、可重复识别的命名结构。含义含混、同名异形的网络俗称只保留为别名或隐藏旧词。

新 AI 打标对教材、能力、解题方法、数学思想、数学模型和特殊题型关闭自由造词。知识点也优先使用候选和完整规范词表；只有完全无匹配时，每题最多提出 1 个待审知识词。模型返回的未知方法、思想或模型在本地剔除，不进入正式标签或待审清单。每次任务继续冻结一个词表 revision，失败重试不自动追加模型调用。

本决定不迁移或删除真实题库数据，不改变教材章节身份、能力词或特殊题型词，也不改变 ADR 0004 中“解题证据是标签、训练判定点和评分步骤共同来源”的决定。
