# 题库原卷分值隐藏与只读预览

日期：2026-10-03。用途：记录用户确认的显示与导出方案、验证范围及历史题目只读预览。程序只在呈现副本中隐藏题干分值，数据库、导入、原卷及分析资料保留原文。

## 当前规则

题库题面、组卷预览、训练草稿题干及新生成的普通和训练 Word／PDF，隐藏题干最前端完整的“（数字分）”或“(数字分)”。支持横向空格、小数分值和分值跨多个 Word 字符片段。已知原题号可以位于分值前，隐藏分值时保留该题号。组卷预览不再额外显示原卷分值，也不显示“未标分”。

答案中的分值保留。正文中的数字、分钟、小问编号、计分情境及末尾分值保留。公式、图片、字符格式和段落结构保留。

数据库、原始富内容、原卷、分析输入和冻结题目资料不改写。新导入仍保存原文。历史题目与以后导入的题目使用同一显示规则，无需批量清库、数据库迁移或模型请求。导入代码和作答空间计算函数保持原有行为，不新增存储字段。

作答空间先按原始题干计算，再隐藏显示副本中的分值。普通考试赋分、教师最终分锁、成绩和报告保持原有含义。已有 Word／PDF 文件和历史训练打印资料不重写。

## 实现边界与复用

| 实现位置 | 本次行为 |
|---|---|
| `question_bank/services/rich_content_service.py` | 提供共用的题干文字与 Word 富内容副本处理函数；保存和缓存仍保留原文 |
| `question_bank/services/question_read_service.py` | 对外题面、富内容文字与网页预览隐藏分值；题目身份及修订仍按原资料计算，私有导出读取保留原题干 |
| `backend/api/routers/training.py` | 训练草稿对外题干隐藏分值；递归生成新的公开资料，不改冻结草稿 |
| `question_bank/exporters/paper_docx_exporter.py` | 普通 Word 的富内容与纯文字回退都隐藏题干分值，答案沿用原规则 |
| `question_bank/exporters/paper_pdf_exporter.py` | 普通 PDF 的原生 Word XML 与纯文字转换都使用相同隐藏规则 |
| `question_bank/personalized_papers/rendering.py` | 训练 Word 按显示副本渲染；教师文件的内容核对使用同一题面规则，冻结来源保留原文 |
| `question_bank/personalized_papers/latex_render.py` | 训练 PDF 的 LaTeX 内容隐藏分值，作答空间仍按冻结原文计算 |
| `frontend/src/components/question-bank/AssemblyEditorWorkspace.vue` | 去掉组卷预览额外的原卷分值和“未标分”提示 |
| `tools/maintain_question_bank.py` | 在原位置只读预览显示差异，禁止执行清理 |

没有新增页面、服务、接口或策略层。题库在线读取与普通、训练导出分别使用已有入口，因此必须在这些入口调用同一函数。不能只修改题库列表文字后假定 Word XML 和其他导出路径也已覆盖。

隐藏函数复制段落字典，并从临时 Word XML 中只移除普通文字节点的对应字符。公式节点、图片关系、样式属性和节点顺序不参与替换。只有 XML 而没有独立文字字段的导出资料同样支持处理，临时识别文字不写回资料。

训练 Word 的内容核对仍检查冻结题目的其余完整内容和题序。显示隐藏不改变原始题目、来源指纹、判定点来源校验、冻结快照或保存回执。

## 预览工具

在项目根目录执行：

```powershell
.\runtime\python\python.exe tools/maintain_question_bank.py source-scores
```

输出只包含匿名计数、分值标记差异、富内容结构核对、原文作答空间保留数量和已有分析记录数量。该命令不复制数据库，不保存题干正文，不调用模型。`source-scores --apply` 拒绝执行，不进入其他维护操作的复制或写入流程。

## 验证范围与限制

扩展现有题库 API、训练 API、组卷导出和组卷页面测试，没有新建测试文件。边界输入覆盖中英文括号、空格、小数、格式标签拆分，以及保留小问编号、分钟、公式、正文计分情境和末尾分值。

合成 Word 完整流程核对新导入保留原分值，在线显示隐藏分值，普通 Word／PDF 和训练 Word／LaTeX 隐藏题干分值。答案分值保留，原生公式、图片、字符格式和 8 行作答空间保留。训练 Word 通过内容与题序核对，冻结快照、分析输入、数据库及富内容文件保持原样。

普通 PDF 测试使用本机编译器生成文件并检查文本、表格、图片和页面边界，覆盖纯文字公式及只有 XML 的资料。前端测试核对题面组件及组卷预览额外分值标签去除。既有导入、重复题、任务、缓存和训练流程按影响回归。

没有调用真实模型，没有修改真实数据，没有重写历史文件。本次未启动或重启正式服务，也未进行纸张实打印；验证结果不等同于真实纸张打印验收。
