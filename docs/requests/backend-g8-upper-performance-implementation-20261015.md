# 八上读取优化与验证

日期：2026-10-15。用途：记录用户选定的五项工作的实现、同输入对照和验收边界。本文是请求记录；当前模块与存储规则分别见 `ARCHITECTURE.md` 和 `docs/maintenance/storage-policy.md`。

## 实现范围

本轮按顺序修改显示诊断、候选去重、掌握度组装和试卷评价，再验证八上整页。四处实现都是通用读取路径，没有按八上硬编码。评分、掌握度模型、原题排除、去重和教师最终分规则保持原意。

| 项目 | 实际改动 |
|---|---|
| 显示结果重复加工 | 先选取显示模式返回的字段，再遍历清理、检查数值和验证响应；不再完整遍历随后丢弃的证据 |
| 候选判重复用 | 在现有 `question_identity.cache` 保存整题去重标识和图片标识，以已有题目版本、更新时间和精确去重标识判断复用；批量读取、批量保存，不新增缓存文件种类 |
| 掌握度结果组装 | 用已有来源版本、范围、周次、参数和排除条件组成缓存键；不再遍历全部观测生成第二套键。章节层级信息每次组装只准备一份，学生结果不再经过完整对象转字典 |
| 试卷评价章节统计 | 复用已有整册统计；整册统计缺失时，只组装评价涉及的小节。整册试卷分组和统计分母仍保留，不把局部统计冒充整册统计 |
| 八上整页验证 | 使用同一份当前前端构建，对照修改前、修改后的后端；覆盖首次进入、学期切回、切班和副本更新后刷新 |

候选标识首次缺失时仍要计算。已经算过的标识才能减少后续整池重建中的正文和图片读取。标识只服务去重与原题排除，读取过期判断继续使用已有版本，不新增内容指纹检查。

## 后端同输入对照

基准是本轮开始时、已完成上轮七项优化的代码。脚本保存基准源码，不切换 Git，也不更改真实数据。每个冷读样本使用新进程；关闭主要结果磁盘缓存，保留现有基础去重标识。计时不含进程启动和模块导入，也没有清空操作系统文件缓存。

显示诊断与概览使用八上全部学生和三场考试。显示结果包含 91 名学生、4,547 条考试作答记录和 41,029 个“学生×知识项”条目。最后一个数量不代表独立薄弱点数量。

| 读取 | 修改前中位数 | 修改后中位数 | 样本与解释 |
|---|---:|---:|---|
| 显示诊断 | 8.704 秒 | 6.877 秒 | 各 3 个新进程；减少 21.0% |
| 掌握度概览 | 6.244 秒 | 5.392 秒 | 各 3 个新进程；减少 13.6% |
| 试卷评价 | 7.556 秒 | 6.314 秒 | 各 3 个新进程；减少 16.4% |
| 有效候选池，整题标识未建立 | 5.548 秒 | 5.416 秒 | 各 3 个新进程；基本持平 |
| 全量候选池，整题标识未建立 | 10.220 秒 | 10.452 秒 | 各 3 个新进程；本轮未证明首次加速 |
| 有效候选池，整题标识可复用 | 5.548 秒 | 3.333 秒 | 后者为 3 个新进程复用标识，整池仍重建 |
| 全量候选池，整题标识可复用 | 10.220 秒 | 3.639 秒 | 后者为 3 个新进程复用标识，整池仍重建 |

前三项取 `paired-reads.json`；候选最终结果取批量读写完成后的 `paired-reads-candidates.json`。两批测量的机器负载不同，不能混用它们的候选绝对耗时。本轮同一读取的单次耗时也有明显波动，表中不是速度保证。

所有对应完整结果的校验值一致。校验值仅用于这次实验比较，不加入正式读取逻辑。标识复用实验把新标识通过进程间内存传递，避免向真实缓存写入；实际磁盘保存和重新加载另用合成数据验证。

缓存命中追加验证使用两轮交替顺序，每侧每个读取共 50 次。显示诊断中位数从 0.0972 秒到 0.1006 秒，概览从 0.0450 秒到 0.0455 秒。有效候选池、全量候选池和试卷评价的命中中位数分别约 0.045、0.150 和 0.007 秒。没有秒级命中回退，但不将毫秒差异表述为零退化。

现有整池磁盘缓存的新进程命中单次从 0.253 秒到 0.282 秒。显示诊断和概览的新进程单次分别从 7.135 到 5.332 秒、3.931 到 2.940 秒；这两项只复用了部分基础缓存，并非完整响应命中。

“所有首次读取低于 1 秒”和“首次耗时压到原来的 10%”尚未实现。当前收益来自少做重复工作，没有降低计算精度，也没有把后台刷新视为计算完成。

## 八上整页对照

以下为各一次浏览器样本。计时从导航开始，到当前范围的页面内容可见且没有加载或后台刷新状态；两侧使用同一份前端构建。服务启动时间不在表内。完整页面包含多个接口、响应解码和绘制，不能用后端单项时间代替。

| 页面首次进入 | 修改前 | 修改后 |
|---|---:|---:|
| 掌握度概览 | 8.078 秒 | 8.018 秒 |
| 出训练 | 11.313 秒 | 9.262 秒 |
| 题库章节考情 | 6.504 秒 | 6.169 秒 |
| 题库按标签 | 9.397 秒 | 9.499 秒 |

训练页本次缩短 18.1%。概览首次进入基本持平，标签页没有加速。章节考情与标签页的完整读取不走试卷评价的局部小节分支。本轮不是前端启动链改造，也没有证据证明五页均稳定加速。

概览第一次切班从 2.858 秒到 2.488 秒，训练第一次切班从 4.140 秒到 3.467 秒。修改后，概览与训练切回已查看班级为 0.079–0.098 秒；从其他学期切回八上为 0.061–0.107 秒，均未重新请求核心结果。章节考情切回八上为 0.136–0.157 秒。

副本更新实验把一名学生的 53 条作答记录及对应最终分锁改为零分，再由页面重新读取。更新后的完整结果与清空测试缓存后的重算结果一致；修改前、修改后页面取得的完整响应也一致。该实验验证缓存失效，不替代正式教师改分操作验收。

| 副本更新后刷新 | 修改前 | 修改后 |
|---|---:|---:|
| 掌握度概览 | 6.651 秒 | 8.213 秒 |
| 出训练 | 13.192 秒 | 10.734 秒 |

概览刷新样本更慢，不能宣称该操作已提速。五页均无页面异常或错误面板。另有范围边界：章节考情首次切到七下用了 8.845／10.039 秒；“当前没有考试”不等于题库章节资料为空，空考试快速返回不能保证该页面秒开。

## 回归与边界

后端 `full --skip-frontend --workers 4` 执行 102 个现有用例，全部通过。批量身份缓存最后调整后，12 个推荐用例再次通过。独立合成实验验证了 11 个候选的标识保存、重新加载、题目更新后失效，以及更新后的缓存结果等于强制重算结果。

没有增加、删除或修改测试。测试文件数为 22→22，函数数为 113→113，参数化展开的后端收集数为 114→114。114 是全部收集数，不是本轮执行的独立用例数。前端未修改；构建写入实验目录，没有覆盖共享构建来完成浏览器对照。

真实数据库的文件状态在测量前后保持一致；所有完成样本的越界写入或外网尝试数为零。没有调用真实模型。实验过程中修复了脚本变量、弹层点击顺序，以及只读保护误拦测试副本 WAL 快照的问题；这些修复没有改动正式应用逻辑。

收尾已删除本次创建的数据库副本与合成数据，回收约 56.5 MiB。确认正式端口未运行、没有活动任务或待执行维护后，已用 `运行.bat` 启动当前版本；`/api/healthz` 返回正常。整页对照来自隔离测试服务，正式服务只做了短时限健康检查。

剩余重点是概览刷新、页面启动与多接口等待、首次班级计算，以及整题去重标识尚未建立时的候选池重建。缩短这些读取仍需同输入验证，不能用预热或展示旧结果替代首次完整结果达标。
