实施目标：数据库和已保存文件，在哪里存就在哪里直接读。业务结果的查看和统计不计算整题、整库识别码，不按分析版本筛掉旧结果。每项结果一份，需要更新只提醒。

## A 已确定的保存规则

1. **有保存内容就直接读取。** 查看和统计取消整题、整库识别码比较，取消分析版本门槛。数据库读数据库，报告文件读原保存文件，不为这个目标先搬库。
2. **每项结果只保留一份。** 同一份报告、同一项归类不再保留多份可选择的历史结果。不同考试、学生、题目和训练各自保存，不互相覆盖。
3. **旧结果继续使用。** 已存错因继续参与统计。系统升级、补题面、补解析或修改标签，不让已有结果消失，也不变成“未归类”。
4. **需要更新只提醒。** 保留生成时间和简单的改动标记。提示“不是最新，仍可使用”，不比较版本号，不阻止打开或统计。
5. **更新成功才替换。** 新结果保存成功后替换原结果。重新生成失败时，原成功结果保持原样。普通查看和统计不调用模型。
6. **保留下载后回收。** 沿用现有自动回收的文件范围。实际回收后显示“文件已清理”。已保存的正文、成绩和归类不跟着清空。

```callout info 实施状态
代码与对应文档已实施，本机应用已更新。原地只读核对中，3场考试保存的1998条错因记录全部读回，2份班级正文和88份个人正文可读。更新后的应用也已打开旧班级正文和个人正文，默认复用、勾选更新的预估与取消恢复均通过。验收前后保存文件的路径、字节和修改时间不变，数据库文件未变。本轮未删除、迁移或批量修改已有数据，未调用真实模型。刷新应用页面即可使用。
```

## B 这次移除的读取比较

旧错因被屏蔽的原因已经核对。原先程序把题面、解析等资料算成一串识别码，再比较是否变化。原来缺少的资料补齐后，整题比较失败，读取入口便跳过已有归类。此前核对的学生评分信息没有变化，旧归类仍保存。本次代码已取消这条拦截。

原先部分学情与题库检查会读出完整题库；另一段检查会遍历业务表，再计算识别码。本次代码已移除这些读取比较。原实现有临时复用，并非每次请求都读取整库。

本轮用内存测试库运行了现有函数。只修改另一张表，选定的成绩没有变化，两段整库比较的结果仍改变。这个实验确认了比较范围，未测量真实页面延迟。尚不能断言后端慢主要由它造成，也不能给出提速比例。

当前代码见[错因读取](../../backend/class_analysis.py)、[读取改动检测](../../integration/data_generation.py)和[学情缓存读取](../../integration/diagnosis_profile_service.py)。

## C 各个地方采用同一规则

下表是本次采用的统一规则。核心代码与对应测试已完成，本机应用页面验收已通过。

| 数据 | 统一后的行为 |
|---|---|
| 成绩、教师确认分、名册和考勤 | 已保存内容正常读取。教师确认分仍优先。 |
| 错因、典型错误和选项解析 | 已存内容可看。已有错因继续统计，不因资料补充或系统升级变成未归类。 |
| 个人报告和班级报告 | 每份报告保留一个成功结果。旧正文可看。更新失败不清空原正文。 |
| Excel、批注 PDF、错题本、讲义和报告包 | 文件仍在就可下载。现有下载后回收设计保留。清理后写明“文件已清理”。 |
| 推荐草稿和试卷篮 | 保存内容可以打开。标签或组卷方法改变只提醒，不跳过已存草稿。 |
| 题框草稿、题目解析和评分资料 | 保存内容可找到。查看不自动搬走原文件。采用时确认属于当前试卷。 |
| 已发训练卷、作答、判定和反馈 | 每次训练保存自己的完成结果。之后题库调整不抹掉已有作答和反馈。 |
| 掌握度、班级学情和组卷统计 | 继续读取已保存的考试与训练结果。无法对应当前标签名称时，保留原名称展示，不当作没有作答或没有归类。 |
| 题库、知识标准、技能候选和分析结果 | 每个对象保留一份采用内容。已完成的考试和训练各自保存自己的资料。 |
| 以前保存的任务资料、普通设置和模型配置 | 兼容读取已有内容。读取失败写清原因，原文件留在原处，不显示成“未保存”。 |
| 临时计算结果、近期筛选记录和诊断日志 | 取消反复比较整库内容。检测到数据库或相关保存文件发生写入时，刷新所选范围的临时结果；已保存业务结果仍直接读取。数据库内其他写入也可能触发刷新。 |

“一份”按具体对象区分。一名学生两次考试的结果是两条不同记录，各自保留。答卷、报告和教师改分记录有各自用途，不互相替代。已有备份继续按原规则保存。

统计仍遵守原有考试、学生、题目和失分范围。同一个结果不会重复计入。教师改分不会被旧页面或模型结果覆盖。

报告需要说明生成时间和成绩范围。以后生成的报告，正文与成绩表应使用同一次生成时的数据。早期报告未保存原成绩表时，旧正文照常打开，页面说明“成绩表为当前成绩”，不冒充当时的完整报告。

## D 从哪里开始实施

先记录现状，再从共享错因读取入口开始。这个入口同时影响报告、学情和组卷。修正共享入口后，逐一验证调用它的页面，避免每个页面另写一套规则。

| 顺序 | 实施内容 | 完成条件 |
|---|---|---|
| 1 记录现状 | 核对已保存错因、个人报告、班级报告、班级组卷和学情。记录能够安全只读的页面耗时。 | 明确哪些内容已保存却未显示。耗时未知就标明未测，不推算提速。 |
| 2 修正读取 | 取消错因、报告和导出入口的整题比较与分析版本拦截。文件仍在就允许下载。按保存归属打开旧报告。 | 补资料、改标签或升级后，已有错因仍统计。旧正文与可用文件能打开。成绩和教师确认分不变。 |
| 3 统一保存 | 每项结果只保留一份成功内容。成功更新才替换，失败保留原结果。提醒与保存状态分开。 | 用模型替身验证成功、失败和再次打开。失败不清空旧正文，提醒不调用模型。 |
| 4 草稿与训练 | 兼容已有草稿和解析资料，读取不搬走原件。训练卷、作答、判定和反馈按保存内容读取，已有作答继续纳入学情。 | 草稿能恢复；旧归类与训练作答不因题库调整变成缺失；同一记录不重复计数。 |
| 5 简化统计 | 去掉学情和题库读取中的整库比较。按当前选择查询和汇总；相关数据修改后刷新相应临时结果。 | 相关改分、错因整理和题库修改能更新统计；无关范围不参与本次汇总；数据库内其他写入可能使临时结果重算，保存保护仍有效。 |
| 6 验收与收尾 | 重走错因、报告、文件中心、草稿、班级组卷和训练入口。用同一数据比较首次与重复打开。更新受影响的正式文档。 | 每个入口符合相同规则。明确实际耗时与尚未验证项。现有下载后回收范围保持原样。 |

每一步完成后先验证，再继续下一步。修复旧错因缺失后，已归类人数可能恢复增加，这是预期修复。性能阶段按同一修正口径比较，不能把旧入口少读数据当成更快。

继续复用现有错因读取、报告结果保存、文件中心、草稿与训练读取、学情统计模块。本方案不新增通用版本管理服务或另一套数据存储。

测试优先扩展各模块已有用例：错因与组卷、报告保存与导出、草稿恢复、训练作答与掌握度、题库与学情缓存。验证保存和生成失败时使用隔离数据与模型替身；纯文案和布局不新增业务测试。每一步核对教师确认分、对象归属和重复提交保护。

正式实现使用本地 main。本轮与知识训练合并、关键步骤显示共同修改部分文件，按协调约定保留未提交改动，避免混合提交。之后每次提交只包含已核实的任务内容。改动产品规则、数据归属、术语、存储或测试入口时，同步更新对应正式文档。已有真实数据保持原样；若必须清理重复文件或执行数据库迁移，先准备精确目标、备份和回退清单，再按项目授权规则处理。

## H 直接读取，怎样保持快且不写错

**查看保存结果。** 直接查询这份结果属于哪个考试、学生和题目，读取保存内容。不先扫描全部数据库，不比较整份资料，不按分析方法新旧拒绝读取。

**班级统计。** 按所选考试、班级、学生和题目查询，再做必要汇总。选择、填空使用整题作答结果，解答题使用逐点结果；训练按达成点数与总判定点数统计。数据库有原始记录时仍需要汇总，但只处理本次所需范围。

**重复打开。** 可保留一份临时汇总，避免每次重算。程序使用数据库和相关文件的简单写入信息，判断是否需要刷新所选范围的临时汇总。程序不读取整库内容来判断。数据库内的其他写入，包括任务进度，也可能触发刷新；因此目前仍可能重复汇总，但不会永远沿用旧统计。

**提醒需要更新。** 用生成时间和“相关内容改过”的简单标记。系统更新分析方法时，只提醒受影响的结果。普通界面调整不把所有数据标成旧数据。早期记录没有可靠时间时，显示“已保存”，照常使用。提醒不触发模型调用。

**保存与恢复。** 保留学生、题目和试卷编号，保留教师确认分优先，防止旧窗口覆盖新分数，防止重复提交把同一结果保存两次。保存是否完整、备份能否正确恢复，仍按现有规则检查。旧格式由程序兼容读取。这些保护不作为旧报告或旧错因能否打开的门槛。

**速度验收。** 改造后用同一页面、同一数据与同一筛选范围对比。分别检查第一次打开和重复打开，并确认成绩、错因人数和推荐结果没有因提速而少读数据。本轮未做真实页面耗时对比，尚未证明整体提速。

已有真实数据如果存在多份，先确定当前采用的成功内容。清理前列出精确文件或记录、备份和回退办法，单独获得本次清理授权。本轮不执行清理。

隔离测试已验证：补资料后旧归类继续统计；旧报告和草稿兼容读取；更新失败保住原结果；成功更新替换当前成功内容；保存与恢复保护仍正常。下载回收沿用原规则，未对真实文件执行回收验收。正式应用只读验收已打开旧报告并核对整理预估，本轮没有实际调用模型更新真实报告。整体页面提速仍未做前后对比。
