说明 · 本原型为静态演示（合成数据），用于比较工作台首页的三种版式；点这里收起
  • 用途：比较工作台首页改版效果。全部使用合成样例数据（考试名、题型名都不是真实数据）；点击页面中的任何按钮只弹出小提示「原型：将进入 …」，不会跳转、不改数据。底部悬浮工具条切换「版式 / 场景 / 宽度」，刷新后保持。
  • 版式「现状」：与当前正式首页一致，供对照。
  • 版式「第1档整理」（改动 5 条）：
    　1）待处理面板改名「需要处理」，标题数字只算必办事项（复核、答卷异常、继续批改、上传、配置、补题库资料、训练核对/复核/发布）；正在运行的任务单列一组、不计入数字；必办为 0 时收成一行绿色提示。
    　2）「看卷 10 分钟」「按失分题组讲义」从待办移入当前考试卡，且只在当前考试是最新一场时出现。
    　3）考试全部完成后，5 个步骤收成一行「✓ 已全部完成 · N 份答卷已批改」，点「查看步骤」可展开原步骤；卡内按钮：成绩中心（主按钮）、看卷 10 分钟、按失分题组讲义（后两个限最新一场）。个人报告需重新生成时在卡内提示一行，不受场次限制。
    　4）最近考试表：合并「批改+状态」为「进度」列（全部完成显示「✓ 已完成」，否则进度条+份数，有待复核加黄色标签）；去掉「当前」徽标，改用浅色底+左侧色条标当前行；每一行都有「看成绩」。
    　5）窄屏（约 1100 宽）：需要处理占满宽 → 当前考试卡与学情卡并排 → 最近考试占满宽；步骤只在卡片宽度内显示。
  • 版式「第1档+平均得分率」：在第1档整理基础上，最近考试表加「平均得分率」列（表头标注样例数据），显示与上一场相比的增减；悬停可看到口径说明。
  • 尚未实现：以上全部是原型，正式页面未做任何改动；「平均得分率」列需后端在最近考试数据中新增字段后才可实现。
