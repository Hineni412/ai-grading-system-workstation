# 扫描姓名匹配的本地校验需求记录

用途：保留用户提出的校验需求。当前实现与操作规则以 [考试阅卷说明](../product/GRADING.md) 为准，以下为原始需求范围，不作为独立功能说明。

用户要求：姓名自动匹配出现串人时，除了纠正当前匹配，后续应增加本地验证程序兜底。

原始检查要求：

- 同一考试中，同一学生对应多份不同答卷时，预检显式提示冲突；不能只按学生编号去重后显示“人数正常”。
- 显示扫描答卷数、有效匹配数、唯一学生数与未决异常数，并校验这些数量能相互对上。
- 将卷面班级、所选班级与学生名单中的班级用于匹配核对；不一致时提示确认，不自动串班。
- 更正误匹配时保留原学生本人的答卷，只调整误挂答卷的归属；重新核对缺考统计。
- 批改前再次验证最终匹配；存在未解决的重复归属时，先处理相关答卷，不能悄悄丢弃或覆盖成绩。

实现时优先复用现有扫描预检、人工匹配决定与批改计划。使用合成数据验证重名、误识别、重复扫描及纠正后的成绩归属，不把真实答卷写入测试夹具。
