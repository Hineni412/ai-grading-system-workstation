# 任务中心改版原型（已选方案：胶囊+浮层面板）

方案一的参考原型，供正式实施时对照。全部使用合成数据，无后端、无构建步骤，
不连接应用内的任何代码与真实数据。

## 打开方式

在本目录启动任意静态服务器，例如：

```
py -3 -m http.server 8098 --bind 127.0.0.1
```

然后访问 `http://127.0.0.1:8098/index.html`。顶部深色控制条只属于原型：
「模拟」按钮发起各类后台任务（AI 任务会先弹确认对话框），「速度 4×」加快
进度，「清空模拟」重置。

## 文件说明

- `index.html` — 页面骨架：控制条、假应用侧栏与页面区、挂载点。
- `proto.css` — 设计令牌与外壳样式（令牌值抄自 `frontend/src/styles/tokens.css` 与 `app-shell.css`）。
- `variants.css` — 已选方案样式：环钮胶囊、浮层面板、完成通知卡片。
- `data.js` — 任务模板（名称、时长、阶段、结果、去向页）与假页面内容。
- `engine.js` — 模拟引擎：任务状态、进度推进、取消、已读与自动移出规则。
- `shared-ui.js` — 共用渲染：胶囊、任务条目、分组列表、完成通知卡片。
- `task-center.js` — 已选方案挂载：环钮胶囊 + 360px 浮层面板。
- `shell.js` — 假应用行为：侧栏导航、发起任务的确认/进度/结果对话框、轻提示。
- `app.js` — 启动：挂载方案并接管模拟控件。
