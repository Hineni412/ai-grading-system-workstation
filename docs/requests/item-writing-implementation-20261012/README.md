## 1. 已确认的决定

| 问题 | 决定 |
|---|---|
| 使用者 | 用户本人，单人练习 |
| 训练形式 | 读一份材料，按八步分维度作答，命一道题；对应基本功大赛的现场命题环节 |
| 作答输入 | 能点选的点选，能填写的填写；题干、答案可上传 Word、PDF、图片识别后核对 |
| 评价 | 本机自检免费即时；AI 评价每次确认费用，含题目分析、独立解题、量表评分三个请求 |
| 量表 | 九维、百分制，权重与水平描述按原型 `rubric-data.js`，不改 |
| 材料 | AI 从题库题目抽取原生情境，舍弃具体题目、数值与设问；教师审核后可用 |
| 存储 | 复用题库中保留的四张 authoring 表，并做一次迁移扩充 |
| 作品去向 | 默认与真卷隔离；教师确认后可转入正式题库 |
| 时限 | 默认 60 分钟，计时期间不强制锁定资料 |

## 4. 模块归属与跨模块改动

命题训练属于“题库、组卷与知识训练”模块：代码放 `question_bank/authoring/`，数据在 `question_bank.db`。页面挂在教研提升（`frontend/src/views/TeachingResearchView.vue`），这是页面层组合，不改变试卷评价（考试模块）的接口。

需要改动的共享热点文件只有：`backend/api/app.py`（挂载路由）、`backend/api/routers/__init__.py`、`backend/api/dependencies.py`（服务装配）、`backend/jobs/default_handlers.py`（注册任务）、`TeachingResearchView.vue`（页签）。旧功能的挂载方式可参考 `git show fb6a4648`（删除旧命题练习的提交），按当前代码重写，不整段恢复。
