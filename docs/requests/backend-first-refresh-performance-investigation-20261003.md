# 页面首次刷新性能调查

用途：保留首次刷新与两秒目标调查的证据边界和未验证事项。下列数字是注明输入条件的历史样本，不代表当前代码性能。当前运行机制以 [系统架构](../../ARCHITECTURE.md) 为准，回归入口以 [测试说明](../testing/README.md) 为准。

## 测量口径

调查分别记录页面结构出现、完整数据可见、模型计算、公开响应整理与浏览器绘制。后端单项耗时不能相加后当成整页耗时。首次无缓存、已有快照恢复、同进程再次读取和业务数据更新后重算必须分别比较。

2026-10-03 的合成浏览器样本中，准备完成后的知识概览、知识图谱与训练诊断首次完整加载达到两秒目标。相同专项中，无有效缓存或更新后立即重算仍未达到目标；正式服务的真实输入整页目标未验收。

2026-10-04 的首章样本使用本学期 91 名学生，无已有快照、无预热，首次整页可见为 26.37 秒，同轮完整响应缓存命中为 1.13 秒。两章合卷在候选已准备、但跳过完整分组响应缓存时，后端分组样本为 21.53 秒。各值是不同条件的单次样本，不是当前版本的固定指标。

后续已经调整了预热、所选小组复核和推荐内部复用。最新实现、输入范围及比较方法见 [训练推荐交接](training-recommendation-backend-handoff-20261004.md)。原始详细记录仍可从 Git 历史读取。

## 已确认的调查方向

- 来源准备：相同考试、班级和题目资料反复准备会放大首次请求成本。
- 候选计算：原题身份、适用范围、任务匹配和整卷限制须使用同一输入比较。
- 公开响应：完整逐题证据的清理、校验、编码和浏览器读取本身也有成本。
- 失效规则：同等业务内容的 WAL 归档不应制造业务更新；真正改分、题库写入和训练证据发布必须重新核对。

这些方向已有部分实现，不能据旧剖析断言当前仍有同样的热点。当前缓存位置和保留规则见 [存储说明](../maintenance/storage-policy.md)，备选方案及尚未实现的条件见 [优化方法调查](training-recommendation-performance-options-20261004.md)。

## 尚未验证的范围

- 当前版本在真实题目更新、新增作答后，完整 HTTP 响应和浏览器可见时间。
- 大批上传或中断恢复中的批改页面。
- 用户曾描述的长期整页空白；早期调查没有稳定复现其原因。
- 没有有效快照时，三个知识训练页面在真实输入上的完整两秒目标。

首屏摘要与逐生证据分开读取仍属于待论证方案，会改变接口及页面契约，不能当成本次已经实现的行为。来源输入的增量复用也必须保持全年级拟合、完整输出、来源校验和教师最终分锁。

## 可复用的证据与限制

早期匿名测量位于本机 `output/test_backend_perf_implementation_20261003/`。源码仓库不包含这些测量文件，也不包含原始业务响应。新验收应在固定输入和相同环境下比较当前代码，记录首次、命中、更新后重算，并分别报告后端和浏览器耗时。

调查没有调用真实模型，没有复制或修改真实数据库。既有真实只读样本只能说明被测输入，不能替代打印、正式出卷、评分保存、模型质量或学习效果验收。
