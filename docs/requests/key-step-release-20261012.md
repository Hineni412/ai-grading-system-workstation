## 3. 代码规则（已实现）

- 补挂任务与内嵌挂接写入：客观题点不写关键步骤；每个判定点只保留一条直接关键步骤；补关键步骤时不再把客观题点发给模型。挂接提示词同步说明这两条。
- 关键步骤缺口：客观题点不算缺口；只有含非客观题点且没有任何关键步骤的题才算“缺关键步骤”。
- 题目小节归属（`question_scope_summary`）不再计入关键步骤链接。
- 考试步骤诊断：冻结快照中的旧标识按当前标准的替换关系显示现名；冻结快照一点挂多个时，参考题库当前同版本的主关键步骤。成绩、排名与冻结文件不变。
