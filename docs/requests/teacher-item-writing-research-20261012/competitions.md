# 初中数学教师命题比赛与命题人员遴选调研

调研日期：2026-10-12。用途：为教师命题训练系统确定训练任务形式与评审维度。官方命题文件见同目录 [zhongkao-standards.md](zhongkao-standards.md)。引号内为原文摘录，每条附来源。比赛通知属地方教研机构或学校发布，只代表该次比赛的规则。

## 一、比赛形式

### 1. 提交整卷、专家盲评（常州市教科院，2020）
来源：https://jky.czedu.cn/html/article5577606.html
- 命题内容按任教年级：七、八年级命本学期期中卷，九年级与教研员命「初中数学学业水平模拟试卷」。
- 题型分值参照指定样卷；「难度系数：大市样本 0.7-0.75」；「简单题、中档题和难题分值比大致为 7:2:1」。
- 「原创题或改编题的比例不低于 20%，原创题和改编题请在命题简要细目表后给出立意说明。」
- 提交顺序：「试题、评分标准、命题细目表、原创和改编试题立意说明」；文档「不出现学校和姓名」；「组织相关专家进行盲评」。
- 命题原则四条：科学性、基础性、人文性、创新性。

### 2. 校、区、市三级选拔（常州第二届原创性命题比赛，2024）
来源：https://jky.czedu.cn/html/article6089674.html
- 「经过校、区、市三级选拔评比，由教科院选聘的专家评委进行盲评。」
- 区级比赛按学校规模限额推荐（天宁区 2026：「8轨及以下学校提交 3份、9轨及以上学校提交 6份」），作品含「命制的试题、参考答案及评分标准三部分」。来源：http://www.tn.czedu.cn/html/article6983869.html

### 3. 现场闭卷命题 + 说题 + 答辩（深圳大学附属教育集团青年教师基本功大赛）
来源：https://c.460.net.cn/a/578047.html （集团新闻转载，二手）
- 第一阶段：限时完成一套初中数学综合能力测试题（解题），晋级者「围绕给定主题或教材内容，现场闭卷命制一道原创试题（含选择题或解答题），并附上参考答案、评分标准及命题说明。教师只能携带教材、课程标准和文具」。
- 第二阶段：「在10分钟内进行说题，清晰地阐述试题的命题意图、解题思路、教学建议及试题价值」；评委「围绕试题设计、数学思想方法、学生典型错误及教学策略等方面进行3分钟提问」。

### 4. 全国命卷大赛的量化要求（学科网杯 2026，企业主办）
来源：https://news.zxxk.com/article/1098936.html （二手性质：企业比赛，规则仅适用该赛）
- 初中全卷难度系数建议 0.6–0.7；结构「基础题60%-70%、中等题20%-30%、拓展题10%」。
- 「减少机械记忆类试题占比（不超过10%），提高应用性、探究性、开放性、综合性试题占比（不低于20%）」；原创题不低于总题数 10%，并在题干前标注。
- 主观题须给「详细评分细则、分等级答题示例」；双向细目表「必须包含考查知识点、题型、分值、难度系数四个维度」。

### 5. 说题比赛评分（唐县教研室，2026）
来源：http://www.bdtxjys.cn/xiangqing_2/356.html
- 100 分：整体结构完整性 30、解题研题专业度 25、变式与模型建构 20、团队协同展示效果 15、教态语言与创新亮点 10。

## 二、评委总结中的常见失误
- 常州 2020：「部分参赛试题内容不完整，没有评分标准，缺少双向细目表；原创题和改编题的数量和质量不高，拼卷的比例很高；有的试题科学性欠缺，代数和几何的比例与学时比差距明显，试题的阅读量没有与考试时间合理匹配」。来源：https://jky.czedu.cn/html/article5577771.html
- 常州 2024：超出初中内容和学业要求；三大领域「分值也出现了比例失调」；情境「比较单一，或是生搬硬套」；缺指导语，「版式、图表、公式、符号、单位等也有不符合国家标准的情况」；主观题缺明确评分标准。来源：https://jky.czedu.cn/html/article6089674.html
- 天宁区 2026：内容集中在图形与几何；跨学科情境过度依赖其他学科知识；「仅对原题进行数据替换或题型微调，缺乏原创性」；「新定义题型存在描述不清、区分度不足等问题」。来源：http://www.tn.czedu.cn/html/article7071931.html

## 三、命题人员遴选与培训
- 玉林市中考命题人才库：候选人培训内容含「教育测量理论、命题技术、考试质量分析、保密规定」；「命题人员库候选对象须按命题程序和要求……独立命制一定数量的试题，并提交作为考核依据；审题人才库候选对象要对提交上来的试题进行评审，提出审题意见」。条件含「具备学科独立命题的能力……特别是对创新性、开放性及探究性试题的命制有独到见解」。来源：http://edu.yulin.gov.cn/xxgk/zc/wjzl/t1349403.shtml
- 安徽省级命题专家库推荐条件：教龄 8 年以上、高级职称为主，「承担过县（区）级及以上教育部门组织的统一考试命题工作」。来源：https://fz.ahnu.edu.cn/info/1156/10733.htm
- 深圳市教科院 2023 初中数学命题能力提升培训：理论自学、专家授课、「现场命题实操」；分组三天命制一份中考模拟卷，展示「试题多维细目表」与代表性解答题，专家点评。命题方向「育人性、情境性、应用性、探究性、开放性、综合性、科学性和创新性」。来源：https://mp.weixin.qq.com/s/8671Jow3BbqzLV90WIMFBg （公众号，二手）

## 四、对系统设计的含义
- 比赛有两种主流形式：提交整卷后盲评；现场限时命一道题，再说题、答辩。两种都要求「试题 + 答案 + 评分标准 + 细目表 + 命题说明」五件套。
- 量化门槛反复出现：难度系数区间、易中难 7:2:1、原创或改编比例、领域比例、题量与时长匹配。
- 选拔类评审看重的能力还包括「审题」：遴选审题人员时要求对他人试题提出审题意见。
- 未查到公开的官方评分细则。系统内置的评分表是综合以上来源的建议，比赛前应按该次通知调整。
