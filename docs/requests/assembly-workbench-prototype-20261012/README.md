# 组卷工作台改版原型

组卷工作台改版的参考原型：两栏「班级组卷」+ 共用「试卷篮抽屉」+ 新增整页「整卷预览」+「整理与导出」两种结构方案（A 在卷面上直接排 / B 卡片墙 + 卷面）+「题库管理（示意）」。全部为虚构数据，未接后端、无构建步骤、不读取应用内任何真实数据。

## 打开方式

在本目录启动静态服务器（任何空闲端口均可，例如 8099）：

```
py -3 -m http.server 8099 --bind 127.0.0.1
```

然后访问 `http://127.0.0.1:8099/index.html#class`。

顶部深色控制条只属于原型：三个视图页签直接切换；「模拟后台重算」演示范围条右侧的小状态胶囊（后台更新中… → 已更新），不再出现整页横幅。「整理与导出」视图底部胶囊或 ← → 键切换方案 A / B，地址栏 `?variant=` 同步。

路由：`#class`（班级组卷）、`#preview`（整卷预览）、`#export?variant=a|b`（整理与导出）、`#bank`（题库管理示意）。

右栏「这张卷」已并入试卷篮抽屉：右缘开关、页头「试卷篮 · N」或 B 键打开，推开页面约 1/3 屏；抽屉复用整卷预览的卷面与题号轨道（可拖拽排序），出卷设置移到「整理与导出」的试卷设置面板；`#preview` 与 `#export` 不显示入口并自动收起抽屉。

左栏「要补的点」筛选改版：章节多选、排序（薄弱人数 / 原题得分率 / 区域常考）、只看未配题；得分率门槛收进「更多 ▾」，行内药丸随排序指标变化。

## 文件说明

- `index.html` — 页面骨架：原型控制条、假应用侧栏、页头挂载点、切换胶囊、原型状态面板。
- `proto.css` — 设计令牌（抄自 `frontend/src/styles/tokens.css`）、控制条、侧栏、页头与通用控件（按钮、分段器、徽章、提示、拖拽指示）。
- `basket.css` — 试卷篮抽屉布局、右缘开关、抽屉内紧凑卷面、题库管理示意样式。
- `views.css` — 两栏布局、要补的点、配题栏样式。
- `export.css` — 整理与导出的设置/导出面板与方案 B 卡片墙样式。
- `paper.css` — A4 卷面与题号轨道样式（整卷预览与导出 A/B 共用）。
- `data-questions.js` / `data-questions2.js` — 26 道虚构八年级数学题（实数、二次根式、勾股定理）。
- `data-needs.js` — 虚构班级、考试、12 个要补的点、19 道相关原题、两个折叠分组与试卷篮初稿。
- `state.js` — 共享内存状态与试卷篮操作（增删、拖拽排序、乐观保存 V#）、通用 HTML5 拖拽。
- `shell.js` — 假侧栏导航与页头（页签：班级组卷 / 整理与导出，去题库选题）。
- `view-paper.js` — 卷面 + 题号轨道共用渲染、学生版/教师版与答案模式控件。
- `view-needs.js` / `view-match.js` — 班级组卷左（要补的点）、中（配题）两栏。
- `view-papercol.js` — 试卷篮抽屉（原右栏「这张卷」并入，组卷工作台与题库管理共用）。
- `view-bank.js` — 题库管理（示意）视图，演示共用同一抽屉。
- `view-class.js` — 班级组卷装配、范围条与动作（W/S 切换、快速起草占位）。
- `view-preview.js` — 整卷预览页。
- `view-export.js` — 整理与导出（方案 A / B、试卷设置与导出面板）。
- `app.js` — hash 路由、方案切换、原型状态面板、键盘快捷键、模拟后台重算。

## 落地情况

正式页面已按本原型的方案 A、试卷篮抽屉与新版左栏筛选实现，当前规则以 `docs/product/KNOWLEDGE_AND_TRAINING.md`「班级组卷」为准。以下内容未进入正式页面：

- 方案 B（卡片墙 + 卷面）：用户选定方案 A。
- 独立「整卷预览」页（`#preview`）：用户决定预览入口直接进入「整理与导出」。
- 「区域常考」排序：系统中没有区域试卷出现次数的数据来源。
- 教师版「只看答案 / 答案+解析」分段：题库答案与解析存在同一字段，正式页面改为默认只显示「故答案为 / 故选」后的答案，解析按需展开。
- 原型控制条、模拟后台重算与假侧栏只属于原型。
