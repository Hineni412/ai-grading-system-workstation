# 班级学情组卷助手：成熟产品交互调研

核验日期：2026-09-13。用途：为本次已确认的人工选题流程提供产品依据；本文是调研与设计建议，不代表项目功能已经实现或验收。

本次范围：依据班级考试和知识掌握数据缩小现成题的候选范围，教师手动选择题目，加入现有试卷篮，形成全班共用的一张练习卷。不自动配出初稿，不调用模型，不设置锁题流程。

## 调研结论

可以借鉴的成熟操作是：看班级薄弱证据，勾选本次练习重点，在相关题目中继续筛选，预览后选入试卷。Pear Assessment 已公开“从学情报告挑选薄弱知识标准”的明确操作；Formative、ASSISTments 和二一组卷提供了成熟的现成题筛选与人工编组方式。把前后两段接入本项目已有题库和试卷篮，是本项目的设计推论。

外部产品拥有“智能”或“推荐”功能，不等于它能在本地运行或不调用模型。本调研只确认公开交互，不推测内部算法，不将营销效果作为验证结论。

## 1. Pear Assessment（原 Edulastic）：从学情报告选择薄弱点

**已核实事实。** 现行手册的操作为：进入班级的 Standards Based Report，点击 Assign Intervention，选择掌握表现区间；系统按落入该区间的学生人数排列知识标准，教师勾选需要处理的标准。之后再选择学生，进入 SmartBuild 或生成式 Instant Lesson Package。手册注明题目需要关联标准，且班级至少有 50% 学生完成评分，才能出现该入口。这是其产品条件，不是本项目应直接采用的阈值。[官方操作手册，2026-08-10 更新](https://docs.goguardian.com/products/pear-assessment/create-targeted-interventions-from-standards-based-report)

官方 2026 年发布说明还展示了 Identify Learning Gaps → 学生分组 → 平均掌握情况 → Recommended Content，推荐内容包括已有课程、课件和校区编写的测验，另有生成新内容的选择。[官方功能发布，2026-05-06](https://www.peardeck.com/product-updates/ai-powered-innovations-2026)

**对本项目的推论。** 借鉴前半段：把薄弱知识点与涉及人数放在一起，由教师勾选重点，再显示关联题。保留全班作为共同使用对象，不引入分组作业、SmartBuild 自动组题和生成内容步骤。

**不能核实。** 公开资料没有说明 Recommended Content 的内部检索算法或生成式模型调用边界；不能把它称为零模型方案。其推荐对象也不限于单道试题，与本项目的题库候选列表有差异。

## 2. Formative：班级知识表现与人工题库筛选

**已核实事实。** 教师在 Tracker 的 Standards 视图选定班级后，可查看班级在各标准上的平均表现，并追查关联题目。这里的标准相当于用于题目分类和学习评价的知识要求。[官方班级标准表现说明](https://help.formative.com/en/articles/919877-track-class-and-individual-growth-on-standards)

题库支持按标准、年级、学科、题型及 DOK 筛选；已选筛选条件可逐一移除，点开题目可预览，勾选多题后批量加入当前测验，再调整顺序或删除。DOK 表示思考复杂程度，不应直接转换为本项目的题目难度。题库页将人工选取现成题与 Generate with AI、Luna 助手分别说明。[官方题库操作说明，2026-07-08 更新](https://help.formative.com/en/articles/6520625-item-bank-school-district-license-add-on)

打印功能支持空白学生卷、教师答案册及保存 PDF，说明同一份测验可以用于全班纸面练习；题库和打印存在相应订阅要求。[官方打印说明](https://help.formative.com/en/articles/2580505-print-assignments-responses-and-scores-paid-teacher-school-district-feature)

**对本项目的推论。** 学情确定知识范围后，将范围直接带入现有题库筛选；老师继续调整题型、难度，查看答案解析，手动入篮。筛选条件和已入篮状态持续可见。

**不能核实。** 所查手册分别确认了班级报告和题库操作，没有证明“点击报告弱项，一键进入带条件的题库”已经连通。这个衔接需要由本项目完成。其题库预览阶段不显示全部答案信息，不宜照搬这一限制。

## 3. ASSISTments：同时显示表现、证据数量与完成情况

**已核实事实。** 作业报告可切换题目视图与知识标准视图：后者显示班级各标准的平均表现、关联题目数量以及学生是否完成这些题。题目视图还区分首次答对、后来答对和未答对，并可查看常见错误。[官方作业报告说明](https://www.assistments.org/individual-resource/assignment-reports)

Find & Assign 支持按标准关键词或编码找题，再用课程、题型筛选；教师勾选后可以加入新建或已有 Problem Set，之后将同一题集布置给班级。[官方现成题自定义题集说明](https://www.assistments.org/individual-resource/creating-custom-problem-sets) 普通作业也可以导出可打印 PDF。[官方作业管理说明](https://www.assistments.org/individual-resource/viewing-my-assignments)

**对本项目的推论。** 薄弱程度旁应呈现已有的证据范围和人数/题量，让老师判断这是否是全班共同问题。考试得分率与知识训练掌握情况分别表达，不把不同含义的数值平均成一个“AI 薄弱分”。候选题按现有知识关联得到，最终由老师选入同一试卷篮。

**不能核实。** 所查资料没有证明报告中的弱项会自动跳转至相应候选题。另一个 Skill Builders 功能给学生随机练习题，采用连续答对的掌握规则，属于个人练习机制；不适合作为全班同一张卷的参照。[官方 Skill Builders 说明](https://www.assistments.org/individual-resource/skillbuilders)

## 4. 二一组卷：教师熟悉的筛题—试题篮—试卷编辑

**已核实事实。** 教师选知识点或教材章节，按题型、难度、题类、年级缩小范围；查看考点、答案、解析后点击选题，加入试题篮。从篮中进入试卷预览和组卷中心，可调整题目、格式和分数。官方将这条手动选题流程与智能选题分开介绍。[官方“如何组卷”说明](https://zujuan.21cnjy.com/help/makepaper)

**对本项目的推论。** 沿用已有试卷篮完成后半程，将学情助手作为更有依据的筛题入口。选题动作只改变篮中内容；切换关注知识点时，已选题保持可见。无需再加细目表、生成初稿或锁题阶段。

**不能核实。** 所查公开说明没有展示班级考试弱点直接关联题库的完整操作，也没有公开智能选题的内部算法。不能仅凭产品名称中的“AI”或“智能”推断人工选题会调用模型。本次未取得可核验的组卷网、智学网同类完整官方手册，因此不使用第三方采购参数或转载补成事实。

## 对第一版的直接建议

以下为本项目设计建议，不是竞品已经验证的本项目实现。

1. **只保留一条主线。** 选择班级与证据范围 → 查看并勾选薄弱知识点 → 筛选关联题 → 手动加入现有试卷篮。主操作围绕“查看相关题”和“加入试卷篮”，不设置自动出卷按钮。
2. **让薄弱依据看得懂。** 使用现有可获取的班级人数、参与统计人数、题量和表现数据；明确是考试得分率还是训练掌握情况。数据缺失表示缺少证据，不直接判成薄弱；不照搬竞品阈值。
3. **让相关性看得见。** 候选列表保留所选知识范围、题型和难度条件，允许教师调整；题目展示匹配的知识点及答案解析。候选数量表示本地题库可选数量，不包装成预测准确率。
4. **复用已有选题成果。** 直接反馈当前篮中数量和题目是否已加入。改变筛选范围不清空已经选择的题，不建立平行草稿或逐题锁定状态。
5. **明确处理空结果。** 区分“学情证据不足”和“题库没有符合条件的题”，提示教师选择知识范围或调整题型、难度。候选为空时保持真实结果，不悄悄放宽条件，也不自动生成新题。
