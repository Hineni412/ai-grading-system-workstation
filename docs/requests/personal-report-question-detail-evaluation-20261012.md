# 家长报告逐题详情整合评估

用途：评估“题目格子展开后直接看作答截图与完整分析，取消末尾重复失分题详解”的建议。本文中的新结构尚未实现。

## 结论

建议采用。屏幕端把同一道题的题面、作答、错因和解法放在原位详情中，取消页尾重复详解。打印与离线导出继续保留全部失分题的完整内容。

评估使用 Impeccable 的 distill 信息精简原则：合并相关信息、减少查找与跳转、保留完整依据。按项目约定，本次只调查新方案，不删除附录、不新增真实模型请求。

## 当前可核实的行为

入口与渲染均在 [个人报告模板](../../backend/reporting/analysis_report_exporter.py)。

| 内容 | 题目格子的原位详情 | 页尾失分题附录 |
|---|---|---|
| 得分、班级平均、考查点 | 已显示 | 显示题目与小问得分 |
| 题面与已保存分析 | 失分题点击“看原卷和解法”后显示 | 已显示 |
| 作答截图 | 显示链接，跳到附录截图区域 | 承载实际图片，支持同一横行复用 |
| 老师批语 | 无可展示分析时作为回退内容 | 显式列出真实老师批语 |
| 失分步骤定位 | 详情未接入该内容 | 调用步骤诊断块，保留缺记录或无法定位的说明 |
| 打印 | 原位详情面板在打印时隐藏；题目片段存在 template 中 | 打印前展开全部失分题与依据 |

浏览器实测：展开已有失分题的“看原卷和解法”后，原位详情没有作答图片，仍提供附录截图链接。该检查只读取本机保存报告。

因此，现阶段直接删附录会失去截图目标和完整打印内容，也可能少显示老师批语与步骤定位。

## 建议阅读结构

1. 点击题目格子，保留简短的得分、学生作答、标准答案和结果摘要。
2. 点击“看题目、作答和解法”，在原位直接显示题面和作答截图。
3. 紧接截图列出真实老师批语、已保存错因、失分步骤定位与完整解法。
4. 同一时刻只展开正在查看的一题，减少长正文占据页面。

截图在第二步直接可见，不再要求家长点击一次截图链接并跳到页尾。手机保持原有宽横行图片的完整边缘，并复用现有放大阅读能力。

满分题也可查看题面、作答和已有参考内容，不为满分题补生成分析。未作答题明确标注，不能补出不存在的学生作答。

“完整分析”指已有的分析和参考内容完整展示。没有保存分析时显示真实老师批语与参考答案；没有步骤定位或原卷时说明缺失。仅查看报告不追加模型请求，不从失分推断未记录的步骤问题。

## 屏幕、打印与导出的分工

| 输出场景 | 建议结构 | 必须保留的内容 |
|---|---|---|
| 在线或离线屏幕阅读 | 题目格子下原位详情，不再追加重复页尾详解 | 当前题的完整题面、截图、老师批语和已保存分析 |
| A4 打印 | 自动输出全部失分题的完整清单 | 每道失分小问与证据，不能只打印当时打开的一题 |
| 离线 HTML | 包含全部题目内容，按格子展开 | 图片、公式与字体可离线读取 |

同一横行涉及多个客观题时，保持现有截图分组规则。图片只保存一次供各题复用，打印也只输出一次，并标明关联题号。区域部分重叠时保留全部边缘作答。

## 复用与完成标准

复用 `_question_detail_template`、`_lost_appendix_html` 已有内容、`_shots_html` 的截图分组、`_step_diagnosis_html` 和现有打印展开机制。没有新增页面、模型接口或跨模块写入的必要。

未来实现需逐项核对：失分题、满分题、未作答、无已保存分析、教师总分与步骤记录不相符、多个题共享横行图、原卷已释放、手机阅读、离线读取和 A4 全量打印。分数、排名、教师最终分锁与已保存模型正文保持原意。

本次已按用户确认合并信息精简调整，保留原有报告页面顺序。逐题整合仍停在建议阶段。
