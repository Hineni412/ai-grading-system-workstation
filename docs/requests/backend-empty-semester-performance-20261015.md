# 七项读取优化与验证

日期：2026-10-15。用途：记录已授权的七项实现、同输入对照与未达成的性能目标。七项代码均已实施，整页首次一秒目标仍未达成。

## 实现范围

| 项目 | 当前实现 | 保持的规则与复用位置 |
|---|---|---|
| 1．空考试范围 | 明确没有所选考试时，不再查询全部考试评分明细 | 收口在 DiagnosisProfileService；仓储空参数表示全部考试的既有语义不变；仍合并所属学期的已发布训练证据 |
| 2．省去不显示的资料 | 无分组显示诊断直接使用摘要；概览只为返回的技能节点读取关联；知识点与纯题型模式跳过无用途关联 | 复用完整、摘要、显示与共享显示响应；完整诊断、教材目录和有用途的跨册关联保留 |
| 3．按当前操作读取 | 试卷目录先取元数据，展开后读取可见试卷的分析状态；按问题或完整度筛选时读取所需全表状态；本册零题不预取补齐；中考摘要跨册复用 | 复用原试卷列表接口，默认仍返回完整统计；未知状态显示等待，失败可重试；按册题目筛选保留本册与中考跨册候选，空页不再组装逐题正文与展示附带资料 |
| 4．复用有效结果 | 上次显示结果保存来源版本；有效结果直接返回，过期结果立即显示并后台重算；浏览器按范围复用空结果，取消已切走范围的排队计算 | 复用原持久条目、数据版本、store 与在途请求；成功写入和已跟踪任务结束后失效；小组仍核对设置、日期、训练过程与素材状态 |
| 5．轻量候选筛选 | 先读取文字、当前判定资料、归属与难度；合格候选再取图片路径、格式和字节摘要；采用或导出时读取完整图片与 Word 正文 | 复用原资料加载器和 question_identity.cache；不再为筛选构造完整图片载荷；图示缺失、查重、难度、候选结果和付费缓存规则不变 |
| 6．缩小失效范围 | 技能索引和章节考情核对本册题目版本、贡献试卷资料与共享标准；明确题号候选按所选题号核对；活动标准解析器不因普通题目修改重建 | 复用 data_versions、question_versions、materials_global 和原有限结果缓存；保留有效旧章节缓存；标准及真正依赖的训练证据仍更新，不增加数据库表或迁移 |
| 7．评价与摘要去重 | 考试列表直接返回 has_results；教研页省去逐场报告请求；试卷评价按批读取材料，只组装所需题号与错因资料，并合并同键计算 | 复用原考试列表、报告能力、持久结果和 ResultCache；保留六维评价、详细证据入口与教师最终分规则 |

没有新建页面、服务、接口、数据库或并行业务实现。共享刷新代码同时影响学情、训练、题库与组卷只读接口：只有共享入口能够合并排队与上次结果，模块内部的重复处理不能消除这一层等待。写入及付费流程继续使用原流程。

新增保留量受已有容量限制：页面上次结果仍为 128 份、256 MiB，只多保存来源版本；图片字节摘要复用原 20 万项身份缓存，不保存图片正文；试卷评价内存结果最多 8 份、32 MiB；浏览器诊断最多 8 个范围，概览最多 16 个范围。没有新增正文磁盘副本、常驻进程或无界缓存。

## 测量条件

- 修改前源码保存在 `.audit/reading-seven-20261015-01/before/`；修改后使用当前源码。两端读取同一批原始数据库与文件。
- 冷读指独立进程，跳过派生结果磁盘缓存，屏蔽缓存保存；操作系统文件缓存不清空。预先导入和进程启动不计入函数计时，浏览器计时另行列出。
- 内存命中是同一进程重复读取的中位数。独立进程的 restart 模式允许读取原有磁盘条目；只有实际命中才称为磁盘命中，未命中仍是重算。
- 函数样本按顺序执行。关键有数据路径另交替测量修改前后各三次，以中位数报告。机器仍可能有其他任务，单次较大差值不能当作稳定收益。
- 测量工具禁止真实文件写入与模型网络请求。浏览器服务只允许本机只读请求，关闭启动任务、迁移和预热，缓存只放测量进程内存。每次核对打开的源数据库及附属文件状态。
- 不重启共用的 8035 服务，不调用真实模型、不使用密钥发请求、不迁移或改写真实数据。正常本机访问权限用于读取实际版本状态；路径访问受限而进入回退的失败样本不计入表格。

## 有数据路径与命中

下表采用交替运行修改前后各三次的中位数。冷读均为独立进程，派生结果缓存禁用；新进程命中行明确允许并命中原有磁盘条目。单位为秒。

| 路径 | 首次：前 → 后 | 内存命中：前 → 后 |
|---|---:|---:|
| 完整试卷评价（冷读） | 4.893 → 4.489 | 0.0027 → 0.0039 |
| 来源有效请求的候选池（冷读） | 5.364 → 5.420 | 0.0433 → 0.0425 |
| 全库候选池（冷读） | 10.134 → 10.017 | 0.1508 → 0.1453 |
| 候选池新进程磁盘命中 | 0.246 → 0.253 | 0.0366 → 0.0368 |
| 八上章节考情新进程磁盘命中 | 0.063 → 0.096 | 0.0391 → 0.0386 |
| 七上索引（冷读） | 0.318 → 0.338 | 0.0034 → 0.0033 |

试卷评价与候选输出在所有交替样本中一致。候选池首次读取没有稳定的大幅收益：该输入多数题目通过筛选，仍需准备合格候选的判定资料与图片身份。全库重算仍约十秒，不能声称候选优化已达到一秒。此项目前主要减少筛选阶段的完整图片与 Word 载荷准备。

有效缓存并非全部更快。章节考情的新进程命中中位数增加约 33 毫秒，来自本册来源依赖准备；有效旧条目继续命中，没有退回完整重算。试卷评价内存命中增加约 1 毫秒，当前每次返回独立结果副本。来源有效候选的磁盘命中约为 0.25 秒，差值约 7 毫秒。尚不能证明“所有命中均不退化”，这些小幅差值也保留在表中。

独立进程允许缓存的整组复测还包括：七上概览 0.593 秒、七下 0.706 秒、八下 0.450 秒、九上 0.426 秒；八上索引 0.622 秒、完整试卷列表 0.929 秒。诊断与概览的对应显示条目未实际命中时，仍按重算报告。试卷评价该次新进程读取为 3.185 秒，但没有命中完整评价磁盘条目，不能把它作为磁盘命中性能。

有一处既有结果不一致已修复：七上冷读没有本册知识主题行，读取全库旧技能快照后却会带入其他册的零题主题。现在仅保留与本册题目相交的主题行，原教材章、节和技能目录保留；七上冷读与新进程读取恢复一致。此项属于修正原缓存路径差异，不能笼统称全部旧磁盘结果逐字不变。

## 浏览器整页

使用实际构建产物与 Chromium，视口为 1440 × 960。每页使用独立只读服务进程和新浏览器上下文，禁用派生结果磁盘缓存及预热。计时从导航开始到必要内容显示并经过两帧，包含页面请求与渲染，不包含浏览器进程启动。下表是七上空范围的单次样本，单位为秒。

| 页面 | 修改前首次 | 修改后首次 |
|---|---:|---:|
| 学情 | 3.323 | 1.876 |
| 出训练 | 3.021 | 1.766 |
| 章节考情 | 1.983 | 1.806 |
| 题库按题型 | 4.305 | 1.966 |
| 试卷库 | 3.792 | 1.385 |

学情、出训练和章节考情切至八下、切回七上、切至七下、再切回七上，随后跨帧连续切换至九上、八下和七上。必要读取已经完成的七上恢复约 33～61 毫秒，诊断、概览或考情核心请求均为零。快速切换核对当前 store 的实际学期与可见页面，未出现旧学期或错误面板。题库元数据与分析状态分开验证，按需状态与完整列表一致；模拟分析详情读取失败后，页面显示错误，重试后全部分析状态恢复。

以上样本在机器有其他验证活动时取得，不能当作稳定百分位。五个页面的首次打开仍均超过一秒，后端空范围也未全部低于 0.2 秒。请求记录显示首个页面资料请求约在导航后 0.6～0.9 秒发出；目录、考试列表及页面加载之后才发业务请求。剩余时间含启动请求、计算、传输与渲染，尚未完成逐段稳定负载剖析。不能仅根据函数已低于一秒声称整页达标。

没有重启实际共用服务，因此未验收运行中的 8035 页面是否已加载新产物，也未验收真实模型输出、付费分析、真实数据迁移、正式打包或整页性能的长期百分位。

## 一致性、失效与验证入口

- 16 条原函数路径的冷读完整摘要全部一致；新增题目列表与筛选项的空册、有题册对照也一致；四册共享显示诊断保持同模式完整摘要一致。每个进程的重复读取另核对自身摘要一致。
- 合成 TEST 数据实验核对：修改其他册题目保留本册来源与结果；修改本册题目使本册来源变化；修改共享标准域使两册来源变化。另模拟训练证据域版本变化，诊断依赖改变、材料来源保持；实际训练发布后重新进入的结果由现有 API 用例覆盖。模拟版本变化不能替代真实训练发布验收。
- 原分组诊断用例已扩展为核对素材改变后返回旧结果及刷新标记，再等待后台完成并核对新结果。原来的立即完成断言改为当前异步契约，没有删除素材失效检查。
- 后端发布回归共 114 个参数化展开用例；前端 13 个用例和编辑器 3 个用例通过。Python 语法、相关前端 ESLint、TypeScript、隔离构建、脚本体积预算和文档检查通过。
- 修改测试前后均为 22 个文件、113 个测试函数、114 个后端展开用例。本任务没有新增测试文件、函数或参数化用例，没有删减业务检查。
- 原始计时与只读检查位于 `.audit/reading-seven-20261015-01/`：`before-cold-suite.json`、`after-cold-suite.json`、`before-restart-suite.json`、`after-restart-suite.json`、`paired-probes.json`、`display-probes.json`、`browser-*.json` 与 `version-probe.json`。这些工具不是正式测试入口，不在文档中固化性能断言。
