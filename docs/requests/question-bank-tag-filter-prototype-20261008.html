知识与训练
原型合成数据，不连接后端；只演示“按标签”页的交互与布局。
本原型表达的要点（实施规则见方案文档）
  1. 左栏只有章节树：点名字 = 只看这一章或这一节；名字前的小框 = 同时看多个。章节按“主考小节”统计，章的数字等于各节之和。
  2. 右侧顶部点维度名切换，一次只摊开一个维度的标签；切换不会清掉其他维度已选的标签，维度名上的数字是该维度已选个数。
  3. 题型和知识点只列左侧所选章节涉及的项；标签超过两行时折叠，可展开或搜索。
  4. 同一维度点多个 = 有其一即可；不同维度之间 = 同时满足；“全部”= 不限这一维度。标签后的数字 = 加上它之后的题数。
  5. 换章节后，在新范围里已经没有题的题型、知识点条件会自动去掉，并提示一句。
  6. 作答形式、难度、来源三行常驻，不进维度切换。所有已选标签集中列在“已选”一行，可逐个删除或清空。
  7. 题卡不再显示技能；旧链接带技能时，显示为黄色的“旧链接”条件，可删除。
