原型合成数据，不连接后端；只演示“按标签”页的交互与布局。
本原型表达的要点（实施规则见方案文档）
  1. 一进页面显示本学期全部题；左栏勾选即筛选，不再要求“先选一个标签”。
  2. 同一组内勾多个 = 有其一即可；不同组之间 = 同时满足。
  3. 每项右侧数字 = 在其他组已选条件下、带这一项的题数，随勾选实时变化。
  4. 章节按“主考小节”归属，每题只属一个小节，所以章的数字等于各节之和。章始终全部列出，为 0 时灰显；其他长列表只列有题的项和已选项。
  5. 题型、知识点按章 → 节分组；七年级等往届知识点归入“前置知识”。“知识主题”取消，并入知识点。
  6. 右上一行列出全部已选条件，可逐个删除或清空。原“标签筛选”弹窗取消。
  7. 题卡不再显示技能；改为显示主题型与知识点。“按技能”、“未挂技能”入口取消。
  8. 旧链接带技能时，显示为黄色的“旧链接”条件，可删除；左栏不提供技能分组。
