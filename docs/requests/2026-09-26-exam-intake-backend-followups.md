## 查重排重改动

- 精确同题继续比较完整题干、选项、公式及实际图片。新增 Word 与 LaTeX 可无损转换部分的共同公式表示；不做数学化简或改变运算次序，不识别的结构保留差异。
- 相似题查询取消题型硬性排除，预先计算文本特征并用相似度上界跳过不可能达到阈值的比较；数字、运算条件不同的候选标为变式。相似度不授权自动合并。
- 同题代表优先采用已有人工审核证据、人工标签和较完整标签，最后用稳定题目编号排序。导入、历史整理和候选折叠使用同一排序规则。
- 新增题目明确填入的标签和难度优先保留，复用只补未填写的标签维度与难度，不用旧同题值覆盖本次输入。
- 题面相同、答案文本不同的导入保留两个来源并标为待核对；不会用旧答案静默覆盖新来源。图片仅路径不同而内容相同，不构成答案冲突。人工新增和考试分析复用也不传播答案冲突的旧分析。
- 考试错因的同题家族读取检查当前内容，支持多层关系；旧链接失效后不再把不同题的其他场次记录带进来。
- 原历史排重脚本改为默认只读预览；显式 `--apply` 才在事务中修正确定链接及环状指向。答案或难度不同的组单列核对，旧题目 ID、题号、原答案、标签、判定点及考试引用保留，不物理删除题目。旧题目行已经承载原卷出现关系，不重复插入另一份出现记录。

## 导入同题告知：现状与前端待办

以下为当前源码和接口核对结果，没有通过调用真实模型或新建真实导入任务进行验收；本次未修改前端。

| 入口与情况 | 当前用户能看到的内容 | 尚缺的告知 |
|---|---|---|
| 题库重复上传整个相同文件 | 后端按文件内容识别已有试卷，复用原记录，任务显示完成。 | 这条快速路径没有把整卷重复状态明确传给完成提示，页面可能只显示普通“试卷已入库”，不能保证显示同题数量。 |
| 题库导入另一份试卷，其中题目完全相同且答案不冲突 | 上传导入完成后，在“上传试卷与任务”的“查看任务记录”中显示完全相同题目数量、自动关联和已有分析复用数量；不是上传前弹窗。 | 完全同题目前只有数量，没有逐题来源对照；任务记录默认折叠。 |
| 题库导入，相似题或变式 | 任务记录显示近似题数量及本卷题号；照常保留入库。 | 接口已提供 `match_kind`、`reason`、匹配题及来源卷，但页面没有分别展示变式、普通疑似以及具体匹配来源。 |
| 题库导入，题面相同但答案冲突 | 后端保留两份来源并标记待核对，接口返回 `match_kind=answer_conflict` 及具体原因。 | 当前页面仍统一称为“近似题”，没有明确显示“答案冲突”；不能据此宣称用户已收到明确冲突告知。 |
| 考试导入，命中可复用同题 | 查重发生在生成评分依据前；后端复用仍有效的分析，该题不重新发送模型；页面计为通过或入库完成。 | 单纯上传时没有同题提醒，成功复用没有独立的同题数量、题号及来源提示。 |
| 考试导入，命中同题但分析不可复用或图片身份不确定 | 后端将题目阻塞并返回具体原因，不自动追加该题模型调用；题目异常标记的说明可显示原因。 | 页面主标签目前为“入库异常”，应把同题核对原因直接表达清楚；成功复用与此类异常不能共用笼统提示。 |
