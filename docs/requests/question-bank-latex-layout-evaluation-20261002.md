# 题库 Word 与 LaTeX 排版效果调查

调查日期：2026-10-02。用途：判断题库排版方向，并记录同题对照的证据与适用边界。普通组卷已经接入 LaTeX PDF，保留 Word 格式；当前操作规则以[产品文档](../product/KNOWLEDGE_AND_TRAINING.md)为准。下文注明“接入前”的统计与对照是原始基准，不代表当前转换拒绝率或版面。未验证高中、物理打印、全库 PDF 和新工作机的完整离线资源。真实数据库、题目文件及评分规则保持原样，没有调用模型。

## 结论和用户实际使用

建议把“稳定的 PDF 直出，教师无需反复修版”作为改进目标，优先完善项目已有的 LaTeX 能力。用户确认：导出后最多调整排版，若 PDF 已满足使用需求，可以不再依赖 Word。这使 PDF 直出具有实际价值。

普通组卷目前可选择 LaTeX PDF，但没有证据保证它可以完全替代 Word。接入前实排发现，问题集中在 Word 内容转换、图片尺寸、表格结构与分页，而不是公式排版引擎的能力不足。当前实现补齐了样本中的常见转换与分页问题；未知结构明确报错，教师仍可选择 Word。

“严格基于 LaTeX”应区分两个意思：由 TeX 排版最终 PDF，值得继续验证；把现有题库全部强制改写成原生 TeX，目前没有必要性证据。题库原题大量来自 Word 的结构化内容，转换保真应先于迁移。当前按用户确认保留两条路径：PDF 面向直接打印，Word 保留可编辑内容；是否进一步调整常用入口，应以真实题目覆盖和打印验收为依据。

用户提出的“按代码规则排列文字、公式、图片、表格”基本成立，但 LaTeX 是整份文档的排版语言与工具，不仅是公式代码。Word 也可以由代码和统一模板生成，本项目实际就在这样做。差异不应解释为“Word 没有规则、LaTeX 有规则”；对 PDF 直出，更有价值的是先辨认题干、选项、材料表、小问与解析，再以统一模板测量实际宽高并决定分列、缩放与分页。仍须制定最小图幅、可拆边界和答题空间等规则，不能承诺换引擎后规则消失。[exam-zh 的实际测宽源码](https://github.com/xkwxdyy/exam-zh/blob/main/exam-zh-choices.sty)、[xsim 的内容与解答模板](https://github.com/cgnieder/xsim/blob/master/doc/xsim-manual.tex)

## 接入前的全库内容转换预检

逐题调用现有 TeX 生成函数，只生成字符串，不运行业务发布；预检期间图片处理仅检查现有文件，不生成真实数据目录中的缓存。

| 题干转换 | 题目数 |
| --- | ---: |
| 可生成 TeX 源码 | 1,156，86.7% |
| 拒绝并应触发 Word 回退 | 178，13.3% |
| 其中括号分隔符不支持 | 110 |
| 公式字符不支持 | 54 |
| 上方极限等公式结构不支持 | 7 |
| 有文字但没有冻结 XML | 6 |
| 公式内部节点不支持 | 1 |

按题型，选择题 477/545、填空题 310/339、解答题 369/450 可生成源码。这里的“可生成”不代表编译成功，更不代表内容完整或页面合格。

括号转换器目前只接受有限的分隔符，题库公式存在逗号分隔等输入。公式中还存在全角标点、居中省略号、圈号等字符。因此部分拒绝来自转换器覆盖不足，并不能据此判断 LaTeX 不适合该题。

普通组卷还需要答案解析。把同一转换函数用于全库答案内容块的实验预检，995/1,334 可生成源码，339 道拒绝，占 25.4%。现有训练模板本身没有普通组卷的集中答案区，本统计是扩展可行性检查，不能称该功能已经实现。

更重要的是静默退化：32 道含合并单元格的题中，28 道通过源码预检；但现有表格转换没有保留横向、纵向合并关系。本次样本已实际看到表格结构改变。另有 1 道含旧式图片节点的题通过预检，其图片节点处理需单独核查，本次未对该题实排。拒绝率不是内容保真率。

## 接入前的实际试排方法和边界

按题型和版面特征选取 20 道题，使用项目原有 Word 正文函数与 LaTeX 正文函数。选择不是随机抽样，目的是覆盖常规题与困难题，不能用这 20 道估计全库视觉合格率。

| 样本组 | 本机题目标识 | 覆盖 |
| --- | --- | --- |
| 普通公式与文字选项 | 127、128、129、133、141、142 | 根式、分数、上下标、普通公式文字、选择与填空 |
| 图片 | 125、135、137、165、226、151、796、1319 | 两类图片选项、小图、横长图、竖长图、大像素图、表格内图片 |
| 表格与长题 | 186、194、295、719 | 数值表、图文表格、合并单元格、多方案图、小问、长材料 |
| 解答和解析 | 152、258 | 多小问、长解析、几何图、复杂公式转换边界 |

Word 经项目现有 WPS 转换脚本生成 PDF；LaTeX 使用本项目已有 Tectonic，补齐公开排版资源，并在实验进程中指定隔离的字体索引配置。没有修改正式模板。实验图片压缩缓存只写入本次测试目录，没有写入真实 `user_data`。

默认 Word 配置写着 A4，但本次实际 PDF 为 Letter，即 215.9×279.4 mm；LaTeX 为 A4，即 210×297 mm。源码核查发现普通导出布局函数设置了页边距，没有应用纸张尺寸字段。为避免据此误判，另生成了图片、表格两组 A4 Word，对齐左右 18 mm、上 20 mm、下 28 mm 页边距。

原 Word 富文本仍带局部字体和字号。PDF 检查显示 Word 正文主要约 10.4–10.5 pt，现有 LaTeX 约 10.9 pt；A4 对照未强行改写全部原题局部格式。因此本调查只用页数说明该实现的具体输出，不把页数差当成排版引擎效率比较。正式省纸对照还需统一字大小、选项图尺寸与答题空间。

实排覆盖 20 道 Word 题目；18 道题干进入三组 LaTeX PDF，另试排第 258 题及解析。第 152 题解析被转换器拒绝。本地页面对照包括失败版面，没有为了展示漂亮效果手工修正文档。

## 接入前的分题型效果评价

| 类型 | 现有 Word 的实际表现 | 现有 LaTeX 的实际表现 | 是否值得以 LaTeX 改进 |
| --- | --- | --- | --- |
| 普通公式、填空 | 根式、分数、上下标可读，保留原生公式 | 常见公式也清楚，但本样本没有明显整体优势；普通文字算式没有自动变为原生数学结构 | 值得统一数学结构与字体，不能宣传仅换引擎就大幅提升 |
| 普通文字选项 | 保留源题布局，有原卷空格和局部格式 | 主要保留原段落、空格和制表符，没有成熟的内容宽度测量 | 可参考自动测量后采用 1/2/4 列，避免按字符数决定 |
| 图片选项 | 本次选项图限高 22 mm，部分排成两行；第 125 题部分标签与图距离较远 | 选项图限高 16 mm，部分更紧凑，第 125 题单行选项关联更清楚 | 有改进空间；当前差异主要来自尺寸和图文布局规则，需兼顾可读性 |
| 小型几何图 | 能与短题干并排，本样本图文可读 | 同样可并排，部分图与 Word 大小接近 | 适合继续使用紧凑布局，不需要所有图另占一行 |
| 横长图、大图 | 两道横长图均被压至约 55 mm 宽 | 同样约 55 mm 宽，没有解决细节小的问题 | 必须允许占整行或更大区域，不能统一套小图规则 |
| 竖长图 | 第 151 题题干、图在同一页 | 第 151 题题干在第 1 页，图被推到第 2 页 | 需要测量可用高度并保持题干与图关联；只约束宽度不够 |
| 表格内大图 | 第 1319 题场景图片约 81.7×50.3 mm | 同图约 35.5×22 mm，图片明显更小 | 表格内图片不能统一按行内公式图的高度处理 |
| 数值表格 | 第 186、194 题数据可见 | 表格超过版心，部分列越出纸张；编译仍成功 | 先修列宽、单元格边距和跨页，再扩展使用 |
| 合并单元格、多方案题 | 第 295 题保留合并布局，可跨页 | 合并关系改变，整块表格移页，列宽也偏大 | 这是内容关系保真问题，不能仅做字号或缩放修补 |
| 长材料、多小问、多图 | Word 也有跨页和空白，仍需改进 | 同一 4 题组输出 4 页；最后一页只剩第 719 题两张图，A4 Word 为 3 页 | 需要有限的题首、题图关联，允许长题合理跨页 |
| 长解析 | 能保留源解析格式，但也有跨页、来源广告图片 | 部分解析拒绝；第 258 题实验能输出，但仍有宽度警告 | 可做 PDF 方向，先完整转换与验证；来源重复题干、广告图片应另评估，不是 TeX 自动解决的事项 |

大图的关键不是“能否嵌入 PDF”，而是印出来后点名、数值和线条能否看清。第 165 题横图约 55×12.6 mm：Word 保留 1,652×379 像素，LaTeX 压为 1,000×229 像素。像素虽仍较多，物理图幅太小的问题没有改变。图片进入 TeX 后也不会自动变成矢量图。

现有表格生成把各列宽分配到约 172 mm，却又叠加单元格左右空隙、竖线等宽度，也没有保留原合并结构。样本日志出现最高约 137 pt 的超宽警告。PDF 文本位置检查确认表格组至少两处字符超出纸张右边界；页面视觉检查也确认裁切。现有编译函数以退出码和文件存在判断成功，这类非致命警告不会自动触发 Word 回退。因此“PDF 已生成”必须与“可交给教师打印”分开判断。

## GitHub 项目能借鉴什么

查阅了两个真实题库 MathBank、MathCyclus，以及中文试卷模板 exam-zh 和初中数学讲义 Onion。源码与官方文档的详细出处、许可证和未核实项见[一手来源笔记](latex-question-bank-primary-sources-20261002.md)。没有在外部服务上传本项目题目，也没有运行外部项目。

另外核查了数学橘子题库采用的 BHCexam、刷题本文档类 ExBook，以及题目与解答管理宏包 xsim。它们分别能提供试卷导出模板、同题多种版式、题干与答案及模板分离的参考，不能把文档类或宏包误当成完整题库。BHCexam 的选项分支存在直接可见的源码不一致；ExBook 仍用整题 `minipage`、固定留白及固定图片缩放。公开源码和漂亮样卷都不能替代对本项目困难输入的验证。[BHCexam 源码](https://github.com/mathedu4all/bhcexam/blob/master/BHCexam.cls)、[ExBook 源码](https://github.com/ExBook/ExBookie/blob/main/ExBook.cls)、[xsim 官方手册](https://github.com/cgnieder/xsim/blob/master/doc/xsim-manual.tex)

更具体的取舍是：参考 exam-zh 的真实选项、标签与间距测量；短题可试并排图文，长题不直接套整个不可拆图文盒；参考 xsim 将题干、答案、稳定身份和显示模板分开，但选题和题序仍由本应用的快照确定；合并表格按 multirow 与 longtable 的官方规则试排。上述是现有能力的改进候选，不要求更换题库存储或新增抽题系统。[exam-zh 图文源码](https://github.com/xkwxdyy/exam-zh/blob/main/exam-zh-textfigure.sty)、[multirow 官方用法](https://github.com/pietvo/multirow/blob/master/multirow.dtx)

两个题库的输入主要已经是 LaTeX 或 LaTeX 加 Markdown。本项目的 Word 原生公式、图文表格不能直接获得同样的效果。MathBank 仍有表格图 4 cm、配图最大 9×6 cm、右图区 5.2 cm、答题留白等具体规则；MathCyclus 会测量选项宽度选择列数，公开样卷还使用人工换页和图文块。漂亮样卷不能证明随机组卷不需要规则。[MathBank 排版源码](https://github.com/JudgePeach/math-question-bank/blob/main/mathbank/paper_helper.py)、[MathCyclus 排版类](https://github.com/JinLingxi/MathCyclus---Lingxi-Question-Bank-Assistant/blob/main/MathCyclus_book.cls)

更有价值的借鉴是可测量的选项和图文布局，统一的题号、小问与答案控制。`graphicx` 提供宽高边界和保持比例的缩放；中文模板 exam-zh 提供图文位置与选项能力。这些可以减少零散经验规则，但不能替代本项目对最小可读图幅和分页的产品选择。[graphics 官方手册](https://mirrors.ctan.org/macros/latex/required/graphics/grfguide.pdf)、[exam-zh](https://ctan.org/pkg/exam-zh)

网页 KaTeX/MathJax 公式预览和整卷 TeX PDF 是不同能力，前者不能证明纸张分页效果。[KaTeX 官方支持范围](https://katex.org/docs/supported.html)

## 隔离排版原型的实际结果

原型复用现有 OMML 公式和 Word 内容块转换，在独立实验进程中补充转换与布局；应用不会导入这个原型。没有新增正式模块、页面、服务或接口。原始对照文件保留，基础改进版写在 `tmp/latex-layout-audit-20261002/prototype-v2/`，纵向合并试排写在 `prototype-v3/`，分页与作答空间试排写在 `prototype-v4/`。这些是可比较的隔离实验版本，没有替换应用或真实数据。用户已授权参考所调查项目继续改善原型。

原型使用相同的 20 道样本和题序，并增加 126、191、601、1465、1483 五道现有公式转换失败的题，共 25 道题干；152、258 两道还包含答案解析。新增 A4 Word 普通公式和解析对照，所有 Word 对照均为 A4、相同页边距；保留原题局部字号。原型西文字体使用 Times New Roman，中文和部分符号使用宋体，字号仍为 11 pt。原型保留原始图片像素，未使用现有最长边 1,000 像素的压缩缓存。

## 扩大覆盖的完成标准

普通组卷已可选择 PDF 与 Word。以下标准用于继续扩大题型和机器覆盖，尚未全部达到。

1. **先守住内容完整。** 补齐本题库常见公式输入，明确处理合并单元格与旧图片节点；不认识的结构明确拒绝，不静默丢弃。题干和答案分别检查，保留原题内容与语义。
2. **把图片分为真实版面用途。** 小配图可并排，横长图或密集图允许整行，竖长图同时受宽高边界限制，表格内图单独测量，多图按组保留关系。不能仅靠“客观题 55 mm、行内图 22 mm”覆盖所有情况。最小可读文字和纸面尺寸要由实际打印样本确定。
3. **建立统一试卷模板。** 用实际宽度排选项，保留表格列和合并关系；让长表可合理跨页；题号、必要的起始题干和关联图一起判断剩余空间，长题允许分段。统一 A4、字体、字号和答题空间之后再比较页数。
4. **把离线与版面验收加到出卷完成标准。** 检查缺字、图片缺失、公式差异、表格裁切、超宽、题图分离和异常空白，避免仅以编译成功认定可打印。训练冻结、二维码、双面补页与回收流程需沿原流程回归。
5. **扩大覆盖前分层验收。** 当前八年级普通组卷已接入 PDF，题干与解析已有困难样本实排；高中另用真实样本确认。保留 Word 输出，未知转换失败不自动发布其他格式。

建议验收口径：当前全库题干与解析逐题内容检查，困难题型分层实排；没有题目、公式、图或表格关系丢失；印刷图中文字可读；没有纸张外裁切；题图关系和作答空间可用；断网的新工作机能完成出卷。省纸和速度必须在同输入、同纸张、同字号、同答题空间下测量。此次没有做完整全库 PDF 编译、真实打印或批量性能对比，不承诺“完全解决所有排版”。
