# 任务一：知识图谱掌握度精细化实施方案

日期：2026-09-08\
用途：明确实现范围、旧数据处理方式、验收与启用步骤。\
状态：方案，尚未实现。本次仅编写文档，没有盘点或处理真实数据库，也没有调用真实模型。\
后续任务：[跨班候选训练小组实施方案](2026-09-08-cross-class-training-groups-implementation-plan.md)。

## 1. 要得到的结果

让教师能够区分“第一问会、第二问不会”“基础题出错、综合题失分”“已观察到失败、尚无足够依据”，并让这些差异进入当前掌握度与后续选题。

主要结果：

1. 解答题的小问分别关联实际考查的知识，不再自动继承整题全部标签作为小问直接证据。
2. 有可靠步骤结果时，进一步区分相关知识的表现；只有小问得分时，不编造每一步的状态。
3. 难度与作答结果共同影响一条证据的作用：简单题错误提供较强负面证据，难题错误较弱；可核实的难题正确表现提供较强正面证据。
4. 图谱、章节训练、学生证据详情及推荐使用同一份当前计算结果，并显示证据数量、来源粒度及缺项。
5. 当前掌握度可以变化；历史考试分数、排名、教师最终分锁、已冻结训练卷及其原判定不因本次计算调整而改变。

本任务不包含：复测台账、自动判断学生实际用时、增加考试评分项、重新批改历史答卷、全库统一重新打标签、课程安排或班主任流程。

## 3. 现有数据库是否需要再处理

**需要有针对性地处理，但要分成四种不同操作。代码更新不会自动完成旧题补齐。**

| 操作 | 是否预计需要 | 是否调用模型 | 影响 |
|---|---|---|---|
| 数据库结构升级 | 预计需要，主要在题库库中补充小问评估资料的存储；最终以迁移差异为准 | 否 | 增加所需结构，不重算考试分数，不批量重写题干 |
| 本地整理已有资料 | 需要 | 否 | 读取已有小问、步骤和知识关联，建立准确的计算对应关系 |
| 缺项补分析 | 按盘点结果决定 | 可能需要 | 多小问难度、缺失知识关联、失效或缺失的详细判定资料分别处理 |
| 当前掌握度重新计算 | 启用新口径时需要 | 否 | 根据有效原始证据更新图谱与推荐依据，刷新相关缓存；不是重新阅卷 |

### 3.1 盘点采用两个独立维度

不能只按“有判定点／没有判定点”分类。有判定点不代表小问知识关联、难度和历史答卷对位都齐全。

**维度一：知识归属是否可用。**

| 类别 | 数据情况 | 处理 |
|---|---|---|
| A | 详细判定版本有效，小问、步骤、活动知识身份完整，能与考试或训练项准确对应 | 本地读取、整理和校验，复用已有分析 |
| B | 有有效小问和步骤，但知识关联缺失或只有整题标签 | 保留既有判定内容，只补缺少的知识归属；有明确人工来源可本地整理，否则才请求定向分析 |
| C | 只有旧训练判定点或整题标签，缺少有效详细判定来源 | 检查是否有可恢复的对应历史版本或已确认资料；确实没有时，所选题需补分析 |
| D | 题目已改动、图片缺失、小问无法唯一对位，或知识身份无法解析 | 列为待处理，不强行挂入细知识点，不自动猜测 |

**维度二：难度是否可用。**

- 单一有效小问题：题目内容一致、整题难度有效时，可复用整题难度作为该小问估计，并注明来源。
- 多小问题：逐小问检查。没有明确小问难度时显示“尚未细分”，计算暂用中性系数。
- 不能仅按题号靠后、步骤数量多、整题难度高，就本地推断每个小问都难。
- 多小问缺难度时，需要教师确认或补充模型估计；这类补充可以只分析小问评估资料，不必把七维标签、答案和判定标准全部重做。

因此，即使某批题的知识关联都可本地复用，为完整使用难度调整，仍可能需要一次小问难度补充。真实需要处理多少题、多少小问和多少请求，必须盘点后才有答案。

### 3.2 先处理哪里

推荐按教师选定的一个章／小节做试点：

1. 优先整理该范围内、已有考试证据涉及的题目，使当前诊断先变得可解释。
2. 再补齐该范围内近期需要用来组卷的题库候选，使训练使用相同口径。
3. 根据缺项清单处理必要题目，不要求全库补齐后才能使用已准备好的范围。
4. 扩大到其他章节时重复相同流程，不把试点授权理解为全库授权。

### 3.3 真实盘点与处理的输出

真实盘点前另行确认精确范围。首次盘点只读，不能通过会初始化数据库的业务入口间接写库。

给教师展示：各类别题数、小问数、可本地处理数、需补分析数、无法处理的具体原因、影响的所选考试范围，以及模型请求与用量估算。

真实题号明细、关联学生资料和分析正文只在已有受控业务位置保存和查看，不写入本方案、Git、普通日志或公共任务摘要。盘点报告位置及内容随该次真实数据授权说明。

## 4. 证据归属规则

### 4.1 整题、小问、步骤各自负责什么

- 整题七维标签继续服务题库检索和选题，不拆成多个独立题库题目；共用题干、图片和前问条件保持完整。
- 小问知识关联从该小问的有效详细判定资料形成。直接考查与辅助先修保持区别。
- 当前学业诊断不把“题目涉及某知识”直接等同于“这份答卷已经测出了该知识的表现”。
- 教材归属等整题信息继续复用原字段，不为了小问细化把所有七个维度重新标一次。
- 可靠步骤结果优先用于定位；不足时退回小问层级并明确粒度。

### 4.2 考试成绩与详细判定对位

优先使用本场评分依据中的来源版本、题号、小问标识和步骤标识。新配置投影保留必要的来源小问标识。

历史配置缺少直接对位字段时，只有原题内容、版本和小问／步骤结构能形成唯一对应，才按现有转换规则建立对应。仅小问数量一致、按数组位置排列或名称相似，都不足以证明对应正确。

历史题目来源对不上时保留原成绩，显示“缺少小问归属依据”。不得用题库当前最新版直接覆盖一场旧考试的来源含义。

对于题目内容未变、只补充小问知识归属或难度的情况，可以把新补充资料用于这道旧题的当前诊断，但必须显式对应原题、小问和原判定步骤，并记录它是后补的分析资料。原始来源版本继续保留，不把后补内容伪装成考试当时已经存在的资料。这是让旧考试受益于本地整理或定向补分析的路径。

### 4.3 何时使用步骤结果

| 输入 | 计算处理 |
|---|---|
| 有可核实步骤结果、稳定步骤身份，且与教师最终决定一致 | 使用相关直接目标的步骤表现 |
| 只有教师确认的小问分数 | 用小问得分率作该小问表现，注明不能进一步判断内部错因 |
| AI步骤与教师最终分锁冲突，或教师改分后步骤未同步 | 教师最终决定优先，不采用冲突步骤来细分；保留小问级事实 |
| 未评分、识别失败、待复核、训练不确定或无法辨认 | 沿用现有无有效证据规则，不补零 |
| 明确空白 | 原考试零分保持；空白本身不足以定位到所有具体知识点，标为待核查，不推断时间不够 |
| 只有报告中的原因推测 | 可供教师阅读，不作为独立判定证据 |

对综合小问，只有粗分且无法区分直接目标时，显示“小问综合表现，归因有限”；不能把同一失分复制成每个辅助知识的独立失败。

### 4.4 防止重复放大

- 同一学生、同一作答修订、同一小问或目标的表现采用稳定来源身份去重。
- 同一小问某目标的多个步骤先在小问内部汇总，合计基础权重不超过该小问一次观察的权重。
- 已用步骤细分时，不再把同一小问总分作为额外独立证据叠加。
- 依赖前一步、实际上未能独立观察的后续步骤，不连锁记为多个独立失败。
- 父级章／节沿用既有去重汇总，分组时只使用选定范围的细点，避免父子重复。

## 5. 难度参与掌握度的首版计算

### 5.1 原则

系数作用于一条作答中的正、负证据贡献，不直接给最终百分比打折，不影响本场考试评分。难度未知时系数中性。

第一版保留现有初始参考值、考试／训练来源权重和时间衰减参数，集中验证知识归属与难度解释的变化。没有有效证据仍返回“无证据”，不显示65%。

以下数值是用于实现和合成验收的首版候选参数，不是经真实题库校准的教育测量结论。后续若修改，应更新参数版本并重新给出对比，不交给教师反复调技术滑块。

### 5.2 建议计算形式

每个已整理的小问目标输入：

- r：可靠的达成比例，0—1；
- w：来源权重、时间衰减和小问内部归一化后的基础权重；
- d：对应小问的难度估计，1—10；缺失时保持中性；
- p：正证据系数；n：负证据系数。

候选系数：

    t = (d - 5.5) / 4.5
    p = 1 + 0.25 × t
    n = 1 - 0.25 × t
    难度缺失时 p = n = 1

因此，最简单题的 p/n 为0.75/1.25，最难题为1.25/0.75。对同一个知识目标：

    正贡献 = Σ(w × r × p)
    负贡献 = Σ(w × (1-r) × n)
    当前掌握度 = (初始参考值 × 初始强度 + 正贡献)
                 / (初始强度 + 正贡献 + 负贡献)

这允许同一小问有部分达成。步骤支持哪个目标须先确定，不能用难度系数弥补错误的知识归属。

基础权重不再重复乘现有 difficulty/5。旧训练行中的 difficulty_weight 作为兼容输入处理：优先读原冻结推荐中的难度，确知旧格式时可还原其含义；来源不明时使用中性值并提示，不把两套难度机制相乘。

### 5.3 合成预期

在初始参考65%、强度2、当天单条考试证据、无其他证据时，以上候选公式预期：

| 情形 | 候选结果 |
|---|---:|
| 最简单题全错 | 40.0% |
| 最难题全错 | 47.3% |
| 最简单题全对 | 74.5% |
| 最难题全对 | 78.5% |

这些数值用于验证公式方向与实现，不作为教师对某学生的结论。多道独立证据应逐步增强判断；显示层同时提供证据来源与数量。

### 5.4 难度估计的边界

使用小问本身的要求估计难度。全班得分率可以作为人工核对参考，不直接用“1－本班得分率”回头调整同一班的掌握度，以免把共同知识缺口解释成题难。

本轮不根据答卷尾部空白自动增加“时间系数”，也不拟合复杂能力模型。训练与考试均遵循同一套难度规则；普通考试分数和排名保持原含义。

## 6. 复用与最小存储调整

新建存储或接口前按此表核对，优先在现有模块内实现。

| 候选 | 决策与理由 |
|---|---|
| question_solution_evidence_versions | 继续作为小问、步骤、知识关联的来源；不新建重复的知识标签真值 |
| questions.difficulty | 保留整题用途；单字段不能表达多个小问难度，不能直接代替小问资料 |
| training_criterion_versions 与冻结训练快照 | 继续作为怎样判定的依据；仅补难度不应重写判定内容或让旧卷失效 |
| 题目分析任务、已有补齐与模型通道 | 复用调度、逐题状态、费用提示、有效结果保留等能力；现有补齐结果绑定判定点版本，不能把“仅补小问难度”伪装成重生成判定点 |
| CurrentMasteryCalculator 与现有计算函数 | 在现有掌握度模块内扩展输入和贡献计算，保留一个当前口径 |
| 图谱、章节矩阵、StudentEvidenceView、QuestionInspector | 直接扩展已有详情与缺项展示，不新建教学首页或维护工作台 |

**拟新增一类小问评估补充资料**，存于 question_bank 数据库，建议以 question_part_assessment_profiles 为表名，具体迁移编号实施时分配。以题目身份、既有题目来源版本及详细判定版本关联，保存各小问难度、估计来源、理由、修订和完成状态。采用已有版本与来源检查方式，不新增独立安全机制。

知识关联读取其引用的详细判定版本，不在补充资料里维护第二套可独立修改的知识标签。补知识关联时形成现有详细判定资料的新版本；若涉及判定标准实质改变，沿用既有审核流程，不能以本任务名义静默替换。

单纯难度补充不改变题干、答案、整题标签或批准的训练判定版本。小问评估任务复用已有任务基础设施，并补足对应的结果分支与必要存储约束；不直接启动已有“全量重新分析”入口。

新考试和新题目联合分析一次性带出所需补充资料；老题定向补充只请求缺项。不存在合格历史来源的题，才需要更完整的分析。

## 7. 历史考试、旧训练与推荐如何衔接

### 7.1 历史考试

只读原最终成绩、对应题目版本和已有作答证据，生成新的计算输入，不回写考试分数或原评分标准。不因补齐标签重发历史阅卷请求。

新口径下，部分旧百分比会变化；不能准确归到细点的旧记录可能改为“粗粒度参考／细点证据不足”。这一变化在启用预览中展示，不能把旧粗证据静默混成新细证据。

### 7.2 已发布训练

原冻结题目、判定点、逐点结果、教师锁及发布／撤回记录保持。

当前计算优先从有效已发布事实和其对应冻结来源整理细化证据。历史来源能唯一对位才细分；不能拿题库的新版本替换旧卷当时的判定含义。

同题内容及判定含义未变、旧冻结步骤身份仍能唯一对应时，可以采用后补知识归属或难度来解释原有逐点结果；仅形成当前分析的补充对应，不改动冻结判定快照。若新分析改变了步骤义务、拆并了无法对应的判定点或修改答案，则不能用于自动细化旧卷。

仅重新计算不需要重新发布原训练证据，不为同一结果同时计入旧整题汇总与新小问贡献，不借重放 outbox 改写历史业务事实。撤回、修正继续按现有稳定身份收敛。

冻结来源完全不支持细分时保留粗粒度说明，不补造步骤结果。现有反馈快照保留生成时口径，查看当前掌握度时另取当前值并标明版本差异。

### 7.3 草稿、缓存与输出

- 掌握度参数、小问归属或补充资料改变后，刷新受影响的诊断缓存和推荐来源修订。
- 未冻结旧草稿保留，按现有来源变化提示要求重新核对后再出卷。
- 已冻结试卷、已经导出的考试报告不自动重生成。
- 图谱与训练页必须来自同一次范围和版本计算，不能一个页面显示旧公式、另一个页面显示新公式。

## 8. 实施步骤与交付物

| 步骤 | 工作与交付 | 完成标准 |

| 1：整理计算契约 | 明确小问／步骤对位、证据来源、难度缺失、粗细粒度、唯一贡献身份；准备合成样本 | 相反小问表现能形成不同知识输入，缺失来源不会被猜测 |
| 2：补充资料与旧题处理工具 | 增量迁移、本地检查与整理、定向补分析、逐题恢复；先在合成库实现 | 能区分本地复用、只补难度、补关联、完整补分析及无法处理 |
| 3：接通考试和训练计算 | 修改相关只读投影、逐点汇总、难度计算、缓存和推荐版本 | 数值符合独立预期，修正／撤回不重复贡献 |
| 4：融入现有页面 | 在题目详情、热力图详情及证据页显示小问归属、难度来源、粗细证据与缺项 | 教师能看懂为什么变动、哪里还缺数据；主操作保持清晰 |
| 5：真实范围试点 | 单独授权后盘点、备份、迁移、本地整理；有必要再确认补分析费用 | 给出选定范围前后差异、剩余缺项和失败清单，保留原业务事实 |

## 9. 验收

使用合成数据与模型替身验证，不以全量测试数量作为完成标准。

| 场景 | 应有结果 |
|---|---|
| 两名学生总分相同，但第一／第二问对错相反 | 对应细知识点表现不同；不能因父题标签相同被压成同一画像 |
| 同一小问列式正确、后续运算错误，有可靠步骤依据 | 列式目标保留正证据，运算目标体现错误，不连坐所有先修知识 |
| 只有小问部分分、没有步骤记录 | 保留小问表现，显示归因有限，不生成虚构错因 |
| 简单题错与难题错，其他输入相同 | 前者负面作用更强；难题对仍能提供正面证据 |
| 难度缺失、未测到、无法辨认、未评分 | 分别显示局限，不把无证据补为零或初始65% |
| 一个目标的步骤数从2个等价细拆成5个 | 不因形式拆分显著增加该小问权重 |
| 教师改分后旧AI步骤仍保留 | 最终分锁优先，冲突步骤不继续支配细分判断 |
| 训练发布、重复读取、修正、撤回 | 与有效来源一致；不会叠加旧整题和新细化贡献 |
| 同一版本重复执行本地整理，处理中途退出再继续 | 已完成结果复用，不重复计入，不追加未授权模型请求 |
| 来源题后来被修改 | 旧考试、旧训练仍对应原版本，无法对位明确提示 |
| 页面切换和重新进入 | 同一范围的图谱、证据页与推荐数值一致，草稿来源变化可见 |
| 同等合成输入前后性能 | 记录同机读取与计算耗时，排除逐学生逐题反复查库造成的明显回退 |

复用现有相关测试入口，例如小问标签投影、mastery_v2、诊断、训练反馈及章节页面测试；只补本次缺少的行为场景，不默认启动正式应用或执行完整发布套件。文档规则见[测试说明](../testing/README.md)。

## 10. 数据授权、费用与回退

本方案不是读取或处理真实数据的授权。按[项目规则](../../AGENTS.md)，真实只读盘点、真实数据写入／迁移、真实模型调用和本次正式服务重启分别在执行前明确目标与影响；不因用户同意开发就自动执行。

建议实际操作顺序：

1. 展示拟盘点的题库、章节／题目和考试范围，取得本次只读盘点授权。
2. 出具可复用与缺项清单、迁移结构差异、补分析预计请求及用量。
3. 明确本次处理批次、保存位置、备份范围、失败状态后，取得对应写入及模型授权。
4. 暂停会修改有关数据的业务操作，沿用现有备份与维护入口处理相关数据库和来源资料；是否停服／重启单独说明并授权。
5. 先本地处理；真实模型补充只执行已确认缺项批次，失败不隐式扩大范围。费用遵循所选渠道的现有策略，未知结果按既有规则查询或人工处理。
6. 给出结果摘要和剩余缺项，再决定启用或扩大范围。

回退优先依靠保留原事实、增量补充资料和可回退代码版本：本任务不得就地覆盖旧题干、旧分数、旧判定快照。新补充资料停用后，旧版本能否忽略新增结构必须在合成库验证；不能仅凭“加了表”就承诺老程序一定可启动。

如确需数据库恢复覆盖，必须重新确认精确备份及恢复后会丢失哪些新增业务，不把恢复作为自动失败处理。两个独立数据库没有原子事务：按原来源版本读事实、以题为本地补齐单位保存；部分成功保留清单，不把单库提交成功说成全部完成。

尚不能给出的数字：真实需补齐题量、模型费用、数据处理耗时，以及可细化历史证据比例。这些依赖真实盘点，本次没有读取相关数据，不能预先保证“全部免费复用”或“必须全库重跑”。
