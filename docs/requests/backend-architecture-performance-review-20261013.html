01 · 共享刷新在释放锁后登记完成回调

后台计算提前完成时，登记回调会立即执行该回调。原代码此时仍持有刷新锁，回调又等待同一把锁，请求因此无法继续。修改后，创建者先登记在途任务，退出锁后再登记回调。

复用选择
保留 serve_with_refresh、_Flight 和 _complete。只移出持锁登记回调这一动作，不新增调度器。锁与任务生命周期由共享模块拥有，页面内部无法消除这个锁依赖。

结果一致
160 组差异用例及其中 32 次改变父节点、参数或动态节点后的重复拟合通过。拟合参数、权重、精度、参数数组及完整协方差的类型、形状和字节一致。公开掌握度、区间、档位与预测相同。覆盖空输入、动态周、多个目标共享祖先、训练证据、NumPy 标量权重、未观测节点与学生，以及不同参数。
完整规模
修改前后各 5 次拟合的参数、权重和完整协方差摘要相同。各 5 次完整计算返回的 4,500 项全部字段相同，叶级观测数总和均为 160,000。每次重新计算，没有跨请求缓存命中或跳过证据。另以同一拟合参数单独计时区间计算，每侧 5 次，完整协方差字节相同。
CPU 对比
每侧 5 次的进程 CPU 时间中位数：完整拟合 11.203 → 9.891 秒；完整计算 13.500 → 11.172 秒；区间分项 3.172 → 2.641 秒。完整拟合第 5 对的 CPU 时间增加 0.016 秒，其余 4 对下降；完整计算和区间分项 5 对均下降。CPU 时间接近实际耗时，主要成本仍是本地计算。
成本定位
独立性能分析中，系数外积调用从 160,000 次降为 4,000 次，参数先验宽度计算从 492,900 次降为 44,400 次。前后数值优化的目标函数调用均为 85 次。优化后的主要成本仍包括区间计算、观测参数准备、目标函数与冲突折扣。分析工具自身会增加耗时，分析结果没有混入上表计时。
复用边界
层级和状态字典只存在于本轮参数准备；后续预测和公开结果不借用它们。重复拟合重新创建这些资料。区间系数组合按学生准备并释放，没有跨请求缓存，也没有新数据库表。
保留的计算
全年级统一拟合后再取所选学生。保留冲突折扣、教材层级、完整协方差、阈值、600 轮迭代上限和每轮 40 次试探上限。没有关闭区间、减少学生或减少迭代来换速度。
测量限制
