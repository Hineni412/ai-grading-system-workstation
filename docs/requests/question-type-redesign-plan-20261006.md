# 题型改版方案（已确认，真实启用前）

用途：记录“题库以题型为主轴、技能退出主要用途”的已确认范围。实施状态见 [交接](question-type-redesign-handoff-20261007.md)，产品规则以 [题库、组卷与个性化训练](../product/KNOWLEDGE_AND_TRAINING.md) 为准。真实启用仍需单独授权；实验数据与评估代码在 `output/test_type_experiment_20261006/`（不入库）。

## 1. 已确认的决定（2026-10-06）

| 问题 | 决定 |
|---|---|
| 题型存放 | 做成新版知识标准中的知识点节点，细化学科网叶子；复用现有知识点链接、掌握度和“同知识主题”匹配通道 |
| 技能 | 保留链接数据，不再参与配题排序和教师可见的诊断；只在题目详情说明“哪一步失分” |
| 其余章节 | 第 3、6、7 章题型词表与标签由 SWE-2 按实验协议完成，每章词表先经用户审核 |
| 首批范围 | 组卷候选与个性化推荐按题型匹配；学情页按题型显示薄弱点；挑薄弱点时按章节分散并考虑失分题数；典型题暂不改 |
| 页面验收（2026-10-07） | 用户已人工验收学情与训练页面，认为没有问题 |
| 考试报告（2026-10-07） | 保留 v9 下的“题型分析”，分数、排名和教师最终分锁保持原规则 |
| 小节分散（2026-10-07） | 优先分散；候选不足时允许同小节补齐，不设硬上限 |
| 启用范围（2026-10-07） | 先启用来源校验通过的题；57 道预存来源失效题继续待处理，不自动重分析、不新增模型费用；实际写入仍需另行授权 |

## 2. 依据（实验结果摘要）

范围：八上第 1、2、4、5 章 967 道题；3 次考试、91 名学生；真实数据只读，测算在数据库副本上完成。

- 词表：72 个题型（第 1 章 16、第 2 章 22、第 4 章 20、第 5 章 14），以学科网叶子为底稿；第 5 章不参考讲义项目，作为留出章。
- 找同类题（机器指标，每题前 5 个候选中与讲义项目同类的比例）：现状技能 60%，题型 78%；留出章第 5 章 61% → 67%。
- 用户盲评推荐（30 道考试失分题，每方案前 3 个候选，共 149 次判断）：“同类合适”现状技能 80%，题型 99%，差 18.9 个百分点（90% 区间 +11～+28）。
- 用户盲评练习题组（8 名得分率 50%–80% 的学生，判 7 名）：题型方案最合适 4 次，题型加技能 1 次，两者并列 1 次，都不合适 1 次；现状技能 0 次。
- 学情预测（前两次考试预测第三次，2744 条判定点观测）：三种方案与“只看整体水平”相差不超过 0.007 对数损失；题型加技能比只用题型低 0.004，差距小。
- 典型题：盲评 5 节，现状 2、题型 2、差不多 1，看不出优势。
- 发现的规则问题：一名学生失分题勾股 7 道、根式 8 道，但“取掌握度最低的 3 项”全部落在二次根式小节。原因是最近一次考试把整个小节拉低，三种方案都受影响，与标签无关。另一个问题：练习只按一个统一难度目标筛选，使部分题型在难度范围内没有题或只剩不典型的题。
- 挑题规则盲评（同样 8 名学生）：按题型归并加权得分率、以失分原题为参照的新规则，用户选中 6 名，原题型方案 2 名。用户确认以此版本为底线。
- 单题得分率不能排序：8 名学生的 148 道失分题中 98 道得分率为 0%，其中 96 道为选择填空，只有全对或全错。
- 放宽候选的参照检查（第 2、4、5 章 652 道题作原题，难度相差不超过 1 级，以讲义项目分类为参照）：同题型 70%–90% 为同类，题面越像越高；主题型不同但次题型互相包含 83%；不同题型、同小节且题面高度相似（相似度不低于 0.6）52%；同小节其余 8%；同章其他小节 0%–3%。13% 的原题同题型候选不足 3 道，3% 一道都没有。

## 3. 设计

### 3.1 题型节点与词表
- 新建知识标准版本 v9：在每个小节下增加题型节点，稳定标识建议为 `kp_bnu24_math_g8_upper_{章}_{节}_t{两位序号}`，与学科网叶子的纯数字编号区分；实施时按 `knowledge_tag_identities` 的约束核实格式。
- 学科网叶子保留身份，映射到对应题型（模型输出叶子名称时归并到题型）；不再作为活动的题目主题出现在筛选与统计中。
- 每个题型保存名称、定义、纳入、排除和 2 道锚题，沿用实验词表格式。
- 实施前修补实验词表：第 5 章偏粗（14 类对应参照 17 类），T5-13 没有题，第 1 章 16 类偏粗（参照 24 类）。第 3、6、7 章新建词表。

### 3.2 每题的题型标签
- 每道整题 1 个主题型，0–2 个次题型；主题型按整题核心任务判定，不按背景或关键词。
- 主题型以直接链接挂到该题全部判定点，作为整题任务；次题型只作题目标签，用于找题、解释和第 3.5 节的相关候选匹配，不参与掌握度。
- 实验的 967 题标签作为起点；第 3、6、7 章补标后，经用户抽查再写入。

### 3.3 考试证据中的题型（跨模块改动）
- 已结束考试的冻结快照只有当时的技能与知识点链接，没有题型。学情投影时，按“考试题 → 已确认的题库关联 → 该题库题当前主题型”补上题型节点；技能与小问归属仍按冻结快照。
- 必须改动集成层的原因：掌握度观测由 `integration/question_tag_projection_service.py` 统一投影，题库模块内部无法给已冻结的考试补节点。影响范围：考试阅卷模块只被只读引用；分数、排名、报告、教师最终分锁含义不变。
- 未确认关联的考试题没有题型，按现有方式只用冻结链接。

### 3.4 掌握度与学情页
- 掌握度节点改为题型（并保留小节、章层级）；技能不再进入掌握度。实验中这样做比“题型加技能”的预测差约 0.004 对数损失，换来诊断只用一套教师可读的名称。
- 学情总览、知识结构和按学生页的薄弱项按题型显示；“技能 · 会做什么”一栏移除或折叠为题目详情中的步骤说明，具体页面形态实施前另出原型确认。
- 明显薄弱、还不稳、较稳定、证据不足的判定与把握区间规则不变，只换节点。

### 3.5 推荐与组卷
- 补弱、巩固、新练习、诊断性新练习的目标由技能改为题型；适合难度、近期原题排除、卷内重复、教学进度和范围规则不变。
- 补弱题以学生的失分原题为参照：每道参照题配同题型的题，难度围绕这道原题的难度（相差不超过 1 级，不足时放宽到 2 级），同题型内按与原题的题面相似度排序，再比较难度差。掌握度只决定先补哪些、补几道，不再用一个统一难度筛选所有题型。
- 候选分四层，前一层不够时才使用下一层，推荐理由写明所在层：
  1. 同主题型。
  2. 次题型相关：一方的次题型是另一方的主题型。
  3. 同小节、题型不同，但题面高度相似（相似度不低于 0.6，阈值在实施时用同一参照复核）；推荐理由注明“相近题，不是同一题型”。
  4. 同小节其余题：只在班级组卷中作为“同小节补充”供教师手动选择，不进入自动推荐；同章其他小节不作候选。
- 技能不参与排序。
- 出卷设置中的“同技能最多 N 道”改为“同题型最多 N 道”，默认值沿用；旧草稿兼容读取时按同一数值解释。
- 班级组卷“要补的点”按题型列出，人数与错因统计口径不变。

### 3.6 先补哪些题型
- 按“学生 × 主题型”归并考试作答：加权得分率 = 得分合计 ÷ 满分合计（按原题分值），同时记录考了几道、错了几道，以及本人所属完整班级在同样这些题上的加权得分率。单人或小组选择只限制目标学生，不缩小班级基准；不同班分别统计。不使用单道题得分率排序。
- 稳定失分：同题型至少考过 2 道、至少错 2 道，且加权得分率低于 60%；只错过 1 道的记为“可能失误”。
- 先补稳定失分的题型，按“全班得分率 − 本人得分率”从大到小，再按失分分值；不足时再从“可能失误”中按同一顺序补充。小节分散使用同小节占比三分之二的排序偏好；候选不足时允许同小节补齐，不设硬上限。
- 每个选中题型取全班大多做对、本人却失分的那道题作参照题。
- 阈值（2 道、60%、三分之二）来自本次盲评版本；实施后用新增考试数据复核。小组与全班的需要汇总沿用同一口径。

### 3.7 新导入题
- 联合分析的封闭词表中，知识点改为 v9 题型；提示词要求每题 1 个主题型、最多 2 个次题型；没有合适题型时进入现有“新词例外”待审，不自行新建。
- 提示词版本升级；已有题目不因版本升级自动重打。

### 3.8 技能数据
- 判定点的技能链接保留，题目详情继续显示。
- 待处理页的“技能缺口”“题量少技能”不再计入主要待办，保留入口；技能候选流程暂不删除。

### 3.9 不在本批
- 章节考情的典型题挑选，盲评未显示优势，暂不改。
- 七年级等其他教材册。

## 4. 保持不变

普通考试的分数、排名、报告、评分依据和教师最终分锁；训练四态与达成点表达；训练证据发布、冻结训练卷、修订与操作令牌、审计和恢复；模块边界与跨模块只读协作方式。

## 6. 风险与待核实

- 推荐、诊断、组卷与路由中约 43 处按 `sk_` 过滤技能，需要逐处改为题型或改为通用节点判断，改动面大，需分批并保持缓存键与快照版本正确失效。
- 分组规则“共同需要至少占一半、同技能上限”换成题型后，入组人数会变化，需要重新测量。
- v9 激活后，已冻结的训练卷保持原标准；新建训练使用题型。
- 实验标签由 SWE-2 完成，第 2、4 章参考了讲义项目分类，第 5 章是唯一独立检验；正式使用前需要用户抽查。
