# 题库与数据库简化设计

用途：记录用户确认的简化选择、承接方式和未实施范围。结构改造已落实到代码，真实数据库转换和物理删表尚未执行。当前产品行为以[题库与训练规则](../product/KNOWLEDGE_AND_TRAINING.md)为准，模块连接见[系统架构](../../ARCHITECTURE.md)，结构更新见[打包与更新](../maintenance/packaging.md)。本文不保存真实题目、学生信息或数据库统计。

## 目标与选择

每道题采用一份当前判定依据。完整模型分析保存解题证据，使用时转换为训练判定点。教师确认和手工修改优先，已发考试与训练卷继续使用冻结快照。保留考试阅卷与题库训练的数据库边界、教师最终分锁、跨库幂等、回执和审计。

这次调查核实了旧代码的若干失效机制：富文本按版本编号拒绝旧输入，部分版本值能抛异常；业务分别计算内容来源，图片路径等变化会影响旧摘要；两套当前判定内容需要再次比较；日常启动依赖历史 SQL，程序更新另有升级协调。这些机制不能证明用户经历的每次历史故障都出于同一个原因。

## 复用候选

| 候选 | 已有能力 | 本次选择 |
|---|---|---|
| 现有富文本和题目读取服务 | 正文、Word 结构、图片及题库浏览 | 统一支持的结构读取，逐题记录失败 |
| 现有解题证据仓储及训练转换 | 小问、判定点、参考解法、训练格式 | 模型结果只保存主依据，读取时转换 |
| 现有训练版本记录 | 教师确认、编辑、冲突保护和历史引用 | 保留教师内容与必要来源快照 |
| 现有内容计算与难度服务 | 来源核对与唯一难度公式 | 新结果共用规范内容摘要，旧公式只在读取边界兼容 |
| 现有 ops 维护流程 | 预演、备份、锁、待执行操作与失败恢复 | 更新工具调用同一维护协调 |

不新建统一题目表、版本注册表、策略层或第二套服务。现有接口已能承接读取、依据、教师决定、冻结与维护；新建一套实现会再增加转换与一致性负担。

## 已落实的结构

```mermaid
flowchart LR
  A[受支持的旧格式与导入] --> B[统一结构读取]
  B --> C[当前题目内容]
  C --> D[匹配题面的解题证据]
  D --> E[使用时转换训练判定点]
  T[仍匹配题面的教师决定] --> E
  E --> F[发卷冻结快照]
  F --> G[后续训练判定与教师结果]
```

- 删除训练读取前的并行准备写入和两份完整小问内容相等检查。完整模型结果不再重复写相同的训练正文。历史独立正文、教师覆盖和旧卷引用继续保留。
- 新摘要以题目实际内容为依据。题干、答案、题型、图片内容与顺序、Word 公式与表格、参考解法正文变化时重新核对。题号、提示词、知识分类、文件路径、纯样式和确认标记不改变新内容身份。
- 旧富文本按受支持的结构读取。格式编号不单独使正文失效；未知或损坏结构返回该题原因，批量流程继续处理正常题目，不把不可读资料标为已完成。
- 题目详情、资料状态、补齐和推荐复用同一当前依据。素材文件变化使缓存重新核对，不同资料目录不共享状态；已核对且未变化的题目内容仍可复用读取摘要。
- 空库按当前结构定义直接建立。完整当前库核对当前定义及实际结构，旧库升级继续严格使用历史迁移。更新工具复用 ops 协调和配对回退。

## 验证与边界

验证入口见[测试说明](../testing/README.md)。合成回归覆盖旧格式实际读取、混合批次错误隔离、真正内容变化后拒绝复用、教师确认与编辑、冻结卷、组卷与推荐、缓存恢复、空库和历史前缀升级、两库失败恢复。测试不调用真实模型，不写真实业务数据。

兼容输入只承诺已支持的格式与旧摘要公式。未知内容仍需核对。旧难度摘要没有保存完整图片或 Word 语义，不能声称旧记录具备新摘要的全部检查能力。

真实业务库保持原处。本次代码改造没有迁移真实库，也没有物理删除旧表。四张退役的 authoring 表及历史迁移 SQL 保留；旧 SQL 属于历史升级能力，不能当成备份删除。真实转换、删表和恢复覆盖均需按项目规则单独授权。完整安装包及实际旧机升级尚未验收。

旧备份只按用户另行批准的精确清单清理。备份清理不替代结构改造，也不扩展为删除未知文件或当前数据库。

## pstack 决策依据

采用“尽量少做”（Laziness Protocol），复用已有证据、转换和维护流程，删除重复当前路径。采用“边界集中处理”（Boundary Discipline），把旧格式兼容和逐题失败留在读取入口。采用“验证真实产物”（Prove It Works），通过既有应用入口及合成完整流程核对结果，保留真实升级尚未验收的范围。
