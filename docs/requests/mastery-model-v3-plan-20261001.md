# 掌握度模型调查与检验记录（2026-10-01）

用途：保留本次算法调整的调查依据、参数选择和验证结果。本文不是当前产品规则；规则见 [知识标准与训练](../product/KNOWLEDGE_AND_TRAINING.md)，运行连接见 [架构](../../ARCHITECTURE.md)，维护检验入口见 [测试说明](../testing/README.md)。

[原型代码](assets/mastery-model-prototype.py)仅为当时调查的参照，不是运行入口；其中的旧数据提取方式不用于当前系统。当前实现由 `CurrentMasteryCalculator` 与分层模型共同提供。

## 调查起因与样本

旧公式从每个知识点 65% 的先验起步，相当于已有两道题的分量，而同一小问的权重又被平分到判定点和目标。单个节点的实际证据较少，满分表现仍被拉回先验附近，父级汇总与子节点显示也采用不同口径。用户发现得分率 98.5% 的学生，42 个有证据节点中 41 个全对，却有 16 个被标为需巩固。

本次只读检查的教学学期为 `bnu24-math-g8-upper`：2 个班、91 名学生，3 次考试，5582 条有效模型观测，已发布训练证据为 0。检验不复制或修改真实数据库，不调用真实模型，不保存逐生结果，只输出汇总数字。

## 参数选择

分层 logistic 模型联合估计学生整体水平、沿教材树的节点偏差、公式难度与实测题目偏差。掌握度表示参考难度步骤做对的可能性，参考难度固定为 3.1，显示 80% 把握区间；分档由后端按把握程度判定。

在前两次考试上拟合，用第三次考试检验，共比较 432 组参数。对数损失差异不超过 0.002 时，优先保留较大的知识点层差异，再比较损失。选定参数为：

| 参数 | 选定值 |
|---|---:|
| 学生整体先验标准差 | 1 |
| 知识点、技能先验标准差 | 1.5 |
| 小节、章先验标准差 | 0.75 |
| 题目偏差先验标准差 | 1 |
| 每自然周整体变化速度 | 0 |
| 每自然周知识点、技能变化速度 | 0 |
| 失误率 | 0 |

时间变化与失误率已有实现，但本次样本没有证明非零值更合适。后续参数调整仍需先检验，不能按个别显示结果直接改常量。

## 前向预测结果

以下为前两次考试预测第三次考试的 2744 条观测。对数损失和 Brier 使用全部观测（包含部分达成）；AUC 只使用完全对、完全错的观测。前两项越低越好，AUC 越高越好。旧公式数字为原方案已记录的同一轮基线。

| 方法 | 对数损失 | Brier | AUC |
|---|---:|---:|---:|
| 旧公式记录 | 0.5501 | 0.1771 | 0.5880 |
| 直接做除法 | 0.433553 | 0.132928 | 0.796753 |
| 只用整体能力 | 0.405522 | 0.122404 | 0.804565 |
| 原型参数复现 | 0.400194 | 0.120245 | 0.810262 |
| 正式选定参数 | 0.398781 | 0.119809 | 0.809317 |

正式参数的对数损失、Brier 改善，AUC 与原型接近。只用第一次考试预测第二次时，新模型对数损失为 0.552094，整体能力模型为 0.539207，直接做除法为 0.539929；本次改进不代表每一轮、每一个指标都会更好。

| 预测范围 | 观测数 | 平均预测 | 实际达成 |
|---|---:|---:|---:|
| 0–20% | 19 | 15.75% | 10.53% |
| 20–40% | 204 | 31.27% | 27.92% |
| 40–60% | 199 | 48.04% | 48.24% |
| 60–80% | 576 | 73.01% | 74.29% |
| 80–100% | 1746 | 90.53% | 91.11% |

## 分档与样例

第三次考试中，训练与检验都直接观察到的“学生×目标”共有 504 个，57.74% 能确定档位，其余为证据不足。较稳定 174 个，应验率 98.28%；还不稳 41 个，应验率 48.78%；明显薄弱 76 个，应验率 68.42%；证据不足 213 个，不定义应验率。应验率比较的是后一次观测是否达到该档门槛，不能解读为模型后验把握程度的替代量。加入第三次考试后，此前有观测目标的档位变化率为 8.53%。

全部学期证据拟合后，3655 个直接观察到的“学生×目标”为：较稳定 1386、还不稳 306、明显薄弱 491、证据不足 1472。

- 得分率 98.5% 的样例：42 个有证据节点全部为较稳定。
- 得分率约 21% 的样例：18 个明显薄弱、13 个还不稳、7 个证据不足，没有较稳定。

## 实现验证与边界

正式页面、报告和组卷助手统一读取后端四档，详情显示区间、作答处数、全对处数和近期提示。群体采用该节点有观测学生的等权平均；无观测学生不进入分档人数或平均分母，不能按零分处理。群体颜色用人数最多的档位，同人数时按明显薄弱、还不稳、较稳定、证据不足的顺序显示。

验证覆盖深层教材路径、单人筛选与全体拟合的一致性、零时间变化的静态结果、未来区间扩张、训练发布及重开、更新前排除本次训练证据、旧冻结反馈兼容、后端档位驱动颜色和需关注人数。页面验收使用合成数据，检查了宽屏、窄屏、节点切换与详情显示。考试成绩和教师最终分锁的含义不随本次掌握度变化。

真实数据没有已发布训练记录，因此训练回流用隔离数据和模型替身验证；没有调用真实模型，也没有修改或迁移已有真实数据。三次考试覆盖有限，时间变化、失误率与弱档应验率仍需后续积累数据再检验。

## 同等输入的加载时间

91 名学生、同一教学学期，以两个独立新进程比较旧公式和新模型。关闭本地快照读取，只测后端学情准备及页面数据计算（不含 HTTP 传输和浏览器绘制）；沿用同一套已修复的诊断缓存，避免把并行性能任务的缓存修复算作模型收益。表中首次时间为证据与学情准备加对应页面数据转换，缓存时间为已有同范围页面结果后的再次读取。

| 页面 | 旧公式首次 | 新模型首次 | 旧公式缓存 | 新模型缓存 |
|---|---:|---:|---:|---:|
| 学情总览 | 18.72 秒 | 18.58 秒 | 0.007 秒 | 0.013 秒 |
| 知识结构 | 19.16 秒 | 20.56 秒 | 0.004 秒 | 0.010 秒 |

这轮首次知识结构增加约 1.4 秒，缓存后两页的数据计算均小于 0.02 秒。单独拟合并生成 91 名学生的全部当前节点结果约 1.4 秒。首次时间含证据准备，机器负载与文件缓存会带来波动，不能作为浏览器总等待时间保证。

新模型的全年级结果也沿用已有本地学情快照；隔离数据的独立进程重启检查禁止重新拟合，仍能恢复相同数值、档位和观测数。真实数据验证保持只读，没有为本次检查更新正式快照或重启正式服务。
