# 初中数学知识图谱权威来源与长期治理调查

> 日期：2026-08-03  
> 当前对象：集成预览分支已由历史 1121 个网站来源精细词归并出的 294 个知识词。  
> 范围：节点及 `parent / prerequisite / related` 关系；同时评估“完整词表选择 + AI 提新词 + 定期批量归并”。  
> 不包含：代码实现、真实模型调用、真实题库写入和关系自动替换。

## 结论

这条路线可行，但“AI 帮忙整理”必须与“权威审定”分开。

1. 可以依据教育部课程标准、经审定教材和数学依赖关系，重新整理 294 个词，建立比现有 70 个历史骨架更可靠的候选知识图谱。
2. 不能把 AI 联网生成的图直接称为官方图谱。教育部资料规定课程内容、学业深度和教材范围，但没有发布唯一的初中数学 `parent / prerequisite / related` 标准图；关系仍是本项目的教学建模结果。
3. 权威性应来自“来源明确 + 关系定义明确 + 数学教师确认 + 版本可追溯”，而不是模型名称或旧数据年龄。
4. 294 个词适合继续作为精细题目标签池，但不应默认全部一对一成为掌握度核心节点。
5. “向模型发送完整词表，同时允许提新词”可以采用；但新词只能先成为临时观察词，不得自动进入正式词表、活动图谱或学生掌握度。
6. “累计 200 个再归并”可作为批处理触发条件，不能作为质量标准。已知同义词应随时复用；合并、拆分和先修关系必须集中确认并按版本发布。

## 一、两类权威不能混用

### 数学内容权威

[教育部发布通知](https://www.moe.gov.cn/srcsite/A26/s8001/202204/t20220420_619921.html)明确 2022 版课标自 2022 年秋季执行；其中标注“以此为准”的[《义务教育数学课程标准（2022 年版）》](https://www.moe.gov.cn/srcsite/A26/s8001/202204/W020220510531636118932.pdf)是确定初中应学内容、学段要求和学习深度的最高优先来源。

课标把义务教育数学划为数与代数、图形与几何、统计与概率、综合与实践四个领域，并在第四学段（7～9 年级）组织为数与式、方程与不等式、函数等主题。教育部官方解读说明：[内容要求回答“学什么”，学业要求回答“学得怎样”，教学提示回答“怎么学”](https://www.moe.gov.cn/fbh/live/2022/54382/zjwz/202204/t20220421_620116.html)。节点不能只取题库网站栏目名，还应锚定这三类要求。

[2024 年义务教育国家课程教学用书目录](https://www.moe.gov.cn/srcsite/A26/s8001/202408/W020240805496325238752.pdf)列出多个按 2022 课标修订、经审定的数学教材版本。教材章节和概念出现顺序可作为层级与教学顺序证据，但不能自动成为全国唯一图谱。[中小学教材选用管理办法](https://www.moe.gov.cn/srcsite/A26/moe_714/202303/t20230320_1437577.html)规定，省级单位选用非统编义务教育教材时每学科不少于三个版本，说明多种合法编排并存。因此应至少交叉核对三个审定版本：多版本共同顺序提高置信度，单一版本先后不能直接宣称为数学必然先修。

### 图谱工程权威

W3C [SKOS 正式规范](https://www.w3.org/TR/skos-reference/)区分规范名、别名、隐藏旧名；区分直接上下位 `broader/narrower`、非层级关联 `related`，并提供 `exactMatch/closeMatch/broadMatch/narrowMatch/relatedMatch`。`related` 是对称、非传递关系，不能和同一节点对的上下位混用；层级环路对实际应用是问题。因此“同义、上位、相关、先修”不能混成一个挂靠字段。

[SSSOM 映射规范](https://mapping-commons.github.io/sssom/dev/)要求映射记录作者、置信度、依据和专家审核，适合保存“精细标签如何映射到核心节点”。W3C [PROV-O](https://www.w3.org/TR/prov-o/)和 [Data on the Web Best Practices](https://www.w3.org/TR/dwbp/)要求记录修订、生成/失效时间、责任主体、版本历史和持久标识；旧 ID 不能因改名、合并或退役而复用给另一含义。

## 二、节点应分层

| 层 | 作用 | 是否直接参与掌握度 |
|---|---|---|
| 课程锚点 | 课标领域、主题、学段和审定教材位置 | 否 |
| 核心可测节点 | 可独立讲清、出证据、判断掌握 | 是 |
| 精细标签 | 准确标题、搜题和保留细节 | 通过映射参与 |
| 别名/题型/方法/情境 | 识别说法或题目表现 | 否，另建关系 |

294 个词的目标不是全部升级为节点，而是全部有明确身份：核心节点、映射到核心节点、别名、转到方法/题型/情境，或退役。

核心节点至少应满足：能锚定课标；有定义和包含/排除边界；可独立教学；可由题目或判定点评价；关系可解释；换教材或题型后含义仍稳定。

知识空间理论也支持把节点落到可观察任务和知识状态，而非只画章节目录。Doignon 与 Falmagne 的[原始论文](https://doi.org/10.1016/S0020-7373(85)80031-6)及[《Knowledge Spaces》](https://link.springer.com/book/10.1007/978-3-642-58625-5)提供数学基础；[通过询问专家构建知识空间的原始研究](https://doi.org/10.1016/0022-2496(90)90035-8)也说明依赖结构需要领域专家判断。

## 三、三种关系的严格定义

| 关系 | 建议定义 | 主要证据 | 不能依据 |
|---|---|---|---|
| `parent` | 子概念指向直接上位主题，只存最近一层 | 课标结构、审定教材目录、数学包含关系 | 教学先后、同义、共现 |
| `prerequisite` | 学习或理解 B 前通常应先掌握 A；只存直接、有教学意义的依赖 | 定义/定理依赖、多教材共同顺序、教师判断、稳定学情证据 | 章节相邻、名称相似、同题出现 |
| `related` | 稳定的非层级联系，不声明先学谁 | 公式联系、数形联系、跨主题联合使用 | 同义、上下位、弱共现、传递推断 |

教育知识图谱原始论文 [KnowEdu](https://doi.org/10.1109/ACCESS.2018.2839607)把先修定义为“继续学习 B 前应先掌握 A”，并与概念包含分开；数学示例结合课程标准和学生表现识别关系。论文也指出包含层级较容易从教材目录获得，先修更隐含。

[ACL 2017](https://aclanthology.org/P17-1133/)和 [AAAI 2019](https://ojs.aaai.org/index.php/AAAI/article/view/5033)证明算法可以提出先修候选，但预测性能不等于教学真理。2024 年[AI 辅助构建教育知识图谱研究](https://research.sabanciuniv.edu/id/eprint/51711/)采用“算法评分候选 → 人类专家逐轮确认”的方式，直接支持本项目让 AI 减少工作量、由教师确认活动先修边。

发布前应机械检查：`parent` 和 `prerequisite` 无自环、冲突和循环；`related` 对称但不传递；同一对节点不同时是上下位和普通关联；每条正式边有来源、理由、提议者、审核者、时间和版本；只存直接先修边。W3C [SHACL](https://www.w3.org/TR/shacl/)可把必填字段、允许值和图结构规则固化为可重复校验；即使不采用 RDF，也应实现同等级确定性检查。

## 四、294 词重建流程

1. 冻结 294 词版本、稳定 ID、旧名称和历史来源；历史 1121 词只作来源与别名材料，不恢复为当前正式词表。
2. 按课标第四学段建立“领域 → 主题 → 内容要求 → 学业要求”锚点。
3. 至少核对三个审定教材版本，记录册、章、节和概念顺序；教材只作证据，不复制正文。
4. AI 为每个词提出规范名、定义、边界、类型、课标/教材锚点、最接近词和处置建议。
5. 先人工确认节点属于核心、精细映射、别名、其他维度或退役，再生成关系，避免把题型和同义词误连成先修。
6. `parent` 优先来自课标/教材层级；`prerequisite` 需数学依赖、多教材顺序和教师判断；`related` 只保留对错因解释、迁移或检索有价值的联系。
7. 新核心、合并/拆分、先修方向冲突、循环和一对多映射优先审核；每次发布不可变版本及影响清单。
8. 上线后可用匿名汇总学情发现需复核关系，但学情相关性不能单独改写数学关系。

## 五、“完整词表 + 自由新词”方案

完整发送当前 294 个知识词在技术上通常可行，但应发送稳定 ID、规范名和课标主题，易混项增加短定义；按权威主题分组，但允许从全表选择。章节归属仍为权威闭集，AI 不得自造。最终是否一次全发，应按所用模型的上下文、批量题数、费用和对照测试确定；只发 294 个含混名称未必优于发送有定义的结构化候选。

模型必须优先返回现有稳定 ID；确无合适项时才返回独立 `proposed_term`，同时写最接近现有词、不能复用原因和建议归属。新词可以作为临时显示标签和治理线索“先用”，但未确认时不能影响掌握度与学习路径。

每条新词至少保存：原名与短定义、代表题目语境、权威章节、最近现有词与差异、出现次数和试卷数、首次/最近时间、模型/提示词/词表版本、AI 映射建议及置信度。

“累计 200 个”应改成三层触发：

- 即时：查已确认别名和完全相同规范名，避免已知重复继续积累；
- 周期：数量阈值或固定周期先到者为准；
- 紧急：高频词、大量错误映射或可能改变先修的词不等待阈值。

批处理不能只发送“294 名称 + 200 新名称”，还应发送新词语境、定义、频率、已有映射和当前节点定义。AI 输出须区分 `exact`、`close`、`broader/narrower`、`related`、`new_core_candidate`、`wrong_dimension`、`reject`。AI 提出分组与理由，教师确认高影响变更，确认后发布新版本，不能静默覆盖运行中词表。

## 六、自动化边界与验收

可以自动：已确认别名复用、推荐候选、检查缺字段/循环/冲突、生成版本差异、按已确认映射回填旧题。

不可自动生效：新增/删除核心节点；语义不清的合并；把近义或相关当同义；新增/反转/删除先修；让临时词影响掌握度；改名后更换旧 ID；用单一教材顺序或单次模型输出宣称数学真理。

第一版至少满足：课标第四学段内容全部有锚点；294 词全部有处置；每个核心节点有稳定 ID、定义、边界、课标来源和可观察证据；每条关系有理由、来源和审核；图无环且关系语义不冲突；至少核对三个审定教材版本；用覆盖各领域的脱敏题目盲测；所有版本可比较、回退，旧题与历史掌握记录可追溯。

## 最终建议

采用“稳定核心 + 精细标签 + 临时观察词”三层体系。现有 70 个节点只视为历史稳定身份，逐个复核并保留兼容 ID，允许改名、拆分、降级或退役。294 个词是本次权威重建输入，不预设最终核心节点数；最终可能少于 294，也可能因课标缺口补少量节点。

这样形成的图谱不能称为“教育部官方知识图谱”，但可以称为“依据国家课程标准和审定教材、经数学教师确认、全过程可追溯的项目标准知识图谱”。这是本项目在可实现成本下最可靠、也最诚实的权威性定义。
