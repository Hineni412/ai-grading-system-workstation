# 知识图谱与题库训练任务操作说明

## 知识点何时可用于推荐

批改诊断术语和题库标签必须先映射到同一个标准知识点，并由教师确认。待确认或未映射术语会在训练推荐页显示，但不会静默参与推荐。集中处理入口位于“知识图谱适配调试”页。

## 生成训练任务

1. 默认使用当前考试，也可切换到跨考试或手动选择多场考试。
2. 选择单个学生、按得分率筛选后明确选择多个学生，或选择整个班级。
3. 先分析薄弱知识点，检查已确认映射和被排除的未映射术语。
4. 选择每人独立个性卷或自动分组卷，确认题量、阶段比例、排序权重和原题排除策略。
5. 生成预览并检查缺题与警告，然后保存训练任务。

多学生模式只保存教师明确选中的学生 ID，不保存筛选条件作为替代。

## 原题排除与缺题

当前考试原题排除只使用已确认的阅卷题目与题库题目关联。关联不完整时页面会显示警告。推荐池不足时系统保留缺题记录，不会用知识点未对齐的题目凑数。

## 导出与重试

导出必须基于已保存训练任务进行。学生卷、教师卷和完整任务包都从任务中的固定题目、诊断、考频和推荐快照生成；后续修改题库不会改变旧任务导出内容。

每次单项导出都会记录格式、受众、文件路径、状态、错误和重试次数。失败的学生卷或教师卷可在历史任务详情中点击“重试失败导出”。完整任务包如果失败，应先重试失败的单项导出，再重新生成任务包。

## 第一版边界

训练任务题目包含稳定任务题码，并已预留训练作答证据结构。训练结果回流尚未启用，第一版不会根据训练作答自动更新学生知识图谱掌握度。
