# 本机数据、模型与诊断

本文记录当前运行边界，不能作为新增安全机制的任务授权。代理操作真实数据与模型的授权要求统一见 `AGENTS.md`。

## 本机运行

应用按可信单用户设计，只监听回环地址，没有应用内登录或角色控制，不应直接对外部署。本机账户和文件访问权限是实际边界。

班主任工作台使用独立应用的数据与配置，本应用不再提供其业务接口。

`运行.bat` 默认把模型配置放在 `user_data/config/api_profiles.json`，未覆盖时路径管理器使用 Windows 账户本机配置目录。配置可能含密钥，不进入 Git、业务导出和文档。

## 模型发送

请求按功能包含题干、答案、答卷文字或图片及必要上下文；供应商处理方式由所配置服务的政策决定。

不同业务的发送与重试规则见对应产品文档和 `backend/llm/policy.py`。结果未知不能一概当成未发送；不得无判断追加请求。

## 普通日志与敏感诊断

公共 Task、Job 和普通日志只记录任务编号、状态、耗时、尝试次数、用量和不透明引用，不放请求正文、模型原文、图片、密钥或磁盘路径。业务 API 按领域提供必要内容，不通过公共任务接口传递正文。

专用诊断位于 `logs/llm_diagnostics.jsonl*`，设置页“AI 服务 → 调用记录与排查工具”提供本机查看入口。实现会清理密钥、完整服务地址、路径和图片载荷，但文本仍可能含试题、答案、学生或班主任内容；不能把脱敏等同于不含业务数据。

日志约 32 MiB 轮转，保留当前文件和最近 3 个轮转文件，不进入 Git 或普通业务备份。读取、复制、导出和清空真实诊断正文按敏感数据操作授权。该入口没有独立身份认证。

AI 不代替教师作学生诊断、欺凌认定、惩戒决定、自动外发或结案。紧急事项先按学校线下流程处理。
