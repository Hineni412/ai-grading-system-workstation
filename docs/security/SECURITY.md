# 当前安全、模型与诊断边界

本文件描述当前代码已经具备的安全边界和仍然存在的风险。它不代表已经允许使用真实学生数据、真实模型或真实密钥。

## 本机运行边界

- 应用面向单个教师的 Windows 工作机，只应监听和访问本机回环地址。
- 当前应用没有面向多用户的登录、角色权限或远程访问控制，不得直接暴露到局域网或公网。
- `运行.bat` 默认把 API profile 路径覆盖为 `user_data/config/api_profiles.json`；未设置该覆盖时，路径管理器才回落到当前 Windows 账户的本机配置目录。两处都可能包含模型密钥，均不得写入项目文档、业务导出或 Git。
- API 响应和错误不得返回密钥、完整服务地址、本机绝对路径、数据库连接信息或内部堆栈。

## 数据与模型调用

模型请求可能包含题干、答案、评分依据、学生答卷文字或图片、班主任对话、备课资料等敏感内容。只有当前功能确实需要图片时才发送图片；供应商如何保存和使用已发送数据，取决于用户配置的服务政策。

调用真实模型前必须逐次确认：

1. 本次使用的供应商、模型和任务；
2. 将发送的字段、正文和图片范围；
3. 预计请求次数、费用上限和超时影响；
4. 失败或结果不明后是否允许教师再发一次。

工作台模型任务默认不自动重试。系统无法确认请求是否已经到达供应商时，应保守标记为“可能已发送”并等待教师决定，不能为了得到结果自动追加费用。评分依据等其他功能只允许其当前策略明确规定的有限重试；每次实际尝试都必须单独计入诊断和用量。

坏 JSON 优先进行不产生费用的本地修复。结构或质量门未通过时，不发布半成品，也不为“看起来更好”自动追加模型请求。

## 公共任务、接口与普通日志

公共 Task、Job、状态接口和普通运行日志只允许保存或返回安全元数据，例如：

- 不透明任务编号、模块、用途和状态；
- 开始与结束时间、耗时、尝试次数和是否可能已发送；
- 模型配置标识、用量摘要、错误分类和可重试状态；
- 不包含正文的附件数量、大小和内容指纹。

这些公共位置不得包含完整提示词、模型原始响应、学生或教师正文、图片/base64、密钥、请求头、完整服务地址、本机绝对路径或可据此恢复正文的内部对象。

## 本机敏感诊断

只有受控的本机诊断日志 `logs/llm_diagnostics.jsonl*` 可以保存实际文本请求和模型原始文本响应。设置页中的“AI 服务 → 调用记录与排查工具”读取这份本机日志，用于教师主动排错。

- `logs/` 由 Git 忽略，诊断正文不得复制到文档、测试夹具、普通日志或公开任务接口。
- 日志会清除 API Key、Authorization、完整服务地址、本机绝对路径和图片/base64 正文。
- 日志仍可能含有试卷、答案、学生作答或班主任正文，属于敏感业务数据，只能在本机按需查看。
- 单个日志约 32 MiB 时轮转，保留当前文件和最近 3 个轮转文件。
- 清空、复制或导出诊断正文都属于敏感数据操作，必须说明精确目标并逐次授权。

“受控”只表示入口和存储位置受限制，不表示当前具有身份认证。应用没有为诊断工具提供独立登录或远程访问能力，因此本机账户和设备访问控制仍是必要边界。

## 班主任工作台的当前事实

班主任工作台当前固定使用明文数据格式：

- 普通工作数据库 `user_data/workspaces/class-teacher/class_teacher_work.db` 是明文 SQLite 文件。
- 敏感学生事务数据库 `user_data/workspaces/class-teacher/student_affairs.db` 也使用当前明文 repository，是当前正式数据的一部分。
- 当前没有 PIN 解锁、密码解锁、自动锁定、改密、新加密写入或专用加密备份入口。
- 旧密码、旧 PIN、恢复密钥、旧密文读取、Windows 旧凭据解包和旧库转换能力已经退出。
- 如果 `student_affairs.db` 是旧格式、明密混合格式、损坏或未知格式，运行时只在私有副本上判断格式；全部班主任读写、普通工作库初始化和班主任 AI 任务登记停止，其他模块继续运行。
- 当前版本不会解密、迁移、转换或修改该文件；普通备份和普通恢复也不承担格式转换。
- 普通备份当前可以包含 `class_teacher_work.db` 和已有的 `student_affairs.db`。生成、复制或恢复此类备份时必须按敏感学生数据处理。
- 当前共同 AI Task 发送链路没有单独的匿名化逐字预览关口；教师点击发起任务不等于正文已经匿名。真实启用前必须再次确认供应商、允许字段、费用和失败后的处理方式。

因此，不得把当前班主任工作台描述为“已加密保险箱”，也不得承诺设备丢失或文件被复制后正文不可读。没有单独授权时，只能使用合成数据和假模型进行测试。

## 必须逐次授权的操作

以下每一次操作都必须获得新的明确授权，之前的同类授权不能自动延续：

- 读取、复制、写入、移动、迁移或删除真实 `user_data/`；
- 使用真实数据库、试卷、答卷、教材、课件、学生档案或成绩；
- 使用真实密钥、调用真实模型、产生费用或在失败后追加请求；
- 执行数据库迁移、批量覆盖、永久删除、恢复覆盖或其他不可逆操作；
- 复制、导出或清空包含实际正文的模型诊断日志。

操作前需要确认精确目标、数据范围、备份、回退方式和失败影响。即使获得授权，真实数据也不得进入 Git、文档、普通日志、公开 API 响应或测试夹具。
