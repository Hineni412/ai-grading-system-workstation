# 本机数据、模型与诊断

本文记录当前运行边界，不能作为新增安全机制的任务授权。代理操作真实数据与模型的授权要求统一见 `AGENTS.md`。

## 本机运行

应用按可信单用户设计，只监听回环地址，没有应用内登录或角色控制，不应直接对外部署。本机账户和文件访问权限是实际边界。

`运行.bat` 默认把模型配置放在 `user_data/config/api_profiles.json`，未覆盖时路径管理器使用 Windows 账户本机配置目录。本机业务数据库、备份和含密钥的配置不进入 Git。模型配置也不进入业务导出和文档。

`.gitignore` 排除本机数据与生成文件。`tools/check_tracked_user_data.py` 检查已进入 Git 的文件路径，覆盖业务数据、数据库及其 WAL、SHM、回滚日志和备份、模型配置及其备份、环境密钥文件、私钥和运行产物；CI 在后端测试前执行该检查。路径检查不会扫描代码正文中的硬编码密钥，提交前仍需核对实际改动。

如果密钥曾经公开，仓库中删除密钥不能使旧密钥失效，必须在服务商后台撤销或更换。历史重写也不会清除别人已有的副本或 GitHub 的旧 PR 引用、缓存；后两项需通过 [GitHub Support](https://support.github.com/) 申请，具体条件见 [GitHub 敏感数据清理说明](https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/removing-sensitive-data-from-a-repository)。清理旧 PR 引用可能使相关历史差异页无法再查看。

## 模型发送

请求按功能包含题干、答案、答卷文字或图片及必要上下文；供应商处理方式由所配置服务的政策决定。章节题型整理只发送本章题干、答案、判定点和逐点知识关联，不发送学生身份或作答。预计整理章节与请求上限并入导入分析的同一次费用确认，授权绑定输入指纹、题目清单和各章可能数量上界，超出范围不追加请求；完整输入、返回与回执保存在题库受控目录，公共 Job 只返回新增题型及题数摘要。

旧八上标签刷新只发送该题题干、答案、题图、既有判定点和受控候选，不发送学生身份或作答。逐题请求不自动重试，差异对照与状态回执保存在 `user_data/question_bank/label_refresh_runs/`；命令行只输出预估和结果摘要，沿用本机模型及词表配置。真实抽样与全量执行仍按 `AGENTS.md` 分别授权。

不同业务的发送与重试规则见对应产品文档和 `backend/llm/policy.py`。结果未知不能一概当成未发送；不得无判断追加请求。

## 普通日志与敏感诊断

公共 Task、Job 和普通日志只记录任务编号、状态、耗时、尝试次数、用量和不透明引用，不放请求正文、模型原文、图片、密钥或磁盘路径。业务 API 按领域提供必要内容，不通过公共任务接口传递正文。

普通启动为 `ai_grading.api` 接通控制台日志。该耗时记录包含 HTTP 方法、API 路径、请求编号和耗时，不包含查询参数或请求、响应正文。请求编号也通过响应头返回，用于核对同一次请求。

专用诊断位于 `logs/llm_diagnostics.jsonl*`，设置页“AI 服务 → AI 调用记录”提供本机查看入口，默认收起，展开时才读取记录。实现会清理密钥、完整服务地址、路径和图片载荷，但文本仍可能含试题、答案和学生内容；不能把脱敏等同于不含业务数据。列表缓存只保留调用元数据，不保留请求、响应正文或解析结果；详情仍从受控日志读取。

日志约 32 MiB 轮转，保留当前文件和最近 3 个轮转文件，不进入 Git 或普通业务备份。读取真实诊断正文自动允许；导出到项目外、写入 Git/文档/普通日志或清空仍按敏感数据操作授权。该入口没有独立身份认证。

## 报告问题

公开 Issue 和 PR 只使用合成复现，不附学生资料、答卷、数据库、密钥或原始诊断日志。安全问题也按这一边界处理；需要传递敏感细节时，先通过不含敏感内容的报告与维护者约定私密渠道。
