# 前端视觉参考资产规则

本目录只保存经过裁剪和复核的局部视觉片段，不保存完整 AI 页面概念图，也不承担产品功能设计。

## 当前状态

当前活动参考集为空。2026-07-14 移除的 7 张完整 AI 概念图仍保留在 Git 历史中用于审计，但不再是当前设计输入，不应恢复到仓库内的归档目录。

## 允许保存的内容

- 颜色搭配片段；
- 字体层级和文字密度片段；
- 边框、圆角、阴影和表面层级片段；
- 输入框、按钮、表头等控件的无语义外观片段；
- 间距、对齐、分隔和纸张边界等局部细节。

## 禁止保存的内容

- 完整页面或足以还原完整页面的信息架构；
- 导航、页面名称和可读业务文案；
- 字段、按钮、状态、快捷键、示例数据和操作顺序；
- 当前系统没有依据的未来功能；
- 可被误读为业务需求或验收目标的流程图。

## 片段清单要求

新增片段时，必须在本文件追加一行清单，包含：

| 文件 | 历史来源 | 裁剪坐标 | 允许借鉴 | 禁止推导 | 复核日期 |
|---|---|---|---|---|---|
| 暂无 | — | — | — | — | — |

文件名只描述视觉属性，例如 `dense-table-row-spacing.png` 或 `subtle-panel-border.png`，不得使用“阅卷流程”“评分操作”等业务名称。

## 权威边界

片段只能辅助选择颜色、字体、间距、密度、边框、圆角、阴影和控件外观，不能决定业务功能，也不能单独强制某个 UX 方案存在。业务能力、数据语义、业务结果、状态、权限、安全确认、持久化和失败恢复必须追溯到现有 Streamlit、服务、数据库契约、测试，或用户留下日期与范围的明确决定。在业务能力与结果等价且安全边界不降低的前提下，信息架构与导航结构、页面拆分、布局、控件形式、呈现顺序、快捷键绑定和操作步骤可以按任务效率主动重设计；不要求复制旧 UI，也不因纯 UX 调整自动需要用户专项决定，但快捷键触发的业务结果与安全语义仍必须保持。参考资产不能出现在功能溯源表的“业务来源”列。
