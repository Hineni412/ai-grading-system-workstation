# 当前视觉与可访问性规范

本文件只约束视觉语言、内容可读性和通用可访问性。业务字段、状态含义、权限和操作流程以产品文档与当前代码为准，不能从视觉参考中推导。

## 视觉方向

界面应当安静、专业、清楚、克制，适合教师在 Windows 工作机上长时间使用。信息可以密集，但需要通过稳定的字号、对齐、留白和分隔建立层级，让试卷、答卷、评分证据和当前任务成为视觉重点。

避免营销式大标题、装饰性渐变、强阴影、卡片堆叠、聊天气泡中心化、数据大屏风格和无关插画。

## Token 与基础样式

颜色、字号、间距、圆角、阴影和动效通过 `frontend/src/styles/tokens.css` 及主题映射集中管理。页面优先复用现有 Token；只有当前语义无法表达时才新增。

### 色彩

- 应用背景使用低干扰浅灰，主要内容表面保持清楚。
- 全局只保留一个主要强调色。
- 正文使用高对比深灰，辅助文字仍须容易阅读。
- 成功、警告、危险和信息色只表达对应语义。
- 状态同时提供文字、图标或形状，不得只靠颜色区分。
- 不使用大面积高饱和背景或装饰性渐变。

### 字体

优先使用：

```css
font-family: Inter, "PingFang SC", "Microsoft YaHei",
  "Noto Sans CJK SC", system-ui, -apple-system, BlinkMacSystemFont,
  "Segoe UI", sans-serif;
```

- 页面标题通常为 22–24px，区块标题为 18–20px，面板标题为 15–16px。
- 默认正文为 14px；高密度数据可使用 13px。
- 12px 文字只用于简短辅助信息，不承担大段正文。
- 正文行高通常为 1.5，长内容可放宽到 1.7。

### 间距、边界和表面

- 优先使用 `4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48` 的间距层级。
- 同组内容用较小间距和稳定对齐关联，区块之间使用更清楚的分隔。
- 普通面板使用轻边框和小圆角。
- 阴影只用于菜单、浮层、模态框或拖拽对象。
- 不把每段说明、统计或表单都包装成独立卡片。
- 留白服务于理解和操作，不无故压缩工作区域。

## 信息与操作层级

- 主要工作内容获得最大可用面积和最清楚的对比。
- 辅助信息通过轻背景、窄分隔或较弱文字层级呈现。
- 同一操作区通常只有一个视觉主按钮。
- 风险和确认结果只在需要时使用语义色。
- 重要信息不能只在悬停状态中出现。
- 长中文、长文件名、长反馈和极端数字不能破坏布局。
- 页面采用一栏、多栏、侧栏、抽屉或弹窗，由当前任务决定，不在本文件固定页面几何结构。

## 控件

### 按钮和输入

- 主、次和危险操作有清楚层级；加载、禁用、聚焦和按下状态可辨认。
- 按钮文字说明具体动作，图标不能作为唯一说明。
- 危险操作不能因视觉弱化而容易误触。
- 输入标签常驻，placeholder 只作示例。
- 错误说明靠近对应字段，焦点、错误和禁用外观保持一致。
- 长文本保持可读行高，不塞入过小的固定区域。

### 标签、表格和列表

- 普通属性不全部做成彩色胶囊，醒目标记保持克制。
- 表头和数据列严格对齐，行高稳定。
- 选中、悬停、聚焦和禁用状态可以区分。
- 长内容被截断时，要让用户知道仍有更多内容，并提供可访问的查看方式。
- 加载、空白和失败状态与内容区域对齐。

### 浮层

- 标题、正文和操作区互不遮挡。
- 关闭控件可见，键盘焦点进入和离开后的落点清楚。
- 多个浮层同时出现时保持明确层级。
- 关闭、确认和取消后的业务结果由对应功能定义。

## 图像、文档和图表

- 试卷、答卷和扫描内容保持原始比例与清楚对比。
- 工具条和叠层不能遮住关键内容。
- 纸张边界清楚，但不使用舞台式强阴影。
- 低清晰度、加载失败或不可用时提供文字说明。
- 一个图表只回答一个清楚问题，标题、单位、图例和标签层级一致。
- 图表不使用三维效果、发光、装饰性渐变和无意义动画。
- 趋势、风险、空数据和小样本都要有文字说明；颜色不是唯一编码。

## 可访问性

- 键盘焦点始终明显，操作顺序与视觉顺序一致。
- 图标按钮和图形控件具有可访问名称。
- 正文、控件、边界和风险提示保持足够对比度。
- 错误与对应字段在视觉和语义上关联。
- 点击目标稳定，不因精简样式而过小。
- 图表提供文字摘要，工作流中的图像状态可以被文字识别。
- 尊重 `prefers-reduced-motion`。

动效只用于解释状态，通常控制在 80–240ms。禁止大面积弹跳、庆祝动画和持续背景动画。

## 窗口与验收

视觉修改先在用户实际使用的 Windows 桌面浏览器窗口中检查。改动影响共享布局、导航、长内容或紧凑窗口时，再补充有针对性的窄窗口检查。

任何窗口下都应避免：

- 意外的整页横向溢出；
- 文字、控件和数据列互相遮挡；
- 主要操作不可见或不可达；
- 固定区域遮住长内容；
- 加载、空白、失败、禁用和焦点状态不可读。

视觉参考只可帮助判断颜色、字体、密度、间距、边界、圆角、阴影和控件外观，不得用来推导业务字段、导航、快捷键、流程或未来功能。
