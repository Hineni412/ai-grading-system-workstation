# 界面样式

面向教师 Windows 工作机，界面清楚、克制，允许有组织的信息密度。试卷、答卷、评分证据与当前操作获得主要空间。视觉参考只用于外观，不能据此新增业务字段或流程。

## 复用与层级

- 颜色、字号、间距、圆角和动效使用 `frontend/src/styles/tokens.css` 及主题映射；先复用现有组件与令牌。
- 默认无衬线字体从全局继承。展示标题、试题正文和等宽内容分别使用现有 display、document、mono 字体令牌。
- 通过对齐、留白、轻边框和字号区分层级；避免装饰性渐变、强阴影、无关插画和每段内容单独套卡片。
- 同一操作区突出一个主要动作；重要信息常显，不只藏在悬停中。页面栏数、抽屉和弹窗按当前操作决定。
- 状态同时用文字或图标表达，不能只靠颜色。

## 控件与内容

- 按钮描述具体动作；输入标签常驻，错误靠近字段。加载、禁用、失败、空白和焦点状态可区分。
- 表头与数据对齐，长中文、文件名和数字不互相遮挡；截断内容提供可访问的展开方式。
- 浮层标题、正文、操作区互不遮挡，关闭入口与焦点返回清楚。
- 试卷和答卷保持比例，工具条不挡关键内容；图像不可用时显示文字说明。
- 图表说明问题、单位、图例和缺失数据，避免三维和装饰动画；提供必要文字解释。

## 验证

先检查用户实际窗口；影响共享布局或长内容时补充窄窗口。核对主要动作可达、无意外整页横向溢出、文本不被固定区域遮住。键盘顺序与视觉顺序一致，图标按钮有可访问名称，焦点和对比清晰，尊重减少动态效果设置。
