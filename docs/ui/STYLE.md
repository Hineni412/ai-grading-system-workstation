# 界面样式

面向教师 Windows 工作机，风格精致、专业，允许有组织的信息密度。试卷、答卷、评分证据与当前操作获得主要空间。视觉参考只用于外观，不能据此新增业务字段或流程。

## 复用与层级

- 颜色、字号、间距、圆角、阴影和动效使用 `frontend/src/styles/tokens.css` 及主题映射；先复用现有组件与令牌。
- 默认无衬线字体从全局继承。展示标题、试题正文和等宽内容分别使用现有 display、document、mono 字体令牌。字号只用 `--font-size-*` 令牌，字重只用 `--font-weight-*` 令牌，不写像素、rem 或数字值；正文 15px，可阅读文字不小于 13px。固定尺寸的徽标、题号和计数框按文字大小留足空间。
- 基础外观参考 AIHOT：暖白工作区（`#faf9f6`）、白色内容面、青色强调（`#176b75`）、细灰绿边框和轻阴影。通过对齐、留白、字重、文字颜色和字号区分层级；阴影只用 `--shadow-raised`（静置面板）、`--shadow-floating`（浮起元素）、`--shadow-overlay`（弹层）三级。背景只允许工作区顶部的浅色主色晕染，不加无关插画、强阴影或每段内容单独套卡片。
- 文字层级先用字重（`--font-weight-regular`、`--font-weight-medium`、`--font-weight-semibold`）和文字颜色（`--color-text-primary`、`--color-text-secondary`、`--color-text-muted`）区分，仍不够时再加大字号；不使用低于 400 的字重。
- 用间距分组时，组内间距小于组间间距：字段标签离自己的输入框近，离下一个字段远；小标题离下文近，离上文远。
- 区分相邻区块时先用留白或底色差；两者仍不能说明归属时再加细边框，不给每个区块和列表行都加边框。
- 同一行并排不同字号的文字时按基线对齐（`align-items: baseline`），不按上下居中对齐。
- 同一操作区突出一个主要动作；批量操作在有选中项时出现。重要信息常显，不只藏在悬停中。页面栏数、抽屉和弹窗按当前操作决定。
- 工作台首页在视口宽度不小于 1200px 时使用左侧清单与最近考试、右侧 340px 吸顶面板；较窄时按待处理、当前考试、本学期学情、最近考试排列。待处理清单只突出第一条需要处理事项；当前考试使用竖排步骤，提示文字可见。
- 小标题与分组标签使用中文。
- 状态同时用文字或图标表达，不能只靠颜色。
- 学情总览与知识结构在 `frontend/src/styles/knowledge-overview.css` 的页面作用域内使用 `--heat-0` 至 `--heat-5`，从现有危险色与内容面色混合派生六级热度；阈值集中在 `frontend/src/components/knowledge-overview/metrics.ts`。知识点小圆角加左侧色边、技能大圆角；无证据用灰色斜纹，细条与图例保留四档人数文字，热度不改变掌握档位。

## 信息密度与文字

- 不用占满整行的卡片或进度条只承载一两个数字或一句话。同类信息并排成紧凑行、表格或行内统计；进度用行内细条加数字，放在它所属的行里。
- 文字只保留操作必需的部分：标题和按钮直接说明对象与动作，不写解释设计思路、操作原理或重复标题含义的灰色说明，也不在标题上方加重复标题的小字眉题。
- 说明文字只在可能误操作、结果不可逆或必须知道前提时出现：一句话，紧贴相关控件。空白与失败状态用一句话加下一步按钮。
- 报告、讲解、解析等大段正文限制行宽，每行不超过约 40 个汉字（约 `40em`），不随窗口铺满整行。大标题使用 `--line-height-tight`，正文使用 `--line-height-body`，较宽的大段正文使用 `--line-height-relaxed`。
- 新增或修改页面时按以上前两条检查，删去可以省略的卡片、说明和提示。

## 动效

- 动效只用于说明状态变化、保持位置连贯和确认操作；界面动效不超过 300ms。
- 进入与离开使用 `--ease-out`，屏幕内移动使用 `--ease-in-out`，抽屉使用 `--ease-drawer`；颜色和悬停变化使用 `ease`。时长使用 `--duration-fast`、`--duration-base`、`--duration-drawer`、`--duration-page`。
- 页面切换：新页面淡入并轻微上移，旧页面立即移除。抽屉从边缘滑入，对话框由 0.97 倍放大淡入；离开比进入快。
- 可复用效果放在 `frontend/src/styles/ui-effects.css`：`fx-enter`、`fx-stagger`、`fx-overlay`、`fx-drawer-right`、`fx-dialog`、`fx-lift`。新页面优先使用这些类，不另写同类关键帧。
- 持续动画只用于正在进行的工作（运行中的任务、进度条、加载骨架）。等待处理、失败和当前步骤等静态状态不闪烁、不呼吸。
- 悬停位移只在支持悬停的设备上生效；按钮按下轻微缩小。
- 尊重减少动态效果设置：所有动画与过渡在该设置下关闭。

## 控件与内容

- 普通操作使用 `AppButton` 的主要、次要、弱化、危险四种样式，图标操作使用 `AppIconButton`：青色主要按钮、白底描边次要按钮、透明弱化按钮和红色危险按钮，统一 8px 控件圆角。尺寸由现有高度和字号令牌控制。
- 字段复用 `Input`、`AppField`；需要保留原生数字转换、下拉或多行输入时使用 `app-input` 外观类。字段统一白底、8px 圆角与细边框，标签常驻，错误靠近字段，沿用原有数据绑定、校验和保存事件。
- 状态使用 `StatusBadge` 的柔和底色胶囊标签；空白、加载、失败使用 `StatePanel`，持续提示使用 `FeedbackBanner`。空白状态安静居中，失败时提供原有重试动作，加载显示内容骨架；保留 AI、教师等业务状态的含义。
- 表头与数据对齐，长中文、文件名和数字不互相遮挡；截断内容提供可访问的展开方式。
- 浮层标题、正文、操作区互不遮挡，关闭入口与焦点返回清楚。
- 按章节训练和按学生训练共用出卷面板。视口宽度不小于 1200px 时，左栏 300px、中栏随剩余宽度伸缩、右栏 340px，右侧面板随滚动保持可见；较窄窗口依次排成单栏。名单与章节细条使用紧凑行，学生详情在抽屉中查看，Esc 关闭后返回原姓名按钮。
- 成绩明细的个人报告图标独立于姓名按钮，点击区域至少 24×24px；全屏阅读器的考试条横向滚动，顶栏按宽度换行，Esc 返回所看学生的成绩抽屉。批量导出弹窗宽度最多 720px，内容在弹窗内滚动，关闭后恢复焦点。
- 试卷和答卷保持比例，工具条不挡关键内容；图像不可用时显示文字说明。
- 训练回收批改的汇总行只突出一个主要按钮。1280px 及以上使用学生队列 240px、原始答卷随剩余宽度伸缩、判定点台账 400px 三栏，各自滚动；1024–1279px 使用 220px 队列，右侧答卷和台账上下排列；1024px 以下为单栏，队列变成横向紧凑条。台账使用固定头部、可滚动内容和不透明底栏，内容不进入底栏下方；整页不横向滚动。
- 图表配色使用主题中的 `--chart-1` 至 `--chart-5`，说明问题、单位、图例和缺失数据，不用三维效果和装饰动画；提供必要文字解释。

## 导航与快捷操作

- 侧栏使用深色墨青（`--sidebar-*` 令牌），工作区保持浅色；侧栏内文字对比不低于 4.5:1，状态色使用 `--sidebar-status-*`。
- 桌面端没有顶栏：页面标题只在页面自身出现一次。900px 及以下保留一条窄顶栏（导航开关与页面名）；工作台子导航存在时显示为窄标签条。
- 设置页用标题行右侧三个标签切换：学生名单、AI 服务、数据与空间，不再添加第二条左侧栏；学生名单铺满内容区，按可用宽度显示多栏紧凑名册（常见桌面窗口三栏，窄窗口两栏或一栏），每人保留姓名、学号、班级和编辑入口。编辑抽屉 380px，导入弹窗 760px，较窄窗口按可用宽度收缩。
- 视口宽度不小于 1440px 时侧栏默认展开并显示文字，可收起，偏好保存在本机浏览器；较窄时为图标栏，悬停展开。题库管理与组卷工作台在 900px 以上默认保持展开，以维持原型的栏位宽度；900px 及以下为顶部折叠导航。
- 题库管理与组卷工作台使用一行页头，页签放在标题与操作之间，内容栏各自滚动；题卡展开后卡头吸顶，较宽题卡的题干和标注并排。知识与训练的五个子页复用 `PageHeader`，页签放入页头，当前页用青色下划线标识；1100px 及以下页签换到下一行，窄屏可横向滚动。打开训练卷或讲义草稿后，页头改为返回入口、草稿标题与信息、右上横排步骤条，隐藏五个页签；1100px 及以下步骤条换到第二行左对齐。看卷 10 分钟沿用同一页头，类别页签在右侧并高亮当前类别。
- 返回上一页统一使用 `design-system/BackButton`，放在页面标题左侧（使用 `PageHeader` 时放入 `#back` 插槽），文字为“← 返回 + 上一页名称”；弹窗和抽屉的关闭入口不使用它。
- 侧栏品牌下方是“当前考试”切换卡，显示考试名、状态、教学学期和日期；图标栏中为图标按钮。点开的浅色浮层包含教学学期、考试搜索与列表、其他学期、新建考试和考试管理。任务中心入口位于侧栏底部，任务提示浮卡贴在侧栏右侧底部。
- `Ctrl+K` 打开快速跳转，可搜索页面和切换考试；切换考试与切换教学学期沿用未保存修改与待核对保护。

### 多步流程

- 多步骤页面使用 `design-system/StepProgress`（圆点连线）：节点表达真实完成度（done/in_progress/todo），正在查看的步骤单独标记；项与项之间用固定连接线，不用胶囊按钮表达步骤。

## 验证

先检查用户实际窗口；影响共享布局或长内容时补充窄窗口。核对主要动作可达、无意外整页横向溢出、文本不被固定区域遮住。键盘顺序与视觉顺序一致，图标按钮有可访问名称，焦点和对比清晰，尊重减少动态效果设置。

## 视觉来源

基础颜色、边框、阴影及控件外观参考 [AIHOT](https://github.com/KKKKhazix/AIHOT/tree/cf8f8d07d68dfa9079becc72b0717a45b33485f3) 的主题、Controls、admin/ui、Badge 与 EmptyState，移植到本项目现有 Vue 组件。版权和 MIT 许可保存在 `frontend/third-party/AIHOT-LICENSE.txt`。本项目品牌、导航、步骤、表格与答卷工具沿用现有实现。文字层级、分组间距、区块分隔、基线对齐和行宽规则参考 Adam Wathan 与 Steve Schoger 的《Refactoring UI》，按本项目令牌重新表述。
