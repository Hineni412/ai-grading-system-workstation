# 页面细节与性能优化验收记录（2026-08-07）

## 冻结目标与边界

- 核心目标：消除拆题页跳动和信息失衡，修复 Q3/Q4 结构校验，统一设置与任务中心，简化班主任学生入口，打通备课资料选择，并降低题库/组卷读取等待。
- 常用流程：上传试卷并核对拆题；触发后台任务并随时缩回任务中心；从班主任学生卡查看已确认结构化概览；从已解析备课资料检查范围后交给 AI。
- 包含：上述页面和其最小必要读取/归一化行为、受影响测试、合成数据浏览器验收。
- 不包含：题库管理和组卷工作台的前端重排；真实学生/试卷写入；真实模型验收调用；推送远程仓库。
- 复用：现有 `ConfigSourceService`、题库读取服务、AI 任务/普通 Job store、`StudentCardService`、备课资料目录 store；仅为点击学生补充一个“按学生读取”的最小接口，避免沿用已退役的全班学生卡接口，也没有新建平行策略层。
- 风险等级：中。涉及拆题内容投影、模型结果归一化和跨页面导航；未执行数据库迁移或真实数据写入。

## 人工验收清单

建议在本机真实应用中依次勾选；除第 6 项外均不需要调用模型。

- [ ] 打开一场已有考试，进入“上传与拆题”；确认上传卡始终在拆题列表上方，滚动到底再回来也不跳位。
- [ ] 查看长答案题；确认左右卡片等高、摘要短且清晰，点“查看完整答案”能看到完整解析。
- [ ] 打开原先 Q4；确认题面末尾不再出现下一大类“填空题/解答题”等标题。
- [ ] 连续刷新题库和组卷工作台各 3 次；确认题库首屏和组卷选题明显快于旧版，页面布局没有变化。
- [ ] 发起一个普通后台任务；确认右上角自动弹出不透明进度卡，点“缩到任务中心”后任务仍能在任务中心找到。
- [ ] 如需最终实机确认 Q3/Q4，可只重试这两题 1 次；确认不再出现“conflicting canonical answers”。这会使用 1 次模型调用。
- [ ] 侧栏确认只有一个“设置”；在页面内切换“模型与 AI 任务”“备份与维护”，保存后重新进入仍在正确内容区。
- [ ] 在班主任工作台打开“学生”；确认没有重复搜索/筛选，点一名已有确认记录的学生可看到结构化概览，且不会自动发起 AI。
- [ ] 在备课工作台选择一份已解析但未加入本学期的资料；点“加入本学期并选中”，检查发送范围，再确认“交给 AI 整理课时树”可用。
