# 五册教材知识标准 v2 实施计划

> 冻结日期：2026-08-05
> 业务线：阅卷系统 / P4 知识标准
> 风险等级：中高（改变新题标签候选、图谱身份和版本兼容；本轮不操作真实数据）

## 1. 目标

把组卷网北师大版（2024）七年级上册至九年级上册五册目录中已保留的 1124 个“章—小节—子知识点”节点，发布为下一版纯知识标准候选。新题只在教师选定册别及其之前册别中检索知识节点；模型优先选择能够可靠确定的最深节点，不能确定时回退到最近的可靠父节点。

教材路径节点是知识身份，不是思想方法、数学模型、能力或特殊题型。其他六个受控标签维度保持现有语义和词表，不因本次知识标准切换而合并或扩张。

## 2. 包含内容

- 把一次性来源快照机械转成五册只读教材目录，保留 36 个章、126 个小节和 962 个子知识点。
- 为每个保留节点生成不随显示名变化的项目稳定 ID、完整教材路径、父节点和来源引用。
- 生成知识词表修订版和知识图谱发布包：每个教材路径节点独立累计证据、独立计算掌握度；父子只建立教材结构关系。
- 题目候选先按“当前册及以前册”缩小范围，再按题干、答案和题型本地检索；候选必须带父链，允许模型可靠回退。
- 批量模型请求只发送本批题目候选的并集，并在每题契约中保留允许的知识 ID，避免第一题候选误用于整批。
- 按图谱发布版本选择匹配的词表，使旧发布包仍能读取旧 294 词，新发布包读取 1124 节点。
- 生成旧 294 词到新节点的确定性兼容清单；只接受精确且唯一的名称/来源匹配，歧义和无匹配保持显式，不猜测迁移。
- 更新课程目录接口、前端解码和受影响测试。

## 3. 明确不包含

- 不读取、写入、复制、暂存或迁移真实 `user_data`。
- 不在真实数据库中预演、暂存或激活新图谱发布包。
- 不批量改写历史题目标签、掌握度或教师审核记录。
- 不调用真实模型，不产生费用，不重启 8035 或其他实际服务。
- 不采集题目正文，不再次访问外部网站，不建立定时同步。
- 不新增九年级下册，不补写教材目录以外的知识、思想方法或模型。
- 不把教材相邻关系自动解释成数学先修；本轮只生成 `parent` 教材结构关系。
- 不 push、不创建 PR、不合并或同步 `main`。

## 4. 冻结语义

- **教材知识路径节点**：五册目录中除精确标题“回顾与思考”“复习题”之外保留的章、小节或子知识点。完整路径参与显示和身份区分。
- **当前及以前册别**：按七上、七下、八上、八下、九上的固定教学顺序，从第一册累计到教师选定册；未来册别不能进入候选。
- **父级回退**：候选命中子节点时同时携带其小节和章；模型拿不准子节点时选择最近的可靠父节点，不创建自由文本替代。
- **独立掌握度**：章、小节、子知识点均有独立身份。直接命中哪个节点，就把证据记在哪个节点；父级证据不猜测分配给子节点。
- **历史兼容**：旧 294 词只有精确、唯一对应时才能投影到新节点；多义、拆分或无对应时保持不可计算，不静默选一个。

## 5. 验收条件

1. 教材目录固定为五册，节点总数 1124；只排除 31 个“回顾与思考”和 31 个“复习题”。
2. 册别累计候选上限依次为 243、428、687、916、1124，任何题都不能看到所选册之后的节点。
3. 每个节点 ID 唯一且稳定；显示名包含册、章、小节和自身名称，重名节点不会混淆。
4. 检索后的每题知识候选有明确上限；入选节点的祖先全部在同题候选中，父级回退始终可用。
5. 批量请求的共享知识表等于各题候选并集，每题允许 ID 保持独立；不能借用另一题专属候选。
6. 新词表与新图谱包结构校验通过：1124 个知识词、1124 个活动节点、1124 条一对一映射、1088 条父关系。
7. 旧发布包仍能与旧词表配套读取；新发布包与新词表配套读取。版本不匹配时明确失败，不返回空标签冒充成功。
8. 旧 294 词兼容清单逐项有结果，数量恰为 294；歧义和无匹配不自动迁移。
9. 后端受影响测试、前端受影响测试、类型检查和差异检查通过；稳定候选按仓库规则完成一次需求符合性和一次代码质量并行评审。

## 6. 相关故障场景

| 场景 | 预期结果 |
|---|---|
| 重复生成目录或发布包 | 输出内容和哈希完全一致，不产生第二套身份 |
| 两个任务同时读取目录 | 只读缓存可复用，不写共享状态 |
| 生成中途退出或部分完成 | 校验失败；不把半份目录当作可用发布包 |
| 重新启动且真实库仍激活旧发布 | 继续使用旧发布及旧词表，不自动迁移 |
| 新发布暂存失败或重试 | 真实库本轮不操作；临时库中依赖现有发布幂等与冲突检查 |
| 取消模型任务 | 已冻结的每题候选不改变；不产生额外模型请求 |
| 某题没有可靠叶子 | 返回小节或章；仍无可靠节点时进入知识新词候选，不从未来册借词 |
| 同名节点位于不同教材路径 | 通过完整路径和稳定 ID 区分；短名称只作检索提示 |
| 旧词对应多个新节点 | 标记歧义/拆分，不静默迁移或合并证据 |
| 词表版本与图谱版本冲突 | 明确报版本不匹配，不降级成空候选或错误图谱 |

## 7. 发布边界

本轮交付的是可在临时数据库验证的代码候选。真实应用切换到新标准仍需要教师单独授权：精确确认目标数据库、备份、预演结果、激活步骤和回退版本后，才能执行真实发布激活。
