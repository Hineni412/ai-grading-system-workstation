# 初中数学备课工作台

本文描述当前备课工作台的产品流程、正式写入边界和故障恢复规则。
工作台的最终成果是教师核对过、不会覆盖源文件、可在 WPS 中继续编辑和上课的副本与上课包。

## 1. 当前结论

- 默认首页采用 C 型总览，先展示最近课时和各课时当前进度。
- 资料库是独立工作面，用于长期导入、解析、定位和确认教学资料。
- 单课时工作面保持三栏上下文，并按四个阶段推进。
- 四个阶段是确认资料、定方案、审核改编、生成副本。
- 候选练习、课堂方案和课件改编都先形成草稿，教师确认后才成为正式结果。
- AI 通过共同 AI Task 执行，结果以 Handoff 进入目标页面，以 Receipt 确认正式采用。
- WPS 只操作隔离副本，永远不覆盖教师上传的源 PPTX。
- 备课只读使用题库和教师选择的匿名学情证据，不向知识训练或班主任工作区写入。
- 真实资料、真实模型、真实 WPS 和破坏性文件操作都需要本次明确授权。

## 2. 页面与信息层级

### 2.1 C 型首页

首页首先回答三个问题：

1. 最近要备哪一节课；
2. 每节课进行到哪个阶段；
3. 哪些任务、草稿或副本需要继续处理。

桌面端以近期课时矩阵为主。
教师可以按学期和课时定位，也可以从最近记录直接继续。
首页只显示安全摘要，不铺开完整资料、模型正文或历史版本。
课时尚未建立时，页面引导教师先选择学期并建立个人授课课时树。

### 2.2 资料库

资料库不做通用文件浏览器。
它只管理教师明确导入的教材、教辅、答案、参考 PPTX 和其他教学资料副本。
桌面原文件不会被移动或修改。

### 2.3 单课时三栏

- 左栏：当前课时、资料来源、候选对象和阶段导航。
- 中栏：当前资料、练习、课堂方案或幻灯片的主要预览。
- 右栏：核对依据、缺失项、教师决定和本阶段唯一主要操作。

三栏共同绑定同一课时和来源修订。
切换课时、阶段或来源时，迟到响应不能覆盖当前内容。
窄屏按来源、预览、决定逐层进入，并保留明确返回。

## 3. 资料库流程

1. 教师选择资料并确认导入副本。
2. 系统在受控目录保存来源指纹和文件类型。
3. PDF 逐页生成预览并执行本地文字识别。
4. PPTX 读取页标题、对象摘要和可用预览。
5. 系统形成资料单元，不把失败页伪装成已解析。
6. 教师为资料选择学期和资料角色。
7. 系统基于目录、页码和标题形成课时映射候选。
8. 教师逐条确认、修改或拒绝映射。

资料解析可以后台运行。
离开页面或应用重启后，教师可以从同一任务继续查看进度。
预览、文字识别和目录定位是不同状态；其中一项完成不代表整份资料可用。

课时映射按单份资料形成建议。
不同资料不会未经教师确认就相互覆盖。
模型提出的教材页码只能作为候选，必须能回到真实页或受控目录证据。

删除资料前先显示受影响版本、解析页、课时关联、候选练习和正式生成历史。
有进行中或可恢复生成时拒绝删除。
已经冻结进正式成果的事实快照继续保留，避免旧上课包失去来源解释。

## 4. 单课时四阶段

### 4.1 确认资料

教师选择本节课真正要使用的教材页、教辅区域、答案和参考课件。
页面区分来源事实、系统定位和教师决定。
没有可核对原页、题目或答案的候选不能进入正式生成。

系统在模型调用前冻结本节来源快照。
快照包括资料版本、页或对象身份、教师选择和内容指纹。
来源随后变化时，旧草稿保留，但必须重新核对，不能直接覆盖新来源。

### 4.2 定方案

系统根据已确认资料形成候选练习和课堂方案草稿。
教师决定保留、删除、补充和排序哪些练习。
课堂方案说明教学目标、重点、环节、时间和练习安排，但不替教师作最终教学决定。

候选题必须能回到资料页、题库题目或教师明确补充的来源。
答案状态保持可见：

- 来源提供；
- 系统整理待核对；
- 教师已验证。

AI 不能把“来源提供”或“系统整理”自动升级为“教师已验证”。
正式采用前，教师应核对题目、答案、难度、课堂容量和本班适配性。

### 4.3 审核改编

课件改编先生成逐页、逐对象的结构化操作建议。
页面同时显示源幻灯片画布、目标位置覆盖层和操作清单。
每项操作必须有稳定的源页、源对象或插入位置。

教师逐项选择：

- 接受；
- 拒绝；
- 仅人工处理。

位置无法唯一确定、来源已变化或操作不在安全白名单时，不交给 WPS 猜测执行。
保存审核只记录教师决定，不表示 WPS 已经运行。

### 4.4 生成副本

教师确认完整改编清单后，系统建立隔离 staging 副本。
WPS 只打开该副本并执行已批准的受支持操作。
未触及的页面和对象应保持原样。

执行后必须：

1. 关闭并重新打开 PPTX；
2. 校验页数和对象结果；
3. 逐页渲染可见预览；
4. 检查文件可以继续编辑和放映；
5. 原子发布为新的可信版本。

任何检查失败都不发布半成品。
源 PPTX、上一可信版本和其他课时文件保持不变。

上课包只能从教师选中的可信版本生成。
它可以组合定稿 PPTX、课堂练习、教师答案和必要的离线资源。
下载入口只返回受控文件身份，不暴露本机路径。

## 5. AI Task、Handoff 与 Receipt

每次语义生成使用一个稳定 operation。
第一次派发同时建立 AI Task 和后台任务。
离开页面、刷新或重启不会重复发送。

共同任务区只显示安全标题、状态、进度、来源引用和恢复入口。
资料正文、题目正文、学情内容和完整模型结果不进入公共任务摘要。

模型完成后先保存候选草稿，再建立 Handoff。
Handoff 携带不透明目标、来源修订和返回焦点。
目标来源变化时 Handoff 标为过期，草稿保留，教师重新选择目标。

教师在目标页面逐项核对后才可采用。
正式业务对象和 Adoption Receipt 在同一领域事务中保存。
响应丢失后重放采用操作会返回同一 Receipt，不重复创建方案、练习或课件计划。

单次 operation 最多一次物理模型发送。
模型失败或结果未知不自动重试。
结果已经返回但本地草稿保存失败时，只重试本地保存，不再次付费。

## 6. WPS 隔离与版本规则

- 源 PPTX 只读，不执行原地保存。
- staging 只保存尚未发布的临时副本。
- WPS Adapter 只接收已批准且在安全白名单内的操作。
- 删除页、调序、文本框、静态图片和受支持的新页必须精确定位。
- 复杂公式、组合对象、动画或无法稳定定位的内容转为仅人工处理。
- WPS 超时、退出、保存失败或验证失败都不发布新版本。
- 正式发布使用新文件和新版本身份，不覆盖旧版本。
- 恢复旧版本只移动当前指针，不删除其后的新版本。
- 同一操作的重复点击由请求令牌收敛，不能产生多个正式副本。

## 7. 只读证据边界

备课工作台拥有独立的备课数据库和受控文件根。
它可以只读获取：

- 当前题库题目和已核对答案；
- 教师明确选择的考试学情摘要；
- 匿名化的班级或学生证据；
- 当前教材树和稳定知识身份。

读取必须经稳定 Adapter。
备课不能写入题库标签、知识掌握、训练证据或考试成绩。
备课不读取班主任记录、对话或学生支持正文。
学情证据来源变化时，已有方案保留来源快照，不静默改写。

## 8. 失败与恢复

- 资料上传中断：保留已完成受控副本，不登记成可用资料。
- 预览或文字识别部分失败：逐页显示状态，只重做失败派生物。
- 映射任务失败：保留教师已确认映射，不覆盖为模型结果。
- 模型调用失败：保留来源快照和人工工作区，不生成空方案。
- 模型结果未知：查询原 operation 或由教师放弃，不自动重发。
- Handoff 保存失败：保留模型候选，只重试本地交接。
- 来源版本变化：旧草稿标记过期，不覆盖新来源。
- WPS 中途退出：清理或隔离临时副本，不改变正式版本。
- WPS 发布响应丢失：先读取 Receipt 和版本列表，不重新执行。
- 上课包某项生成失败：整个包不标完成，并列出缺失项。
- 删除响应不确定：重新读取影响对象和当前版本，不盲目重复删除。

## 9. 安全与当前限制

- 默认不把完整资料库发送给模型，只发送本次冻结范围内的必要内容。
- 模型只形成候选，不直接操作 WPS，不自动采用，也不自动发布。
- 题目、答案、学情和文件路径不得进入地址栏、普通日志或公共任务 API。
- 备课可以由教师选择进入普通受保护备份；未选择时不应被暗中包含。
- 备份、恢复、迁移和永久删除都要先显示精确范围并单独授权。
- 真实模型调用前说明目的地和费用影响，失败后不追加隐藏请求。
- 真实教材、教辅、PPTX 或 WPS 操作必须限定到教师授权的副本和输出目录。
- WPS 输出以当前工作机实际可打开、编辑和放映为准，不承诺跨软件像素完全一致。
- 不在安全白名单内的课件对象必须交给教师人工完成。
- 当前工作台不替教师决定教学目标、最终题目、最终答案或正式课件内容。
