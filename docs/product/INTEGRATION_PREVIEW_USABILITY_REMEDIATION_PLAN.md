受隔离数据与费用边界限制，以下路径采用“浏览器界面 + 受影响检查”验收，没有发起真实模型请求：Q10 的真实模型返回、新词归并真实模型输出、上传一份新的备课资料后再归档、存在历史混合批改任务时的实时批次变化。对应本地解析、中文展示、归档和统计代码路径均已覆盖；正式合入后如要做带真实资料或真实模型的验收，仍须单独授权精确数据与调用次数。

## 1. 给教师的结论

本批不是零散的样式微调，而是一次“集成预览基本流程可用性”修复。当前预览存在以下确定问题：

1. 系统把“建议核对题型”错误升级成了逐题强制确认，阻断评分依据生成。
2. 右下角“AI 任务”只覆盖少量教师工作台任务，既遮挡页面，又看不到评分依据、批改、打标签等普通后台任务。
3. Q10 所走的组合分析通道绕过了现有本地 JSON 安全修复和截断识别。
4. 教材小节重复显示原始英文 ID；题库回收站入口和危险层级不清；两页虽复用难度组件，视觉仍被页面样式覆盖。
5. 原问题清单没有第 5 项，本计划沿用原编号，不另造需求。
6. 全局学生管理没有“我的班主任班级”；修改默认班级后，当前旧会话仍可能按旧班级匹配学生。
7. 备课资料回收被藏成两个易中断步骤；任一局部请求失败会把整页说成不可用；生产首页还保留了硬编码验收样例。
8. 批改页用整份答卷终态冒充批次进度，并把尚待 AI 处理的项目全部称为“需要老师”。
9. 题库“补齐”后台实际只补缺口，但界面用总题数冒充模型处理数，任务离页后又难以恢复。
10. 新词理由允许英文原文直出；已审核映射没有充分参与运行时收敛，制造了过多“假新词”。
11. 知识图谱和训练推荐每次筛选前都复制、复读比对并检查两个完整数据库，随后还存在重复计算和并发堆积。
12. 之前的工程检查没有覆盖当前集成预览的首步真实使用流程，却被错误地当成了产品可用性证据。

本批完成后，教师应获得以下直接结果：

- 只修改系统确实判断错的题型，不必逐题“点一下表示同意”。
- 所有可恢复后台工作从一个不遮挡页面的任务中心查看。
- 单题格式失败先零费用本地修复，截断与坏格式明确区分，成功题不重跑。
- 批改显示真实批次完成数，“需要老师”只统计真正异常或待复核项目。
- 补标签先告诉教师实际会跳过多少、本地补多少、需要模型处理多少，离页后仍能续看和续作。
- 备课资料局部失败不再拖垮整页，资料可一步移入可恢复回收站。
- 班主任默认班级在全局学生管理设置，新旧对话的班级语境清楚且不会静默串班。
- 知识图谱和训练推荐不再为每次筛选重复复制两个完整数据库，更新期间保留上一版可用内容。

## 3. 任务边界

### 3.1 目标

1. 修复当前集成预览中已经由截图和源码共同确认的基本流程阻断、错误统计、错误恢复和交互歧义。
2. 把跨页面重复出现的任务恢复、批次进度、班级语境、局部错误、标签补缺和证据快照收口到少量深 Module 后面。
3. 冻结重复操作、同时操作、中途退出、重启、失败重试、取消、部分完成和数据冲突的预期结果。
4. 建立以浏览器模拟教师操作为主的人工验收脚本，停止用自动检查数量代替产品可用性判断。

### 3.2 包含

- 评分依据生成条件、教师题型覆盖的安全恢复和明确阻断原因。
- 组合题目分析响应的截断诊断、本地安全 JSON 修复、业务校验和失败题续作。
- 公共任务中心及普通 Job、Workspace AI Task 两类安全摘要 Adapter。
- 教材小节中文投影、题库回收站交互和共用难度滑块的视觉接口。
- 全局班主任班级偏好、空会话同步和已有会话换班交接。
- 备课资料的原子回收、局部加载状态和生产空态文案。
- 混合批改工作单元台账、批次摘要和正确的教师干预口径。
- 题库补缺预检、任务发现、失败项续作和强制重打区分。
- 新词中文协议、受控本地收敛、结构化建议展示和现有安全审核门。
- 知识图谱/训练推荐的版本化只读快照、同请求合并、轻量查询和共享诊断结果。
- 相关产品契约、当前执行索引和实现完成后的架构事实更新。

### 3.3 明确不包含

- 不改变普通考试分数、排名、报告、评分数学、教师最终分锁或复核语义。
- 不让未确认题型冒充“教师已确认”。
- 不增加隐藏模型调用、自动重试或失败后自动追加费用。
- 不用本地程序补全被截断的模型业务内容。
- 不允许 AI 自动批准真正的新核心知识词、上下位词、相关词、一对多或跨维度映射。
- 不把数据库中的教材小节稳定 ID 改成中文文本。
- 不改变整卷回收、单题删除和随卷恢复的既有数据语义。
- 不执行题库或资料的永久物理删除；不可逆删除另立任务并逐次授权。
- 不删除学生、改变历史事务或静默把已有内容的会话换到另一班级。
- 不覆盖原 PPTX，不操作真实 WPS、教材、教辅、学生档案、成绩、训练卷或答卷。
- 不为提速跳过数据版本校验，也不永久返回旧缓存。
- 不读取、复制、迁移、修复或写入真实 `user_data`。
- 不在当前文档任务中修改生产代码、创建数据库迁移、启动服务、调用模型、运行测试或代码复审。
- 不 push、不创建 PR、不合并、不切换或同步 `main`。

### 3.4 完成条件

本批“代码实现完成”与“产品验收通过”分开记录：

- 所有实施包完成后，只能标记为 `implementation_candidate`，不得自行宣称可用。
- 用户明确要求验收并逐项授权服务、数据和模型范围后，才执行第 8 节浏览器人工验收。
- 浏览器脚本的 P0 场景全部通过、P1 场景没有阻断正常流程的问题后，才可标记 `teacher_accepted`。
- 自动测试、构建或代码复审即使以后获准并通过，也不能替代上述人工验收。
- 未经用户再次授权，不执行提交、合入、push、PR、真实迁移或发布。

### 3.5 风险等级

高。实现涉及公共壳层、后台任务恢复、数据库读一致性、外部模型费用、批改状态、资料生命周期、学生匹配范围和多个多人热文件。风险主要不是算法本身，而是重复执行、半完成、旧响应覆盖、刷新后失联、误报教师工作量和跨页面语境不一致。

## 4. 冻结的产品与修改规则

### 4.1 题型核对是建议，不是生成许可

- `question_type_review_required` 只产生非阻断提醒。
- 未操作表示沿用系统预览，`question_type_confirmed=false`。
- 只有教师实际修改时才保存覆盖值；安全状态只保存枚举和来源版本，不保存正文或图片。
- 源版本变化后旧覆盖失效，必须重新核对，不能静默套用。
- 真实阻断仅包括图片尚未处理、教材范围缺失、没有纳入题目等确实无法生成的条件。
- 生成按钮附近直接列出真实阻断原因，不再只显示“尚未达到整卷条件”。

主要热文件：

- `frontend/src/stores/config-workspace.ts`
- `frontend/src/components/config/ConfigGenerationPanel.vue`
- `frontend/src/components/config/QuestionBlockReview.vue`
- `backend/config_workspace/sources.py`
- `question_bank/training_criteria/adapters.py`

### 4.2 任务中心统一展示，不合并执行状态机

- 删除固定在右下角的全局悬浮按钮。
- 宽屏在顶部栏操作区、窄屏在顶部栏展开区提供“任务中心”。
- 任务中心组合展示普通 Job 和 Workspace AI Task，但两类任务继续保留各自的取消、恢复、`result_unknown`、Handoff 和结果规则。
- 普通 Job 接入现有安全列表；Workspace AI Task 增加只返回安全摘要的服务器列表。
- `workspace_ai.*` 运行 Job 与对应 Workspace AI Task 去重，只显示一张语义完整的卡。
- 服务器负责发现当前和近期任务；localStorage 只作加速引用，不能成为任务存在性的唯一证据。
- 任务摘要不得包含业务正文、prompt、学生姓名、真实文件名、真实路径或敏感结果。
- 打开、刷新和恢复任务中心只能查询，绝不重新提交任务或模型调用。
- 一个来源失败时保留另一来源和上次成功状态，不把整个任务中心置空。

- `frontend/src/components/shell/AppTopbar.vue`
- `frontend/src/workspaces/shared/ai-tasks/*`
- `frontend/src/api/jobs.ts`
- `backend/api/routers/jobs.py`
- `backend/api/routers/workspace_ai_tasks.py`
- Workspace AI Task repository/schema

### 4.3 模型返回先分类，再安全修复

- 组合分析通道先读取 provider 结束原因和结构诊断。
- 被截断的结果单独返回 `truncated`，不得通过补括号伪造成完整业务结果。
- 非截断结果调用现有确定性本地修复器，处理围栏、BOM、可安全修复的逗号、转义和控制字符。
- 本地修复后仍通过题号、字段和业务结构校验；“能解析”不等于“业务有效”。
- 结果分类至少包括：本地已修复、输出未结束、格式无法安全修复、业务字段不完整。
- 诊断只保存修复动作、长度、哈希、结束原因和安全错误码，不保存模型正文。
- 单题失败只允许显式重试该题；其他成功题逐字保留。
- 同一安全失败签名重复出现时停止盲目调用，先调整输出契约或转人工编辑。

主要热文件：

- `question_bank/training_criteria/adapters.py`
- `backend/llm/json_repair.py`
- `backend/jobs/config_generation.py`
- `frontend/src/components/config/ConfigGenerationPanel.vue`

### 4.4 题库显示和回收语义

教材小节：

- `curriculum_section` 从通用自由标签列表和通用添加入口排除。
- 统一显示“册别 · 章 · 小节”的中文路径，内部继续保存稳定 ID。
- 映射暂时缺失时显示“教材小节待核对（保留原记录）”，不得清空或改写 ID。

回收站：

- 顶部入口显示“回收站（N）”，卡片操作显示“移入回收站”。
- 确认框列出会隐藏的试卷和当前活跃题数，并说明源文件、图片、标签及历史证据的保留情况。
- 回收站条目显示“随本次移入 X 题，可恢复”。
- 恢复与永久删除分区；永久删除保持单独影响预览、二次确认和逐次授权。
- 批量恢复部分失败时逐项报告，失败项保持选中，不能只给一个总失败提示。
- 恢复整卷只恢复随该次操作移入的题，不带回此前单独删除的题。

难度滑块：

- 滑块 Module 自己拥有标签、轨道、滑块、刻度、区间说明、键盘和触屏规则。
- 显式清除 WebKit/Firefox 原生轨道，只显示统一自定义轨道。
- 题库和组卷页面只控制外部宽度，不能用通用 `input` 样式覆盖内部元素。
- 删除组卷页重复“难度”标签；两页使用同一视觉和交互接口。

### 4.10 知识图谱与训练推荐复用版本化只读快照和一次诊断结果

- 得分率使用轻量汇总查询，不读取或解析无关 `raw_json`。

## 5. 统一 Module、Interface 与 Seam

本批不允许各页面继续维护一套薄状态。以下 Module 以小 Interface 隐藏复杂恢复规则，提高所有调用方的 leverage，并让修改和故障集中在一个 locality 内。

| Module | 外部 Interface（调用方只需知道） | 隐藏的 Implementation | Seam 与 Adapter |
|---|---|---|---|
| `TaskCenterModule` | 列出安全任务摘要、读取单项、请求允许的取消、返回来源页 | 两套任务查询、去重、局部失败、revision 收敛和安全字段过滤 | 公共壳层 seam；`JobSummaryAdapter` 与 `WorkspaceAITaskSummaryAdapter` 是两个真实 Adapter |
| `QuestionAnalysisResponseModule` | 输入响应文本和结束诊断，返回已解析结果或明确失败分类 | 围栏/BOM/转义修复、截断识别、schema/题号校验和安全诊断 | 组合分析网关内部 seam；只有一种本地实现，不额外制造 pass-through Adapter |
| `HybridGradingProgressModule` | 规划工作单元、开始/收口 attempt、读取运行摘要 | 台账、唯一键、防重、取消、中断、部分完成和教师队列统计 | 批改运行 seam；客观识别与主观批改作为内部调用者，不暴露存储细节 |
| `HomeroomContextModule` | 读取/更新默认班级，解析当前会话该继续还是新建 | preference revision、学生库 revision、空会话更新和已有会话冻结 | 全局学生页与 B 工作台共用 seam；B 存储是现有 Adapter，模块关闭时公共页降级 |
| `MaterialWorkspaceProjectionModule` | 分别读取基础、列表、当前资料、解析、目录建议和维护结果 | 各自 loading/error/generation、上次成功数据和局部恢复 | A 前端工作区 seam；不再把共享 `loadState` 暴露给所有页面 |
| `TaggingGapPlanModule` | 预检补缺计划、执行计划、发现/续作任务 | 完整性分类、本地补齐、费用批次、任务去重和失败项续作 | 题库页 seam；与任务中心共用任务发现，不再复制一套 tracker |
| `EvidenceReadSnapshotModule` | 按数据版本取得一致只读上下文，按范围取得一次诊断结果 | 快照生命周期、版本失效、single-flight、轻量查询和投影缓存 | 知识图谱/推荐 seam；阅卷库与题库读取是两个本地 Adapter |
| `CurriculumLabelModule` | 稳定 ID 与教师可见中文路径互转 | 目录加载、旧 ID 保留和缺失映射提示 | 题库/组卷显示 seam；内部稳定 ID 不泄漏成日常标签 |

接口纪律：

- Interface 包含调用顺序、错误模式、费用和性能承诺，不只是一组类型定义。
- 调用方不得读取 Module 内部表、localStorage key 或临时状态来推断业务结果。
- 只有确实存在两个 Adapter 的 seam 才定义 port；单实现逻辑直接放入深 Module，避免增加薄转发层。
- Implementation 可以保留内部 seam 便于以后验证，但不得为了验证把内部状态暴露给页面。

### 7.2 安全字段

普通任务、Workspace AI Task、批改单元和浏览器验收记录都只允许安全摘要：

- 可公开：任务类型、阶段、数量、百分比、安全错误码、时间、内部安全引用。
- 不可公开：学生姓名、业务正文、答案、评分依据正文、模型原文、真实资料文件名、真实绝对路径、密钥和 prompt。

### 7.3 模型费用

- 打开页面、预检、恢复、刷新、中文模板、快照、掌握度和图谱读取都不得调用模型。
- 一次教师确认只授权页面明确展示的初始批次；不包含失败后追加调用。
- 未知响应先查询原 operation/job/task，不自动补发。
- 失败重试只处理失败或缺失项，且需要教师再次明确点击。
- 已发生的调用和费用不可因取消回滚，页面应明确区分“已发送”和“尚未发送”。
- 每次真实模型验收都需重新确认数据、模型、最大调用次数和失败后的追加规则。

## 9. 故障矩阵

| 故障场景 | 冻结结果 |
|---|---|
| 重复点击 | 复用原 operation、task、job 或工作单元，不重复产生费用或重复保存 |
| 多窗口同时操作 | 使用 revision/source revision 阻止旧页面覆盖；冲突后刷新并保留教师待选内容 |
| 页面离开或刷新 | 服务器发现原任务；恢复状态和已保存结果；不创建新任务 |
| 应用中途退出 | 已完成内容保留；`running` 进入中断/结果未知；禁止自动重发付费请求 |
| 应用重新启动 | 重建只读缓存并查询持久任务；localStorage 不是唯一事实来源 |
| 失败重试 | 只重试失败或缺失项；成功项不重跑；重试 attempt 不增加批次分母 |
| 取消 | 未发送项取消；已发送项允许收口；已保存内容和已发生费用不回滚 |
| 部分完成 | 分别显示成功、失败、待处理和需教师数量；单项失败不把整页说成失败 |
| 响应结果未知 | 先查询原任务/operation；没有明确终态前不允许追加模型调用 |
| 数据缺失 | 保留稳定 ID、历史结果和上次成功视图；明确显示缺失，不伪造默认值 |
| 数据或版本冲突 | 停止写入或续作，刷新真实状态后重新确认；不覆盖教师更新或锁分 |
| 资料回收半途失败 | 同事务整体回滚，不留下“已退出学期但未归档” |
| 换班中途失败 | 学生和历史会话不改；偏好已保存但页面刷新失败时明确区分两件事 |
| 快照或更新失败 | 不把旧快照冒充最新响应；页面可保留上次结果并显示更新失败 |
| 一个任务来源失败 | 任务中心保留另一来源和上次状态，不清空全部任务 |
