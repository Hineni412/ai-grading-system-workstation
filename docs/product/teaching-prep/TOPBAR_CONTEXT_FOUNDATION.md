# 备课工作台公共顶部栏上下文地基

## 冻结边界

- 目标：由工作区 manifest 声明顶部栏上下文；备课工作台和班主任工作台进入后，不再显示与当前工作无关的考试选择、考试管理入口及考试列表状态。
- 包含：公共 manifest 契约、注册表投影与校验、路由元数据、顶部栏条件展示、公共外壳受影响测试。
- 不包含：备课或班主任业务功能、考试选择行为改造、页面内课时/学生上下文、真实数据操作、数据库迁移、模型调用、发布或主线合并。
- 验收条件：两个教师工作区均隐藏考试上下文；考试批改等核心路由仍显示并可使用当前考试上下文；manifest 缺少合法声明时关闭失败；窄屏和桌面顶部栏布局均不留下空白列。
- 风险等级：中。改动位于公共页面外壳，但只影响展示条件和布局，不改变考试状态及数据。

## 故障场景

| 场景 | 预期结果 |
|---|---|
| 重复导航 | 每次进入教师工作区都只显示工作区自己的上下文 |
| 同时操作 | 不改变考试 store 和配置草稿，现有考试页切换保护保持有效 |
| 中途退出/重新启动 | manifest 静态声明重新生效，不依赖本地缓存 |
| 失败重试 | 工作区内不展示无关的考试列表失败与重试入口；考试页仍可重试 |
| 取消 | 不适用；本任务不产生异步业务操作 |
| 部分完成 | manifest 非法时注册失败，不以不确定上下文继续运行 |
| 数据缺失或冲突 | 未声明工作区上下文时校验失败；核心路由默认维持当前考试上下文 |

## 实现检查点

- `WorkspaceManifest` 新增受控的 `topbarContext`，注册表负责校验并投影为路由元数据；两个教师工作区声明 `workspace`，未声明的核心页面默认保持 `current-exam` 行为。
- 顶部栏在工作区上下文中只保留页面标题、说明和窄屏导航按钮，不挂载考试选择、考试管理抽屉或考试列表状态；专用布局移除原本为考试选择预留的空白列。
- 受影响测试 24 项通过；前端无输出类型检查、局部 ESLint、生产构建和差异格式检查通过。构建仅保留仓库既有的大分块提示，没有新增失败。
- 本任务未读取、复制、修改或暂存真实 `user_data`，未调用模型、WPS 或外部服务；当前待与 A 线候选一起进行最终双复审。
