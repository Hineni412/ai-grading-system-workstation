### 包含

- A 模块前后端 manifest、根页面和 API；
- A 独立数据库、迁移、仓储、事务和状态机；
- 请求幂等、operation ID、revision 冲突保护；
- A 专用 Job 注册和 Fake 适配器；

- 只使用临时目录、合成记录和 Fake。

### 不包含

- 真实教材、教辅、PPTX 或学生数据；
- 真实模型、费用或自动重试；
- 真实 WPS 执行；
- 对真实 `user_data/` 的迁移或写入式验证；
- P4/B 数据读取或写入；
- 公共导航、路由、应用壳、全局依赖和普通备份规则修改；
- push、PR、合并或同步 `main`。

### 验收条件

- 模块关闭时没有导航、API、目录或数据库副作用；
- 模块开启后只创建 A 的受控目录和 `teaching_prep.db`；
- 迁移和相同创建请求可安全重复；
- 旧 revision 更新返回冲突，不覆盖新内容；
- Job 中断、失败和重启后的状态可解释；
- 课时树与资料记录不接受客户端服务器绝对输出路径；
- 题目与答案区域固定到原资料版本，答案区域变化使旧确认失效；
- 题目相似提示不自动合并，未确认答案不能成为正式答案依据；
- 所有自动检查只使用临时目录。

### 风险等级

中等。当前不接触真实资料、真实模型和 WPS；主要风险是状态并发、重复创建、错误目录副作用和后续迁移兼容。

## 3. 本任务相关故障场景

| 场景 | 当前预期 |
|---|---|
| 重复创建 | 同一请求键返回原记录；请求键绑定不同内容时明确冲突 |
| 同时更新 | 只有持有当前 revision 的请求成功，旧 revision 不覆盖 |
| 中途退出 | SQLite 事务回滚，不留下半条业务记录 |
| 重新启动 | 已提交状态保留；运行中 Job 由既有 JobManager 标记为中断失败 |
| 失败重试 | 另建明确 operation；模型 Fake 和未来真实模型均不自动追加调用 |
| 取消 | 进入 `cancelled`，不伪装成成功状态 |
| 部分完成 | 保留最后成功状态和失败 operation，不倒退已确认版本 |
| 数据缺失 | 允许教师继续手工补充，缺失来源明确显示 |
| 数据冲突 | 保留已有版本并返回冲突，由教师刷新后决定 |
| 模块关闭 | 不加载路由、服务、迁移或 Job，不创建工作台目录 |

### A03 边界（2026-07-30）

目标：在不调用模型和 WPS 的情况下，把已登记资料拆成可预览、可人工核对的稳定单位，并把一个课时关联到一个或多个不连续范围。

包含：

- PDF 内嵌文本提取与逐页 PNG 预览；
- PPTX 标题、基础对象清单和结构预览；
- 图片资料的单单位预览；
- 扫描空白文本页的人工标签兜底；
- 教材页、参考课件页和教辅页的多段范围关联；
- 关联的新增、修正、停用、排序和资料版本冻结；
- 预览缓存丢失后的确定性重建；
- 公开 API 只返回内部 ID、资料名、页码和受控预览 URL。

不包含：

- 真实教学文件、WPS、OCR、视觉模型或费用；
- 公式 OCR 正确性判断；
- 题目与答案区域（A04）；
- 真实文件选择和任意服务器路径输入。

风险等级：中等。主要风险为资料替换后关联漂移、解析部分完成、缓存与数据库不一致、跨页范围错位和 API 路径泄露。

故障预期：

| 场景 | 预期 |
|---|---|
| 重复解析 | 复用同一资料单位；缺失缓存只重建，不重复建单位 |
| 同时解析 | 数据库唯一约束保证单位唯一；缓存文件按稳定名称原子替换 |
| 中途退出 | 不发布半套单位；残留缓存可覆盖重建 |
| 重新启动 | 数据库单位和确认关联保留；缓存缺失时按原指纹重建 |
| 文件被替换 | 指纹不符时拒绝解析，不让旧关联漂移 |
| 扫描页无文本 | 标记为待人工标注，不自动调用 OCR |
| 公式文本 | 标记为待核对，不声称公式已正确识别 |
| 不连续范围 | 保存为多个有序关联，不扩成一个错误连续区间 |
| 关联修正冲突 | 旧 revision 返回冲突，不覆盖另一页面的修正 |
| 预览删除 | 从固定资料版本重新生成；确认关联不变 |

### A04 边界（2026-07-30）

目标：让教师在已确认的教辅资料范围内，完全离线地框选题目与答案原图、校对匹配关系，并决定题目进入课堂、备用或排除。

包含：

- 一页多题、跨页、多栏和图文分离题目的多个有序区域；
- 题目区域与答案/解析区域的原资料版本、页码和裁切坐标；
- 题号、难度、课堂用途、预计时间、教学重点和教师备注；
- `candidate`、`teacher_verified`、`rejected`、`missing` 四种答案状态；
- 课堂候选、备用和排除三种筛选结果；
- 基于教师填写线索和来源题号的重复候选提示，最终由教师决定；
- 候选题新增、修正和停用的幂等、事务与 revision 冲突保护；
- 受控裁图预览；公开 API 不返回工作机绝对路径。

不包含：

- OCR、视觉模型、真实模型调用或费用；
- 自动判断唯一题号、唯一答案、难度、知识点或重复题；
- 把未确认答案放入教师答案页；
- 写入现有题库，或使用真实教材、教辅、答案册和 `user_data/`；
- A05 资源包与发布证据快照。

验收条件：

- 合成双栏页可以保存两道独立题目，一道题可以包含跨页的多个区域；
- 答案错配后可更换区域，原教师确认自动失效；
- 只有 `teacher_verified` 状态可作为正式答案依据；
- 相同题候选展示可解释依据，但不自动合并；
- 候选题及其全部区域在一个事务中保存，不留下半条记录；
- 不调用模型也能完成课堂候选、备用和排除筛选；
- 来源版本和区域原图引用受外键保护，不能被静默删除或漂移。

风险等级：中高。主要风险是答案错配、跨页区域顺序错误、修改裁图后旧验证仍有效、重复操作留下半成品，以及相似提示被误当作自动去重结论。

故障预期：

| 场景 | 预期 |
|---|---|
| 重复保存 | 同一请求键返回同一候选；绑定不同内容时明确冲突 |
| 同时校对 | 仅当前 revision 可更新，旧页面不能覆盖新区域或答案状态 |
| 中途退出 | 候选题和全部区域同一事务回滚，不留下部分区域 |
| 重新启动 | 已保存区域、教师标签和答案状态保留；未保存画框只作为页面草稿丢弃 |
| 答案区域修正 | 已验证状态自动降为 `candidate`；没有答案区域时降为 `missing` |
| 来源文件被替换 | 资料指纹不一致时拒绝保存或预览，不迁移到新版本 |
| 失败重试 | 使用原请求键安全重放，不重复建立候选 |
| 取消画框 | 不写数据库，不改变已有候选 |
| 重复提示 | 只展示来源题号或教师线索的匹配依据，不自动合并 |
| 来源删除 | 外键拒绝破坏仍被候选题引用的资料单位和版本 |

### A05 边界（2026-07-30）

目标：在任何 AI 分析前，把教师确认的课时、资料、题目、答案与可选匿名学情证据冻结成不可变资源包，使后续草稿只能引用明确版本。

包含：

- 课时树 revision、课堂时长、班级、新授课类型和教师补充的班级整体情况；

- 题目数、学生数、覆盖率、考试日期、缺失项和来源版本；
- 不可变 `ResourcePackVersion`、来源变化提示和不含绝对路径的清单导出；
- 证据源不存在或没有匹配记录时继续冻结，并明确记录缺失。

不包含：

- 自动读取未选择的考试、班级、学生或题库内容；
- 姓名、学号、联系方式、答卷图片、个人错误详情、班主任观察或心理信息；

| 场景 | 预期 |
|---|---|
| 重复冻结 | 同一请求键和相同输入返回原版本，不重复创建 |
| 同时冻结 | 每个课时版本号在事务内顺序分配，唯一约束阻止重号 |
| 中途退出 | 资源包整条 JSON、指纹和版本号同一事务回滚 |
