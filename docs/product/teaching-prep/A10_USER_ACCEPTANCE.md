# A10 用户人工验收脚本

## 1. 当前可安全进行的验收

当前自动化候选只使用匿名合成资料，已经完成课时树、资料定位、题目与答案核对、资源包、课堂草稿、课件计划、WPS Fake 执行、上课包、同课异班和课后复盘的完整闭环。

真实资料验收开始前，仍需用户逐次明确：

1. 本次允许使用的教材、教辅和 PPTX 副本的精确文件；
2. 是否允许启动真实 WPS；
3. 是否只使用匿名或合成班级证据；
4. 输出目录、可用磁盘空间和源文件备份；
5. 测试结束后保留哪些副本、暂存和诊断预览。

未获得上述授权时，不打开真实文件、不执行真实迁移、不启动 WPS 或模型。

## 2. 建议的代表性资料

- 一份用户明确指定的数学 PPTX 副本，包含普通文本、静态图片、公式或组合图形；
- 一段教材范围；
- 两套教辅中的少量合成或获授权题目与答案页；
- 一个匿名班级和另一个匿名班级；
- 不使用姓名、学号、联系方式、个人答卷、心理或班主任记录。

源 PPTX 在开始前记录只读指纹；整个验收只允许修改工作台隔离副本，不覆盖源文件。

## 3. 人工验收步骤

| 步骤 | 操作 | 预期结果 |
|---|---|---|
| 1 | 建立“节”并在下面建立三个课时 | 三个课时独立保存、可排序，节与课时层级正确 |
| 2 | 为目标课时关联教材范围、参考 PPT 范围和两套教辅范围 | 每段范围可预览，来源版本和页/幻灯片位置明确 |
| 3 | 修正一个错误页码和一个错误题目裁切 | 新 revision 生效，旧页面不能覆盖；答案区域变化后旧确认失效 |
| 4 | 核对两道课堂题和教师答案 | 题目可跨页/多区域；只有教师确认答案可进入正式答案页 |
| 5 | 冻结资源包 | 生成不可变版本和安全清单；缺失证据明确显示，不包含绝对路径 |
| 6 | 生成本地课堂草稿 | 不调用模型；重难点、流程和题目取舍均有来源，时间总量可解释 |
| 7 | 调整参考 PPT 练习和两道关键题 | 教师修改生成新的草稿版本，原版本保留 |
| 8 | 生成并逐项审核课件改编计划 | 每项操作有目标、原因、来源和风险；白名单外操作只能人工处理或拒绝 |
| 9 | 经单独授权后用 WPS 执行计划 | 只打开隔离副本；源 PPTX 指纹不变；失败时不发布候选 |
| 10 | 人工打开、编辑和放映输出 PPTX | 输出可由 WPS 重开、可编辑、可完整放映；数学内容由教师确认 |
| 11 | 确认定稿并生成上课包 | ZIP 同时包含 PPTX、练习、教师答案、流程、来源、课检和 manifest |
| 12 | 派生另一个匿名班级版本 | 新班级使用相同冻结资料但班情、草稿、计划、PPTX 和发布历史独立 |
| 13 | 模拟一次 WPS 失败或中断 | 上一个完整版本保持可用；半成品不冒充发布，可安全恢复或清理 |
| 14 | 完成一分钟课后复盘 | 只记录课堂节奏、题目效果、重讲点和下一版动作，不产生学生判断 |
| 15 | 明确选择该复盘生成下一版 | 新资源包保存复盘来源；未选复盘不影响新版本 |
| 16 | 恢复较早的完整上课包 | 较早版本成为当前版本，较新历史包仍保留且可下载 |

## 4. 验收记录

每一步记录：

- 通过 / 未通过 / 未执行；
- 实际看到的结果；
- 是否使用真实资料、真实 WPS 或真实模型；
- 源文件是否保持不变；
- 是否出现路径、个人信息、费用、半成品误发布或历史覆盖；
- 需要修正的问题及截图编号。

## 5. 发布关口

只有用户明确表示“A 线人工验收通过”，才能另行执行 push、创建 PR、合并和同步 `main`。自动测试、正式复审或本脚本本身都不能代替用户授权。
