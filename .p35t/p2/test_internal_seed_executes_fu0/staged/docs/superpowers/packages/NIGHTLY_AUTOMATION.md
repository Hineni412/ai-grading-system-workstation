# 夜间自动化安全停机

当前 P3.5 正在进行，Phase 4 为 `paused`。在这两个状态改变前，任何夜间自动化都必须 **只报告、不实施**。

夜间不得：

- 自动领取、创建、恢复或继续任何开发任务。
- 修改代码或文档、切换分支、创建/重分配 worktree。
- 运行测试、构建、复审或用户验收。
- 创建提交、push、PR、合并或清理分支/worktree。
- 读取或操作真实 `user_data/`。
- 调用真实模型、使用密钥、产生费用或执行不可逆操作。

每次触发只需报告：

1. P3.5 仍由用户在白天逐批推进。
2. Phase 4 仍暂停。
3. 下一动作是等待用户在当前 P3.5 任务中提出或确认需求。

只有用户明确结束 P3.5、恢复某个正式 Phase，并同步更新 `AGENTS.md`、`EXECUTION_INDEX.md` 和本文件后，才可以重新设计夜间自动化。不得根据旧资格矩阵、历史计划、旧包状态或旧自动化配置自行恢复。
